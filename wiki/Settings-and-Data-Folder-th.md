# การตั้งค่าและโฟลเดอร์ข้อมูล

## แท็บการตั้งค่า

แท็บการตั้งค่ารวบรวมการทำงานทั่วไปของโปรแกรม: ลักษณะ (ขนาดตัวอักษร ธีม และภาษา) การอัปเดตโปรแกรม (ตรวจสอบบน GitHub ตอนเริ่มและทุก 30 นาที อัปเดตอัตโนมัติแบบเงียบ ตรวจสอบเดี๋ยวนี้) แหล่งข้อมูลสด (อัปเดตอัตโนมัติทุก 5 นาที) RMOB (ผู้สังเกต ดาวน์โหลดเดี๋ยวนี้ และดึงข้อมูลอัตโนมัติ) และโปรแกรม (แถวคำสั่งและโฟลเดอร์ข้อมูล) ค่าพารามิเตอร์ของการคำนวณยังอยู่ในแถวคำสั่งเหนือแท็บ

## แบบอักษรและการควบคุม

- **แบบอักษร** (การตั้งค่า): ขยาย **ข้อความทั้งหมด** ตั้งแต่ **85 ถึง 140 %** ทีละ 5 % เส้น วงกลม และแผนที่คงขนาดเดิม เมื่อใช้แบบอักษรขนาดใหญ่ แท็บจะขึ้นบรรทัดที่สองและการ์ดจะขยายขึ้น
- **การควบคุม**: เมื่อใช้แบบอักษรขนาดใหญ่หรือหน้าจอเล็ก ให้พับแถวตัวควบคุมสามแถวเพื่อเว้นที่ให้แผนที่และกราฟ สถานะนี้จะถูกจดจำไว้

## โฟลเดอร์ข้อมูล

ข้อมูลและการตั้งค่าทั้งหมดอยู่ในโฟลเดอร์ **`data`** เดียว **ข้างโปรแกรม** – ไม่มี AppData ไม่มีโฟลเดอร์ระบบ:

| ระบบ | โปรแกรม | ข้อมูล |
|---|---|---|
| Windows (ตัวติดตั้ง) | `C:\YA-MS\YA-MS.exe` | `C:\YA-MS\data` |
| Windows (แบบพกพา) | ที่ใดก็ตามที่คุณแตกไฟล์ไว้ | `data` ข้าง `YA-MS.exe` |
| Linux | `~/YA-MS/YA-MS` | `~/YA-MS/data` |
| macOS | `~/YA-MS/YA-MS.app` | `~/YA-MS/data` (ข้างแอป) |

ตอนเริ่มต้น โปรแกรมจะสร้างโฟลเดอร์หากจำเป็น และคัดลอกเฉพาะไฟล์เริ่มต้นที่ **ขาดหายไป**: ไฟล์ที่คุณแก้ไขแล้วจะไม่ถูกเขียนทับ ไฟล์แปลใน `data/lingue` เป็นไฟล์ของโปรแกรม และจะถูกแทนที่เมื่อไฟล์ของเวอร์ชันใหม่ใหม่กว่า

### ไฟล์ที่คุณแก้ไขได้

| ไฟล์ | เนื้อหา |

| `sciami.csv` | แคตตาล็อกฝนดาวตก (ค่าของ IMO และค่าที่ใช้ทำงาน) ดูที่ [ฝนดาวตก](Showers-th#การแก้ไขแคตตาล็อก) |

## config.ini

ข้อความธรรมดา หนึ่ง `key=value` ต่อบรรทัด (บรรทัดที่ขึ้นต้นด้วย `#` หรือ `;` เป็นหมายเหตุ) โปรแกรมจะเขียนไฟล์นี้เมื่อปิด ดังนั้น **ให้แก้ไขขณะที่ YA-MS ปิดอยู่** คีย์ที่คุณอาจอยากรู้:

| คีย์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `mio_locator`, `mia_quota_m` | JN70CN, 62 | locator และความสูงของคุณ (m) |
| `dx_locator`, `dx_quota_m` | JO62QM, 50 | locator และความสูงของสถานี DX (m) |
| `banda_MHz` | 144 | ย่านความถี่ (28, 50, 70, 144, 222, 432) |
| `quota_scie_km`, `quota_da_radar` | 90, 1 | ความสูงของรอยดาวตก (km) 1 = ใช้ฐานนิยมของ Collm |
| `elevazione_lobo_gradi` | 0 | มุมเงยของโลบ (°) |
| `boom_m` | 4.6 | ความยาวบูมของยากิ (m) |
| `hot_spot_km` | 150 | ระยะ Hot A / Hot B จากจุดกึ่งกลาง (30–400 km) |
| `lingua` | ระบบ / `it` | รหัสภาษา (หนึ่งใน 36 รหัสข้างต้น เช่น `it`, `en`, `de`) |
| `tema` | `chiaro` | ชุดสี: `chiaro` (สว่าง), `scuro` (กลางคืน), `nero` (ดำ), `pastello-azzurro`, `pastello-arancione`, `pastello-acquamarina`, `pastello-verde`, `pastello-rosa`, `pastello-lilla`, `pastello-indaco`, `pastello-marrone`, `scia` (รอยดาวตก) |
| `carattere_pct` | 100 | ขนาดแบบอักษร (85–140 %) |
| `comandi_visibili` | 1 | 1 = แสดงแถวตัวควบคุม, 0 = พับเก็บ |
| `mostra_mappa`, `vista_alto` | 1, 1 | แผนที่ยุโรป มุมมองจากด้านบนในโดมท้องฟ้า |
| `aggiornamento_automatico` | 1 | ตรวจสอบแหล่งข้อมูลโดยอัตโนมัติทุก 5 นาที |
| `esponente_lambda` | 3 | เลขชี้กำลัง λ ในแท็บฟลักซ์เรดาร์ |
| `potenza_W`, `guadagno_dBi`, `sensibilita_dBm`, `densita_esponente_q` | 400, 14, −130, 14 | ข้อมูลป้อนเข้าของงบประมาณลิงก์ |
| `prev_frequenza_MHz`, `prev_esponente`, `prev_fattore_stazione` | 144, 3, 1 | การพยากรณ์ทดลอง: ความถี่ k K |
| `rmob_osservatore` | ว่าง | ชื่อผู้สังเกตการณ์ RMOB |
| `rmob_automatico` | 0 | ดาวน์โหลด RMOB อัตโนมัติ (เปิดใช้เฉพาะเมื่อได้รับอนุญาตจาก RMOB) |
| `rmob_url` | `https://rmob.org/index.php/livedata/live_datas/{NOME}_{MMAAAA}rmob.TXT` | เทมเพลตที่อยู่ของ RMOB |
| `graves_sequenza` | 0 | ลำดับของลำคลื่น GRAVES: 0 = 0.8 s (2021), 1 = 3.2 s (2007) |
| `controlla_aggiornamenti` | 1 | ตรวจหารุ่นใหม่บน GitHub เมื่อเริ่มโปรแกรม (วันละครั้ง); 0 = ไม่ |
| `aggiornamenti_salta` | ว่าง | รุ่นที่คุณเลือก *ข้ามรุ่นนี้* |

## ความเป็นส่วนตัว

YA-MS ไม่เก็บข้อมูลใด ๆ และไม่แสดงโฆษณา โปรแกรมเชื่อมต่ออินเทอร์เน็ตเพียงเพื่อดาวน์โหลดข้อมูลสาธารณะ: ภาพเรดาร์จาก Collm และ Sodankylä แผนที่ Natural Earth (เมื่อเริ่มครั้งแรก) และไฟล์ RMOB หากคุณร้องขอ
