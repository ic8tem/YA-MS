# Настройки и папка данных

## Панель вкладок

У правого края панели вкладок, справа налево:

| Элемент | Что делает |
|---|---|
| **Язык интерфейса** (список) | Язык интерфейса; см. [Язык](#язык) |
| **Тема** (список) | Цветовая схема; см. [Цветовые схемы](#цветовые-схемы) |
| **Панель ▴ / ▾** | Сворачивает или разворачивает три ряда элементов управления над вкладками; см. [Шрифт и Панель](#шрифт-и-панель) |

Смена языка или темы сохраняет настройки и **перестраивает окно** в том же положении и размере, на той же вкладке: перезапуск не нужен.

## Язык

Шесть языков интерфейса:

| Язык | Код | Файл |
|---|---|---|
| Italiano | `it` | нет: итальянский – базовый язык (ключи) |
| English | `en` | `data/lingue/en.txt` |
| Русский | `ru` | `data/lingue/ru.txt` |
| 日本語 | `ja` | `data/lingue/ja.txt` |
| Deutsch | `de` | `data/lingue/de.txt` |
| Nederlands | `nl` | `data/lingue/nl.txt` |

При первом запуске YA-MS использует **язык системы**, если это один из перечисленных, иначе итальянский. Числа и даты следуют выбранному языку (например, десятичная точка в английском, запятая в итальянском, немецком и русском). Любой текст, отсутствующий в файле перевода, показывается на итальянском. В Linux для японского нужны подходящие шрифты: см. [Неполадки](Troubleshooting-FAQ-ru#linux-японский-текст-отображается-квадратиками).

Документ [Эффективность - пояснение](Efficiency-Explanation-ru) и руководство по расчётам написаны на итальянском.

## Цветовые схемы

Список **Тема** предлагает 12 схем – те же, что в EME-программе автора YAEC, плюс исходная палитра YA-MS:

| Схема | Описание |
|---|---|
| **Светлая** | по умолчанию |
| **Ночь** | тёмно-синие тона, для работы ночью |
| **Чёрная** | чёрный фон, для темноты и для экранов OLED |
| Пастельный голубой · Пастельный оранжевый · Пастельный аквамарин · Пастельный зелёный · Пастельный розовый · Пастельный сиреневый · Пастельный индиго · Пастельный коричневый | восемь светлых пастельных схем |
| **Метеорный след** | исходный стиль YA-MS (до версии 1.2.0): ночной фиолетовый с голубым, фиолетовым, светло-зелёным, жёлтым и оранжевым |

Схема применяется ко всем вкладкам и сохраняется в `config.ini` (ключ `tema`).

## Шрифт и Панель

- **Шрифт** (в конце первого ряда элементов управления): увеличивает **весь текст** от **100 до 300 %** с шагом 10 %; линии, окружности и карты сохраняют свой размер. При крупном шрифте вкладки переносятся на вторую строку, а карточки увеличиваются.
- **Панель**: при крупном шрифте или маленьком экране сверните три ряда элементов управления, чтобы освободить место для карт и графиков. Состояние запоминается.

## Папка данных

Все данные и настройки находятся в одной папке **`data`** **рядом с программой** – никакого AppData и системных папок:

| Система | Программа | Данные |
|---|---|---|
| Windows (установщик) | `C:\YA-MS\YA-MS.exe` | `C:\YA-MS\data` |
| Windows (портативная) | там, куда вы её распаковали | `data` рядом с `YA-MS.exe` |
| Linux | `~/YA-MS/YA-MS` | `~/YA-MS/data` |
| macOS | `~/YA-MS/YA-MS.app` | `~/YA-MS/data` (рядом с приложением) |

При запуске программа при необходимости создаёт папку и копирует только **отсутствующие** начальные файлы: изменённые вами файлы никогда не перезаписываются. Файлы переводов в `data/lingue` – это файлы программы, и они заменяются, если файлы новой версии более свежие.

### Файлы, которые можно редактировать

| Файл | Содержание |
|---|---|
| `sciami.csv` | Каталог потоков (значения IMO и рабочие значения); см. [Потоки](Showers-ru#редактирование-каталога) |
| `massimi_imo.csv` | Даты и время максимумов, опубликованные IMO (2026, 2027): **новые годы добавляйте** сюда |
| `ant_radiante.csv` | Положение Антигелийного источника (таблица 6 IMO) |
| `fonti_radar.csv` | Адреса радаров; `attivo=1` – загружать, `0` – игнорировать |
| `regole_sperimentali.csv` | Используемые константы и правила, каждое со своим источником (справочно) |
| `lingue/<code>.txt` | Переводы интерфейса; см. [Участие](Contributing-and-Contacts-ru#переводы) |
| `config.ini` | Настройки (см. ниже) |

### Файлы, создаваемые программой

| Файл / папка | Содержание |
|---|---|
| `config.ini` | Настройки |
| `flusso_collm.csv` | Почасовой архив потока Collm |
| `quote_collm.csv` | Архив высот следов |
| `radar/` | Последние изображения радаров и файлы RMOB |
| `mappa/` | Береговые линии и границы Natural Earth (загружаются при первом запуске) |
| `adif_quadrati.csv` | Квадраты из последнего загруженного ADIF |
| `efficienza_spiegazione.txt`, `.docx` | [Документ-пояснение](Efficiency-Explanation-ru) |

## config.ini

Обычный текст, по одной паре `key=value` на строку (строки, начинающиеся с `#` или `;`, – комментарии). Программа записывает файл при закрытии, поэтому **редактируйте его при закрытой YA-MS**. Ключи, которые могут пригодиться:

| Ключ | По умолчанию | Значение |
|---|---|---|
| `mio_locator`, `mia_quota_m` | JN70CN, 62 | Ваш локатор и высота (m) |
| `dx_locator`, `dx_quota_m` | JO62QM, 50 | Локатор и высота корреспондента (m) |
| `banda_MHz` | 144 | Диапазон (28, 50, 70, 144, 222, 432) |
| `quota_scie_km`, `quota_da_radar` | 90, 1 | Высота следов (km); 1 = использовать моду Collm |
| `elevazione_lobo_gradi` | 0 | Угол места ДН (°) |
| `boom_m` | 4.6 | Длина траверсы Яги (m) |
| `hot_spot_km` | 150 | Расстояние Hot A / Hot B от средней точки (30–400 km) |
| `lingua` | системный / `it` | Код языка (`it`, `en`, `ru`, `ja`, `de`, `nl`) |
| `tema` | `chiaro` | Цветовая схема: `chiaro` (Светлая), `scuro` (Ночь), `nero` (Чёрная), `pastello-azzurro`, `pastello-arancione`, `pastello-acquamarina`, `pastello-verde`, `pastello-rosa`, `pastello-lilla`, `pastello-indaco`, `pastello-marrone`, `scia` (Метеорный след) |
| `carattere_pct` | 100 | Размер шрифта (100–300 %) |
| `comandi_visibili` | 1 | 1 = ряды элементов управления показаны, 0 = свёрнуты |
| `mostra_mappa`, `vista_alto` | 1, 1 | Карта Европы, вид сверху на вкладке «Небесная сфера» |
| `aggiornamento_automatico` | 1 | Автоматическая проверка источников каждые 5 минут |
| `esponente_lambda` | 3 | Показатель λ на вкладке «Поток по радару» |
| `potenza_W`, `guadagno_dBi`, `sensibilita_dBm`, `densita_esponente_q` | 400, 14, −130, 14 | Входные данные энергетического баланса |
| `prev_frequenza_MHz`, `prev_esponente`, `prev_fattore_stazione` | 144, 3, 1 | Экспериментальный прогноз: частота, k, K |
| `rmob_osservatore` | пусто | Имя наблюдателя RMOB |
| `rmob_automatico` | 0 | Автозагрузка RMOB (включать только с разрешения RMOB) |
| `rmob_url` | `https://rmob.org/index.php/livedata/live_datas/{NOME}_{MMAAAA}rmob.TXT` | Шаблон адреса RMOB |
| `graves_sequenza` | 0 | Последовательность луча GRAVES: 0 = 0,8 s (2021), 1 = 3,2 s (2007) |

## Конфиденциальность

YA-MS не собирает никаких данных и не показывает рекламу. Программа подключается к интернету только для загрузки общедоступных данных: изображений радаров Collm и Sodankylä, карты Natural Earth (при первом запуске) и, если вы об этом попросите, файла RMOB.
