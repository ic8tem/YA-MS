# Configurações e pasta de dados

## A barra de abas

Na extremidade direita da barra de abas, da direita para a esquerda:

| Comando | O que faz |
|---|---|
| **Idioma** (lista) | Idioma da interface; veja [Idioma](#idioma) |
| **Tema** (lista) | Esquema de cores; veja [Esquemas de cores](#esquemas-de-cores) |
| **Comandos ▴ / ▾** | Recolhe ou exibe as três linhas de comandos acima das abas; veja [Tipo de fonte e Comandos](#tipo-de-fonte-e-comandos) |

Ao mudar o idioma ou o tema, as configurações são salvas e **a janela é reconstruída** na mesma posição e tamanho, na mesma aba: não é preciso reiniciar.

Na primeira inicialização o YA-MS usa o **idioma do sistema** se ele for um destes; caso contrário, o italiano. Os números e as datas seguem o idioma escolhido (p. ex. ponto decimal em inglês, vírgula em italiano e alemão). Qualquer texto ausente em um arquivo de tradução é mostrado em italiano. ## Esquemas de cores

A lista **Tema** oferece 12 esquemas, os mesmos do programa de EME do autor, o YAEC, mais a paleta original do YA-MS:

| Esquema | Descrição |
|---|---|
| **Claro** | padrão |
| **Noite** | tons de azul-escuro, para uso à noite |
| **Preto** | fundo preto, para o escuro e para telas OLED |
| Pastel azul-claro · Pastel laranja · Pastel água-marinha · Pastel verde · Pastel rosa · Pastel lilás · Pastel índigo · Pastel marrom | oito esquemas pastel claros |
| **Rastro meteórico** | o estilo original do YA-MS (até a versão 1.2.0): violeta noturno com azul-claro, violeta, verde-claro, amarelo e laranja |

O esquema vale para todas as abas e é salvo em `config.ini` (chave `tema`).

## Tipo de fonte e Comandos

- **Tipo de fonte** (no final da primeira linha de comandos): amplia **todo o texto** de **100 a 300 %** em passos de 10 %; linhas, círculos e mapas mantêm o seu tamanho. Com fontes grandes, as abas passam para uma segunda linha e os cartões crescem.
- **Comandos**: com fontes grandes ou uma tela pequena, recolha as três linhas de comandos para deixar espaço para mapas e gráficos. O estado fica memorizado.

## Pasta de dados

Todos os dados e configurações ficam em uma única pasta **`data`** **ao lado do programa** – nada de AppData, nada de pastas do sistema:

| Sistema | Programa | Dados |
|---|---|---|
| Windows (instalador) | `C:\YA-MS\YA-MS.exe` | `C:\YA-MS\data` |
| Windows (portátil) | onde você o extraiu | `data` ao lado de `YA-MS.exe` |
| Linux | `~/YA-MS/YA-MS` | `~/YA-MS/data` |
| macOS | `~/YA-MS/YA-MS.app` | `~/YA-MS/data` (ao lado do app) |

Na inicialização, o programa cria a pasta se necessário e copia apenas os arquivos iniciais **ausentes**: os arquivos que você alterou nunca são sobrescritos. Os arquivos de tradução em `data/lingue` são arquivos do programa e são substituídos quando os da nova versão são mais recentes.

## config.ini

Texto simples, um `chave=valor` por linha (as linhas que começam com `#` ou `;` são comentários). O programa o grava ao ser fechado, por isso **edite-o com o YA-MS fechado**. As chaves que você pode querer conhecer:

| Chave | Padrão | Significado |
|---|---|---|
| `mio_locator`, `mia_quota_m` | JN70CN, 62 | O seu locator e altitude (m) |
| `dx_locator`, `dx_quota_m` | JO62QM, 50 | Locator e altitude do correspondente (m) |
| `banda_MHz` | 144 | Banda (28, 50, 70, 144, 222, 432) |
| `quota_scie_km`, `quota_da_radar` | 90, 1 | Altitude dos rastros (km); 1 = usar a moda de Collm |
| `elevazione_lobo_gradi` | 0 | Elevação do lóbulo (°) |
| `boom_m` | 4.6 | Comprimento do boom da Yagi (m) |
| `hot_spot_km` | 150 | Distância de Hot A / Hot B ao ponto médio (30–400 km) |
| `lingua` | sistema / `it` | Código do idioma (`it`, `en`, `ru`, `ja`, `de`, `nl`, …) |
| `tema` | `chiaro` | Esquema de cores: `chiaro` (Claro), `scuro` (Noite), `nero` (Preto), `pastello-azzurro`, `pastello-arancione`, `pastello-acquamarina`, `pastello-verde`, `pastello-rosa`, `pastello-lilla`, `pastello-indaco`, `pastello-marrone`, `scia` (Rastro meteórico) |
| `carattere_pct` | 100 | Tamanho da fonte (100–300 %) |
| `comandi_visibili` | 1 | 1 = linhas de comandos visíveis, 0 = recolhidas |
| `mostra_mappa`, `vista_alto` | 1, 1 | Mapa da Europa, vista de cima na Abóbada celeste |
| `aggiornamento_automatico` | 1 | Verificação automática das fontes a cada 5 minutos |
| `esponente_lambda` | 3 | Expoente λ na aba Fluxo radar |
| `potenza_W`, `guadagno_dBi`, `sensibilita_dBm`, `densita_esponente_q` | 400, 14, −130, 14 | Dados de entrada do balanço do enlace |
| `prev_frequenza_MHz`, `prev_esponente`, `prev_fattore_stazione` | 144, 3, 1 | Previsão experimental: frequência, k, K |
| `rmob_osservatore` | vazio | Nome do observador RMOB |
| `rmob_automatico` | 0 | Download automático do RMOB (ative-o só com autorização do RMOB) |
| `rmob_url` | `https://rmob.org/index.php/livedata/live_datas/{NOME}_{MMAAAA}rmob.TXT` | Modelo de endereço do RMOB |
| `graves_sequenza` | 0 | Sequência do feixe do GRAVES: 0 = 0,8 s (2021), 1 = 3,2 s (2007) |

## Privacidade

O YA-MS não coleta dados nem exibe publicidade. Ele se conecta à internet apenas para baixar dados públicos: as imagens dos radares de Collm e Sodankylä, o mapa do Natural Earth (primeira inicialização) e, se você pedir, um arquivo RMOB.
