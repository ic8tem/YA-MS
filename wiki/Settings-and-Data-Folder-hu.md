A séma minden fülre érvényes, és a `config.ini` fájlba mentődik (`tema` kulcs).

## Betűtípus és Vezérlők

- **Betűtípus** (az első vezérlősor végén): **az összes szöveget** **100 és 300 %** között nagyítja, 10 %-os lépésekben; a vonalak, körök és térképek megtartják a méretüket. Nagy betűméretnél a fülek második sorba törnek, és a kártyák megnőnek.
- **Vezérlők**: nagy betűméretnél vagy kis képernyőn csukja össze a három vezérlősort, hogy maradjon hely a térképeknek és diagramoknak. Az állapotot a program megjegyzi.

## Adatmappa

Minden adat és beállítás egyetlen **`data`** mappában van, **a program mellett** – nincs AppData, nincsenek rendszermappák:

| Rendszer | Program | Adatok |
|---|---|---|
| Windows (telepítő) | `C:\YA-MS\YA-MS.exe` | `C:\YA-MS\data` |
| Windows (hordozható) | ahová kicsomagolta | `data` a `YA-MS.exe` mellett |
| Linux | `~/YA-MS/YA-MS` | `~/YA-MS/data` |
| macOS | `~/YA-MS/YA-MS.app` | `~/YA-MS/data` (az alkalmazás mellett) |

Induláskor a program szükség esetén létrehozza a mappát, és csak a **hiányzó** kiinduló fájlokat másolja be: az Ön által módosított fájlokat soha nem írja felül. A `data/lingue` mappa fordítási fájljai a program részei, és lecserélődnek, ha az új változat fájljai frissebbek.

## config.ini

Egyszerű szöveg, soronként egy `key=value` (a `#` vagy `;` jellel kezdődő sorok megjegyzések). A program bezáráskor írja, ezért **csak bezárt YA-MS mellett szerkessze**. A kulcsok, amelyeket érdemes ismerni:

| Kulcs | Alapértelmezés | Jelentés |
|---|---|---|
| `mio_locator`, `mia_quota_m` | JN70CN, 62 | Az Ön lokátora és magassága (m) |
| `dx_locator`, `dx_quota_m` | JO62QM, 50 | A DX állomás lokátora és magassága (m) |
| `banda_MHz` | 144 | Sáv (28, 50, 70, 144, 222, 432) |
| `quota_scie_km`, `quota_da_radar` | 90, 1 | Nyommagasság (km); 1 = a Collm-módusz használata |
| `elevazione_lobo_gradi` | 0 | Lebeny elevációja (°) |
| `boom_m` | 4.6 | A Yagi tartócsövének hossza (m) |
| `hot_spot_km` | 150 | A Hot A / Hot B távolsága a felezőponttól (30–400 km) |
| `lingua` | rendszer / `it` | Nyelvkód (`it`, `en`, `de`, `hu`, … – 36 kód, lásd [Nyelv](#nyelv)) |
| `tema` | `chiaro` | Színséma: `chiaro` (Világos), `scuro` (Éjszaka), `nero` (Fekete), `pastello-azzurro`, `pastello-arancione`, `pastello-acquamarina`, `pastello-verde`, `pastello-rosa`, `pastello-lilla`, `pastello-indaco`, `pastello-marrone`, `scia` (Meteornyom) |
| `carattere_pct` | 100 | Betűméret (100–300 %) |
| `comandi_visibili` | 1 | 1 = vezérlősorok láthatók, 0 = összecsukva |
| `mostra_mappa`, `vista_alto` | 1, 1 | Európa-térkép, felülnézet az Égbolt-kupolán |
| `aggiornamento_automatico` | 1 | A források automatikus ellenőrzése 5 percenként |
| `esponente_lambda` | 3 | λ-kitevő a Radarfluxus fülön |
| `potenza_W`, `guadagno_dBi`, `sensibilita_dBm`, `densita_esponente_q` | 400, 14, −130, 14 | Az összeköttetési mérleg bemenetei |
| `prev_frequenza_MHz`, `prev_esponente`, `prev_fattore_stazione` | 144, 3, 1 | Kísérleti előrejelzés: frekvencia, k, K |
| `rmob_osservatore` | üres | Az RMOB-megfigyelő neve |
| `rmob_automatico` | 0 | Automatikus RMOB-letöltés (csak az RMOB engedélyével kapcsolja be) |
| `rmob_url` | `https://rmob.org/index.php/livedata/live_datas/{NOME}_{MMAAAA}rmob.TXT` | Az RMOB-cím sablonja |
| `graves_sequenza` | 0 | GRAVES nyalábsorrend: 0 = 0,8 s (2021), 1 = 3,2 s (2007) |

## Adatvédelem

A YA-MS nem gyűjt adatokat, és nem jelenít meg reklámot. Csak nyilvános adatok letöltése miatt csatlakozik az internethez: a Collm és a Sodankylä radarképei, a Natural Earth térkép (első indításkor) és – ha Ön kéri – egy RMOB-fájl.
