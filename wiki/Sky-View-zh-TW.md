# 天穹

*分頁：預報計算 › 預報計算。*

[![天穹](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)

這個子分頁（即早期版本中的天穹）在一個畫面上顯示有用的餘跡此刻**在哪裡**，以及天線**該指向哪裡**。左側是路徑的**平面圖**；右側是流星雨清單、帶輻射點的小天穹、計算文字以及從天線看出去的**剖面**。所有內容都以*計算日期（UTC）*和*小時（−12 至 +36 h）*滑桿所選的時刻為準（預設即時，步長 15 分鐘）。

**平面圖上方的資訊列**彙整該時刻的計算結果：日期和時間（*目前*或距現在的小時數）、**路徑指數 Σ ZHR×η**、**最有用的流星雨**及其 ZHR 和效率（也以相對於 DJ5HG 基準的 dB 表示，請參閱[效率計算](Efficiency-Calculation-zh-TW)）、地平線以上的流星雨數量，以及**建議的 Hot** 及其方位角。

在小天穹中，一條穿過天頂的**橘色線**始終標出**正確的天線方向**，即與所選流星雨（或最有利流星雨）移動方向正交的方向：輻射點方位 ±90°，兩端標註 *天線 NNN°*，並以細線表示 ±45° 容差。天穹邊緣上的橘色短刻度標出其他有用流星雨的正交方向。

## 平面圖（左側）

從上方俯視的歐洲地圖（**東在右**），四周有度數刻度。地圖下方的說明列出其半徑（*地圖：邊緣 = 距本台 … km*）。

| 元素 | 繪製方式 |
|---|---|
| 路徑 / DX | 從本台到對方電台的綠線（始終是兩個網格座標之間的實際大圓路徑） |
| **Hot A / Hot B** | 位於中點兩側、垂直於路徑的點，距離由 AMS 偏角表決定（或手動輸入）。**紅色 = 建議**，**粉紅色 = 在天線波瓣外**，**灰色 = 在波瓣內**（並給出提示） |
| 天線波瓣 | 以天線方位為中心的 −3 dB 水平波瓣（天線始終指向 DX），標註為 *波瓣 …°* |
| 公共區域邊界 | 淡色的 *界 A* / *界 B* 點，以及各台站地平線與 E 層相交形成的兩個圓（請參閱[幾何](Geometry-and-Path-Loss-zh-TW#公共區域邊界)） |
| 流星雨移動軌跡 | **黃線**：所選流星雨（或最有利流星雨）掃過天空的方向，即輻射點方位 |
| 最佳指向 | **橘點**：與移動方向垂直的兩個指向（輻射點方位 ±90°，SM6FHZ） |
| **PREV 區域** | 淺色橢圓：**此刻**最可能的餘跡落點，路徑每側各一個 |

標註不會互相重疊：Hot A 和 PREV A 寫在路徑左側，B 寫在右側。**圖例**是地圖右側一個可收合的欄。

**在地圖上用滑鼠：** **左鍵 = 對方電台網格座標**，**右鍵 = 本台網格座標**。路徑會立即重新計算。

流星雨清單上方的選項：**Hot A / Hot B 方向**、**歐洲地圖**（Natural Earth，首次啟動時下載到 `data/mappa`）、**俯視圖（東在右）**。

### 建議的 Hot

對於所顯示的時刻，程式對地平線以上的所有流星雨累加權重 ZHR × 效率，並依 A 側（比例 f_A）和 B 側分配。權重較大的一側即為建議的 Hot，以紅色繪出：

```math
W_A = \sum \frac{ZHR\,\eta}{100}\,f_A,\qquad W_B = \sum \frac{ZHR\,\eta}{100}\,(1-f_A),\qquad \mathrm{Hot} = \arg\max(W_A,\ W_B)
```

*程式的選擇（手冊公式 23）。* 這一想法的來源：DJ5HG，由 DF5HC 轉述（DARC 會議 2018）——根據輻射點位置，HOT-A 和 HOT-B 兩點中有一個較有利。向該側偏轉 10–30°（側向散射）則來自 Cerrotta–Sartori 的文章。

### PREV 區域

對 E 層上的每個點 P，累加所有活躍流星雨對效率的貢獻（與[效率](Efficiency-Calculation-zh-TW#模型)中相同的鏡面條件），以 ZHR 加權。達到最大值至少 3 % 的點構成 PREV 區域；每個區域繪成一個橢圓，中心 = 各點的加權平均位置，軸長 = 其離散度的兩倍。

```math
W_P = \sum ZHR\; c_P(\hat{s}),\qquad c_P = 100\,\frac{w_P S_P \max(0,\ \hat{s}\cdot\hat{u}_P)}{\max F},\qquad PREV:\ W_P \ge 0{.}03\,\max W
```

*程式的選擇（手冊公式 34）。* 這就是實用規則：如果流星雨由北向南掃過，有用的餘跡就落在東側和西側。

## 流星雨清單（右上）

| 欄位 | 含義 |
|---|---|
| 流星雨、代碼 | 名稱和 IMO 代碼 |
| 目前 ZHR | 此刻的活動水準（IMO 峰值 ZHR 結合活動曲線） |
| 方位角、仰角 | 從本台看的輻射點位置 |
| 效率 % | 該流星雨對這條路徑的效率 |
| 側 | A 或 B，大多數反射到達的一側 |
| 最佳指向 | 輻射點方位 ±90° |
| 升起、落下 | 輻射點的升起和落下時間（UTC）；適用時顯示*拱極*或*始終在下方* |

點選一列即可選取該流星雨：黃色移動軌跡線和橘點會隨之改變。

## 小天穹（右側中部）

從本台看的天穹上的輻射點，附有 **IMO 代碼**和**青色的每日軌跡**（UTC 時刻）。**點選輻射點**即可選取它。顏色：

| 顏色 | 含義 |
|---|---|
| 黃色 | 效率 ≥ 50 % 且 ZHR ≥ 2 |
| 橘色 | 效率 ≥ 20 % |
| 深紅色 | 效率 < 20 % |
| 灰色 | 幾乎不活躍 |

旁邊是計算文字：路徑長度和方位、中點及其仰角、Hot A / Hot B 的方位和偏角、建議的 Hot（*目前建議 …：方位 …°（佔預期反射的 …%）*）、公共區域邊界，以及提示：*流星雨最佳指向：與到達方向垂直（輻射點方位 ±90°，容差 ±40–50°，SM6FHZ）*。

## 剖面（右下）

*剖面 - 從天線朝對方電台方向看到的最可能餘跡。* 橫軸為**相對於對方電台的方位角**（← A 左，B → 右），縱軸為**仰角**。對每個流星雨取最強的 14 個反射點；每條餘跡畫成一條指向輻射點的線段，從餘跡高度以上 10 km 延伸到以下 10 km（每側最多 60 km），可能性越大線條越粗。圖中還畫出天線波瓣（以波瓣仰角為中心的 −3 dB 圓）、對方電台以及 Hot A / Hot B。

```math
Q = P \pm t_{1/2}\,\hat{s},\qquad t_{1/2} = \min\left(60\ \mathrm{km},\ \frac{10\ \mathrm{km}}{\max(0{.}17,\ |\hat{s}\cdot\hat{u}_P|)}\right)
```

*程式的選擇（手冊公式 35）。*

## 警告

| 警告 | 出現時機 |
|---|---|
| **注意：Hot A（和/或 Hot B）位於天線波瓣內 …** | 熱點位於天線方位 ±θ/2 範圍內（θ = −3 dB 水平波瓣寬度）：在此指向下它已被涵蓋。在地圖上以灰色顯示。建議的 Hot 仍為紅色。 |
| **輻射點過高（高於 70°）** | 某個有用的輻射點從本台看高於 70°：餘跡幾乎垂直下落，向路徑方向的反射很少（DF5HC、DH9GCD）。在[逐時表格](Efficiency-Calculation-zh-TW#逐時表格)中，相同的小時以 ↑ 標記。 |
| **輻射點低且沿路徑方向** | 某個活躍輻射點低於 20°，且與路徑方向相差不到 30°。計算出的效率仍然很低（保守），但 DJ5HG 預計沿路徑掠射的餘跡會產生少見而強烈的反射（漢堡–納爾維克，象限儀座流星雨，約 19 UTC）：值得一聽。 |
| **路徑超出餘跡地平線** | 在餘跡高度上，路徑中點位於兩站的地平線以下（餘跡高度 90 km 時約為 2120 km）。警告會列出所需的最低餘跡高度（2200 km 約需 96 km，2300 km 需 105 km）：只有最高的餘跡才可能通聯，效率和損耗都處於模型的極限。 |
| *沒有 E 層公共區域* | 路徑長度超過餘跡高度處涵蓋距離的兩倍：兩個電台看不到 E 層的公共部分（不可能單跳）。 |
| *無建議的 Hot* | 此時幾乎沒有活躍的流星雨。 |
