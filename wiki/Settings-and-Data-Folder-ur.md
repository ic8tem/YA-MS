## رنگ سکیمیں

**تھیم** فہرست میں 12 سکیمیں ہیں، مصنف کے EME پروگرام YAEC والی، نیز YA-MS کی اصل رنگ پٹی:

| سکیم | تفصیل |
|---|---|
| **روشن** | پہلے سے طے شدہ |
| **رات** | گہرے نیلے رنگ، رات میں استعمال کے لیے |
| **سیاہ** | سیاہ پس منظر، اندھیرے اور OLED اسکرینوں کے لیے |
| پیسٹل ہلکا نیلا · پیسٹل نارنجی · پیسٹل آبی سبز · پیسٹل سبز · پیسٹل گلابی · پیسٹل بنفشی · پیسٹل نیلگوں · پیسٹل بھورا | آٹھ ہلکی پیسٹل سکیمیں |
| **شہابی لکیر** | YA-MS کا اصل انداز (ورژن 1.2.0 تک): رات کا بنفشی، ہلکے نیلے، بنفشی، ہلکے سبز، پیلے اور نارنجی کے ساتھ |

سکیم تمام ٹیبوں پر لاگو ہوتی ہے اور `config.ini` میں محفوظ ہوتی ہے (کلید `tema`)۔

## فونٹ اور کنٹرول

- **فونٹ** (کنٹرول کی پہلی قطار کے آخر میں): **تمام متن** کو **100 سے 300 %** تک 10 % کے قدموں میں بڑا کرتا ہے؛ لکیریں، دائرے اور نقشے اپنا سائز برقرار رکھتے ہیں۔ بڑے فونٹ کے ساتھ ٹیب دوسری لائن پر چلے جاتے ہیں اور کارڈ بڑے ہو جاتے ہیں۔
- **کنٹرول**: بڑے فونٹ یا چھوٹی اسکرین پر کنٹرول کی تین قطاریں سمیٹ کر نقشوں اور گرافوں کے لیے جگہ بنائیں۔ حالت یاد رکھی جاتی ہے۔

## ڈیٹا فولڈر

تمام ڈیٹا اور ترتیبات ایک ہی **`data`** فولڈر میں ہیں، **پروگرام کے ساتھ** – نہ AppData، نہ سسٹم فولڈر:

| سسٹم | پروگرام | ڈیٹا |
|---|---|---|
| Windows (انسٹالر) | `C:\YA-MS\YA-MS.exe` | `C:\YA-MS\data` |
| Windows (پورٹیبل) | جہاں آپ نے نکالا | `YA-MS.exe` کے ساتھ `data` |
| Linux | `~/YA-MS/YA-MS` | `~/YA-MS/data` |
| macOS | `~/YA-MS/YA-MS.app` | `~/YA-MS/data` (ایپ کے ساتھ) |

آغاز پر پروگرام ضرورت ہو تو فولڈر بناتا ہے اور صرف **غائب** ابتدائی فائلیں کاپی کرتا ہے: آپ کی بدلی ہوئی فائلیں کبھی اوور رائٹ نہیں ہوتیں۔ `data/lingue` کی ترجمہ فائلیں پروگرام کی فائلیں ہیں اور نئے ورژن کی فائلیں زیادہ تازہ ہوں تو بدل دی جاتی ہیں۔

### وہ فائلیں جن میں آپ ترمیم کر سکتے ہیں

| فائل | مواد |
|---|---|
| `sciami.csv` | شہابی بارشوں کی فہرست (IMO قدریں اور عملی قدریں)؛ دیکھیں [شہابی بارشیں](Showers-ur#فہرست-میں-ترمیم) |
| `massimi_imo.csv` | IMO کی شائع کردہ عروج کی تاریخیں اور اوقات (2026، 2027): **نئے سال یہاں شامل کریں** |
| `ant_radiante.csv` | اینٹی ہیلیئن ماخذ کا مقام (IMO جدول 6) |
| `fonti_radar.csv` | ریڈار کے پتے؛ `attivo=1` ڈاؤن لوڈ کرتا ہے، `0` نظرانداز کرتا ہے |
| `regole_sperimentali.csv` | استعمال شدہ مستقلات اور اصول، ہر ایک اپنے ماخذ کے ساتھ (حوالہ) |
| `lingue/<code>.txt` | انٹرفیس کے ترجمے؛ دیکھیں [تعاون](Contributing-and-Contacts-ur#ترجمے) |
| `config.ini` | ترتیبات (نیچے دیکھیں) |

## config.ini

سادہ متن، ہر لائن میں ایک `key=value` (`#` یا `;` سے شروع ہونے والی لائنیں تبصرے ہیں)۔ پروگرام بند ہوتے وقت اسے لکھتا ہے، اس لیے **YA-MS بند کر کے ترمیم کریں**۔ وہ کلیدیں جو آپ جاننا چاہیں گے:

| کلید | پہلے سے طے شدہ | مطلب |
|---|---|---|
| `mio_locator`، `mia_quota_m` | JN70CN، 62 | آپ کا لوکیٹر اور اونچائی (m) |
| `dx_locator`، `dx_quota_m` | JO62QM، 50 | DX اسٹیشن کا لوکیٹر اور اونچائی (m) |
| `banda_MHz` | 144 | بینڈ (28، 50، 70، 144، 222، 432) |
| `quota_scie_km`، `quota_da_radar` | 90، 1 | لکیروں کی اونچائی (km)؛ 1 = Collm کا موڈ استعمال کریں |
| `elevazione_lobo_gradi` | 0 | لوب کا ارتفاع (°) |
| `boom_m` | 4.6 | Yagi بوم کی لمبائی (m) |
| `hot_spot_km` | 150 | وسطی نقطے سے Hot A / Hot B کا فاصلہ (30–400 km) |
| `lingua` | سسٹم / `it` | زبان کا کوڈ (اوپر دیے گئے 36 کوڈز میں سے ایک، مثلاً `it`، `en`، `de`) |
| `tema` | `chiaro` | رنگ سکیم: `chiaro` (روشن)، `scuro` (رات)، `nero` (سیاہ)، `pastello-azzurro`، `pastello-arancione`، `pastello-acquamarina`، `pastello-verde`، `pastello-rosa`، `pastello-lilla`، `pastello-indaco`، `pastello-marrone`، `scia` (شہابی لکیر) |
| `carattere_pct` | 100 | فونٹ کا سائز (100–300 %) |
| `comandi_visibili` | 1 | 1 = کنٹرول کی قطاریں دکھائی گئیں، 0 = سمیٹی گئیں |
| `mostra_mappa`، `vista_alto` | 1، 1 | یورپ کا نقشہ، آسمانی گنبد میں اوپر سے منظر |

| `prev_frequenza_MHz`، `prev_esponente`، `prev_fattore_stazione` | 144، 3، 1 | تجرباتی پیش گوئی: فریکوئنسی، k، K |
| `rmob_osservatore` | خالی | RMOB مشاہد کا نام |
| `rmob_automatico` | 0 | خودکار RMOB ڈاؤن لوڈ (صرف RMOB کی اجازت سے فعال کریں) |

## رازداری

YA-MS کوئی ڈیٹا جمع نہیں کرتا اور کوئی اشتہار نہیں دکھاتا۔ یہ انٹرنیٹ سے صرف عوامی ڈیٹا ڈاؤن لوڈ کرنے کے لیے جڑتا ہے: Collm اور Sodankylä ریڈار کی تصاویر، Natural Earth نقشہ (پہلی بار چلانے پر) اور، اگر آپ کہیں، ایک RMOB فائل۔
