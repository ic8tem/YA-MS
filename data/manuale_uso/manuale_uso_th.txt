TITLE|คู่มือการใช้งาน YA-MS
SUB|รุ่น 1.8.1 - จัดทำโดย Costantino IC8TEM - พฤศจิกายน 2026
H1|1. บทนำ
H2|1.1 YA-MS ใช้ทำอะไร
P|YA-MS ช่วยพยากรณ์และติดตามสภาวะ meteor scatter แบบสดระหว่างสถานีของคุณกับสถานีคู่ติดต่อ ตั้งแต่ 28 ถึง 432 MHz สำหรับฝนดาวตกแต่ละกลุ่มที่กำลังเกิดขึ้น โปรแกรมจะบอกว่าตำแหน่งจุดเรเดียนต์เอื้อต่อเส้นทางของคุณมากเพียงใด (ประสิทธิภาพ) ในช่วงเวลาใด การสะท้อนมาจากด้านใดของเส้นทาง และควรชี้สายอากาศไปทางใด นอกจากการพยากรณ์แล้ว โปรแกรมยังแสดงข้อมูลที่วัดได้แบบสด ได้แก่ จำนวนนับของเรดาร์ดาวตก Collm กล้องของ Global Meteor Network เรดาร์ CMOR เครื่องส่ง GRAVES และทราฟฟิก meteor scatter ที่รวบรวมจากคลัสเตอร์และจาก PSKReporter
P|โปรแกรมนี้ใช้งานได้ฟรี ทำงานบน Windows, Linux (รวมถึง Raspberry Pi) และ macOS และได้รับการแปลเป็น 36 ภาษา โปรแกรมไม่ได้ควบคุมวิทยุหรือโรเตเตอร์ สำหรับการติดต่อให้ใช้โปรแกรมโหมดดิจิทัลที่ใช้อยู่ตามปกติ (MSHV, WSJT-X)
H2|1.2 วิธีอ่านคู่มือนี้
P|คู่มือนี้อธิบายแท็บทีละแท็บ โดยเริ่มจากการคำนวณพยากรณ์ แต่ละบทจะบอกว่าแท็บนั้นแสดงอะไร การควบคุมแต่ละตัวทำอะไร และจะอ่านผลลัพธ์อย่างไร บทที่ 14 รวบรวมขั้นตอนที่ใช้บ่อยที่สุด บทที่ 15 รวบรวมปัญหาที่พบบ่อย วิธีคำนวณประสิทธิภาพ พร้อมแหล่งอ้างอิงและการตรวจสอบ อธิบายไว้ในเอกสาร "คำอธิบายการคำนวณประสิทธิภาพ" ส่วนสมการฉบับสมบูรณ์อยู่ในคู่มือการคำนวณ (โฟลเดอร์ doc)
TAG|PROCEDURA|ขั้นตอนที่ต้องทำตามลำดับ
TAG|NOTA|ข้อมูลที่เป็นประโยชน์สำหรับการทำความเข้าใจหรือใช้งานฟังก์ชันได้ดีขึ้น
TAG|ATTENZIONE|ข้อผิดพลาดที่พบบ่อย ข้อจำกัดของการคำนวณ หรือพฤติกรรมที่ควรรู้
P|ชื่อของการควบคุมเขียนตามที่ปรากฏในโปรแกรมภาษาไทย ในภาษาอื่นการควบคุมเหล่านี้อยู่ในตำแหน่งและลำดับเดียวกัน
H1|2. การติดตั้ง การเริ่มโปรแกรม และการอัปเดต
H2|2.1 ควรดาวน์โหลดแพ็กเกจใด
P|แพ็กเกจทั้งหมดอยู่ในหน้ารุ่นที่เผยแพร่บน GitHub (github.com/ic8tem/YA-MS/releases) ไม่จำเป็นต้องติดตั้ง .NET เพราะรวมอยู่ในแพ็กเกจแล้ว
LI|Windows 64 บิต: YA-MS-<รุ่น>-windows-x64-setup.exe (ติดตั้งลงใน C:\YA-MS โดยไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ) หรือไฟล์ zip แบบพกพา ซึ่งแตกไฟล์ลงในโฟลเดอร์ใดก็ได้ สำหรับ Windows 32 บิต ใช้ไฟล์เดียวกันที่มี x86
LI|Linux (Debian, Ubuntu, Mint): แพ็กเกจ .deb ติดตั้งด้วย sudo apt install ./ya-ms_<รุ่น>_amd64.deb เมื่อเริ่มครั้งแรกโปรแกรมจะคัดลอกตัวเองไปที่ ~/YA-MS สำหรับดิสทริบิวชันอื่นใช้ไฟล์ .tar.gz แตกไฟล์แล้วเรียกใช้ด้วย ./YA-MS
LI|Raspberry Pi 3, 4, 5, 400 และ 500: แพ็กเกจ raspberry-pi-64bit (Raspberry Pi OS 64 บิต) หรือ raspberry-pi-32bit ในรูปแบบ .tar.gz หรือ .deb
LI|ระบบ Linux ARM อื่น ๆ (เช่น Slackware ARM64 หรือบอร์ด armv7l): แพ็กเกจ linux-arm64 หรือ linux-armv7l แบบ .tar.gz เหมือนกับ Linux ส่วน Linux 32 บิตบนพีซี (i686) และ FreeBSD ไม่มีให้ เพราะ .NET 8 ไม่ทำงานบนระบบเหล่านั้น
LI|Windows บน ARM (พีซีที่ใช้ Snapdragon): แพ็กเกจ windows-arm64 สำหรับ Fedora และ openSUSE: แพ็กเกจ .rpm (x86_64 หรือ aarch64) ด้วย sudo dnf install หรือ sudo zypper install ส่วน OpenBSD ก็ไม่มีให้เช่นกัน
LI|macOS: ไฟล์ .dmg สำหรับ Apple Silicon (M1 ขึ้นไป) หรือสำหรับ Intel หรือไฟล์ app.zip ลาก YA-MS.app ไปไว้ในโฟลเดอร์ของคุณเอง (เช่น ~/YA-MS) โฟลเดอร์ data จะถูกสร้างขึ้นข้างแอป
TAG|ATTENZIONE|Windows อาจแสดงข้อความ "Windows ได้ป้องกันพีซีของคุณ" ให้เลือก "ข้อมูลเพิ่มเติม" แล้วเลือก "เรียกใช้ต่อไป" บน macOS ในครั้งแรกให้เปิดแอปด้วยการคลิกขวาแล้วเลือก "เปิด" โปรแกรมนี้ไม่ได้ลงนามด้วยใบรับรองแบบเสียเงิน
H2|2.2 การเริ่มโปรแกรมครั้งแรก
P|เมื่อเริ่มโปรแกรม จะมีหน้าจอเปิดที่เป็นภาพฝนดาวตกเพอร์ซิอิดเหนือกล้อง VLT ของ ESO ปรากฏขึ้นสองสามวินาที ในการเริ่มครั้งแรก YA-MS จะเลือกภาษาของระบบหากเป็นหนึ่งใน 36 ภาษา มิฉะนั้นจะใช้ภาษาอิตาลี โปรแกรมจะดาวน์โหลดแผนที่ยุโรป (Natural Earth) ลงในโฟลเดอร์ data/mappa และแสดงเส้นทางตัวอย่าง ใช้เวลาเพียงไม่กี่นาทีในการตั้งค่าให้เข้ากับสถานีของคุณ (บทที่ 4)
H2|2.3 โฟลเดอร์ data
P|การตั้งค่าและข้อมูลทั้งหมดอยู่ในโฟลเดอร์ data เพียงโฟลเดอร์เดียวข้างโปรแกรม ไม่มี AppData ไม่มีโฟลเดอร์ระบบ หากต้องการย้าย YA-MS ไปยังคอมพิวเตอร์เครื่องอื่น เพียงคัดลอกโฟลเดอร์โปรแกรมพร้อมโฟลเดอร์ data ของมัน เนื้อหาของโฟลเดอร์นี้อธิบายไว้ในบทที่ 13
H2|2.4 การอัปเดตอัตโนมัติ
P|ตั้งแต่รุ่น 1.8.0 YA-MS จะตรวจสอบบน GitHub เองเมื่อเริ่มโปรแกรม และไม่เกินวันละครั้ง ว่ามีรุ่นใหม่ออกมาหรือไม่ หากมี หน้าต่าง "มีการอัปเดต" จะปรากฏขึ้นพร้อมรายการสิ่งใหม่และปุ่มสามปุ่ม:
LI|อัปเดตเดี๋ยวนี้: ดาวน์โหลดแพ็กเกจที่เหมาะกับระบบของคุณ แทนที่ไฟล์ของโปรแกรม เก็บโฟลเดอร์ data ไว้ และเริ่ม YA-MS ใหม่ ไฟล์ของโปรแกรมในโฟลเดอร์ data ที่รุ่นใหม่เปลี่ยนแปลงจะถูกคัดลอกไปไว้ที่ data/backup/v<รุ่นเก่า> ก่อน ส่วนไฟล์ของคุณ (การตั้งค่า คลังข้อมูล สปอต ADIF) จะไม่ถูกแตะต้อง
LI|ภายหลัง: ปิดหน้าต่าง การตรวจสอบจะทำซ้ำในวันถัดไป
LI|ข้ามรุ่นนี้: จะไม่เสนอรุ่นนั้นอีกเมื่อเริ่มโปรแกรม
P|ปุ่ม "การอัปเดต" ที่มุมขวาล่างในแถบสถานะ ใช้ตรวจสอบแบบเดียวกันด้วยตนเอง รวมถึงรุ่นที่ข้ามไปแล้ว
TAG|ATTENZIONE|การอัปเดตอัตโนมัติต้องเขียนลงในโฟลเดอร์ของโปรแกรมได้ หากเขียนไม่ได้ (เช่น โปรแกรมที่คัดลอกไว้ในโฟลเดอร์ระบบ) YA-MS จะแจ้งให้ทราบและเสนอให้เปิดหน้ารุ่นที่เผยแพร่เพื่อติดตั้งด้วยตนเอง รุ่นจนถึง 1.7.0 ไม่มีฟังก์ชันนี้ ในครั้งแรกต้องอัปเดตด้วยตนเองโดยติดตั้งทับรุ่นก่อนหน้า
TAG|NOTA|หากไม่ต้องการให้ตรวจสอบรุ่นใหม่อีก ให้เขียน controlla_aggiornamenti=0 ในไฟล์ data/config.ini
H2|2.5 ไฟล์ของโปรแกรมที่หายไป
P|เมื่อเริ่มโปรแกรม YA-MS จะตรวจสอบว่ามีไฟล์ของตนครบทุกไฟล์ (คำแปล แค็ตตาล็อก เอกสาร) หากมีไฟล์ใดหายไป เช่น หลังการคัดลอกที่ไม่สมบูรณ์ หน้าต่าง "ไฟล์ที่หายไป" จะแสดงรายการไฟล์เหล่านั้นและเสนอ "ดาวน์โหลดไฟล์ที่หายไป" จาก GitHub ในรุ่นเดียวกับโปรแกรม หรือ "ทำต่อโดยไม่มีไฟล์เหล่านี้" การตรวจสอบเดียวกันนี้จะทำซ้ำเมื่อกด "การอัปเดต"
H1|3. หน้าต่างหลัก
H2|3.1 ส่วนต่าง ๆ ของหน้าต่าง
LI|ด้านบน มีการควบคุมสามแถวที่ใช้กับทุกแท็บ ได้แก่ สถานีและย่านความถี่ ชั้น E และสายอากาศ เวลาของการคำนวณ (บทที่ 4)
LI|แถบแท็บหลัก โดยด้านขวามีปุ่ม การควบคุม ชุดสี (ธีม) และภาษา
LI|แท็บย่อย ในแถวที่มีสีอ่อนกว่า สำหรับแท็บที่มีแท็บย่อย
LI|ด้านล่าง คือแถบสถานะ ได้แก่ ข้อความของการคำนวณ คำเตือนเกี่ยวกับการเชื่อมต่อ และปุ่ม "การอัปเดต"
H2|3.2 แท็บต่าง ๆ
LI|สดและข้อมูลเรียลไทม์: ทราฟฟิกสด, ฟลักซ์เรดาร์, เรดาร์ GRAVES, การเก็บข้อมูล (บทที่ 9)
LI|การคำนวณพยากรณ์: การคำนวณพยากรณ์, เรขาคณิตและการลดทอน, การคำนวณประสิทธิภาพ, การพยากรณ์ทดลอง (บทที่ 5-8)
LI|ฝนดาวตกสด, ฝนดาวตก, แผนที่ช่องกริด (บทที่ 10-11)
LI|เอกสารทางเทคนิค แท็บสุดท้าย: คู่มือการใช้งาน, แหล่งอ้างอิง, แผนที่เรดาร์ในยุโรป, คำอธิบายการคำนวณประสิทธิภาพ (บทที่ 12)
H2|3.3 ภาษา สี แบบอักษร
LI|ภาษา: 36 ภาษา เมื่อเปลี่ยนภาษา หน้าต่างจะสร้างใหม่ในตำแหน่งเดิมและที่แท็บเดิมโดยไม่ต้องเริ่มโปรแกรมใหม่ ตัวเลขและวันที่จะเป็นไปตามภาษาที่เลือก (จุลภาคทศนิยมในภาษาอิตาลี จุดในภาษาอังกฤษ)
LI|ธีม: ชุดสี 12 แบบ สว่าง เป็นค่าเริ่มต้น กลางคืน และ ดำ เหมาะสำหรับที่มืด รอยดาวตก เป็นสไตล์ดั้งเดิมของ YA-MS
LI|แบบอักษร (ท้ายแถวการควบคุมแถวแรก): ขยายข้อความทั้งหมดตั้งแต่ 100 ถึง 300 % เมื่อใช้ตัวอักษรขนาดใหญ่ แท็บจะขึ้นบรรทัดใหม่
LI|การควบคุม: พับและเปิดการควบคุมสามแถวกลับมา เพื่อเพิ่มพื้นที่ให้แผนที่และกราฟ โปรแกรมจะจดจำตัวเลือกนี้ไว้
TAG|NOTA|การควบคุมเกือบทุกตัวมีคำแนะนำเครื่องมือ (tooltip) ให้วางเมาส์ค้างไว้เหนือการควบคุมเพื่ออ่านว่าใช้ทำอะไรและค่าเริ่มต้นมาจากแหล่งใด
H1|4. การตั้งค่าสถานีและเส้นทาง
H2|4.1 แถวที่ 1: สถานีและย่านความถี่
LI|locator ของฉัน และ ความสูง m: locator แบบ Maidenhead ของคุณ (4, 6 หรือ 8 ตัวอักษร โดยใช้จุดศูนย์กลางของช่องกริด) และความสูงของสถานีเหนือระดับน้ำทะเล
LI|สถานีคู่ติดต่อ และ ความสูง m: locator และความสูงของสถานีที่ต้องการติดต่อ
LI|ย่านความถี่ MHz: 28, 50, 70, 144, 222 หรือ 432 MHz ใช้สำหรับอัตราขยายและโลบของสายอากาศ สำหรับการลดทอนและงบประมาณลิงก์ และสำหรับการประมาณฟลักซ์
LI|คำนวณ: คำนวณเส้นทางใหม่ (การสุ่มตัวอย่างชั้น E ใช้เวลาไม่ถึงหนึ่งวินาที)
LI|ทิศสายอากาศ az: มุมแอซิมัทของสายอากาศ ชี้ไปทางสถานีคู่ติดต่อเสมอ
H2|4.2 แถวที่ 2: ชั้น E และสายอากาศ
LI|ความสูงรอยดาวตก km และ จากเรดาร์: ความสูงของรอยดาวตก เมื่อทำเครื่องหมายที่ "จากเรดาร์" จะใช้ความสูงที่พบบ่อยที่สุดซึ่งวัดโดยเรดาร์ Collm (ปกติ 88-90 km) ให้เอาเครื่องหมายออกหากต้องการพิมพ์ค่าเอง
LI|มุมเงยของโลบ °: มุมเงยของจุดสูงสุดของโลบแนวตั้งของสายอากาศคุณ สายอากาศแบบกำหนดทิศทางที่ตั้งไว้ที่ 0° ก็ยังมีโลบหลักอยู่เหนือขอบฟ้าไม่กี่องศา เนื่องจากการสะท้อนจากพื้นดิน โดยปกติ 3-8° ขึ้นอยู่กับความสูงของสายอากาศเมื่อวัดเป็นความยาวคลื่น
LI|แบบรูปสายอากาศ: เมื่อเปิด (ค่าเริ่มต้น) จุดสะท้อนจะถูกนับตามอัตราขยายแนวตั้งของสายอากาศทั้งสองฝั่ง คือเต็มที่รอบจุดสูงสุดของโลบ และลดลงเรื่อย ๆ ไปทางขอบฟ้าและไปทางด้านบน เมื่อปิด มุมเงยของโลบจะเป็นขีดจำกัดที่ชัดเจน จุดที่มองเห็นต่ำกว่านั้นจะไม่ถูกนับ
LI|สายอากาศยากิ: boom m: ความยาวของบูม ข้าง ๆ กันโปรแกรมจะแสดงความยาวเป็นจำนวนความยาวคลื่น อัตราขยาย (เส้นโค้ง DL6WU) และความกว้างของโลบที่ -3 dB ทั้งแนวนอนและแนวตั้ง หากต่ำกว่า 2 λ ค่าประมาณจะไม่ค่อยแม่นยำ
LI|Hot spot จากจุดกึ่งกลาง km และ อัตโนมัติ (AMS): ระยะของ Hot A และ Hot B จากจุดกึ่งกลาง เมื่อทำเครื่องหมายที่ "อัตโนมัติ (AMS)" จะใช้ตารางของ J. Richardson ที่ DJ5HG อ้างถึง (เบี่ยง 13° ที่ 1000 km และ 10° เมื่อเกิน 1500 km) ให้เอาเครื่องหมายออกหากต้องการพิมพ์ 30-400 km เอง (MSHV ใช้ 150 km)
TAG|ATTENZIONE|เมื่อปิด "แบบรูปสายอากาศ" และโลบอยู่ที่ไม่กี่องศา บนเส้นทางที่ยาว สถานีทั้งสองอาจไม่เห็นจุดร่วมใด ๆ ของชั้นเลย ประสิทธิภาพทั้งหมดจะมีค่าเป็น 0 และจะมีคำเตือน "ไม่มีพื้นที่ร่วม" พร้อมบอกมุมโลบหรือความสูงของรอยดาวตกที่จำเป็น ตัวอย่าง: JN70CN - JO76QP, 1791 km, โลบที่ 3°, รอยดาวตกที่ 88,5 km
H2|4.3 แถวที่ 3: เวลาของการคำนวณ
LI|เวลา: นาฬิกา UTC
LI|วันที่คำนวณ (UTC): วันที่ใช้ในการคำนวณ ใช้กับ การคำนวณพยากรณ์ ตาราง 24 ชั่วโมงของ การคำนวณประสิทธิภาพ และลำดับเหตุการณ์ของ เรดาร์ GRAVES ค่าเริ่มต้นคือวันนี้ และเมื่อถึงเที่ยงคืนจะเปลี่ยนเป็นวันใหม่ตามไปด้วย
LI|ชั่วโมง (−12 ถึง +36 h): เลื่อนเวลาของการคำนวณ ทีละ 15 นาที ข้าง ๆ จะแสดง "คำนวณสำหรับ: ตอนนี้" หรือวันที่และเวลาที่เลือก
LI|เวลาจริง: กลับไปที่เวลาปัจจุบัน
H2|4.4 การตั้งค่าสถานีของคุณ
TAG|PROCEDURA|1) พิมพ์ locator ของฉัน และความสูง 2) พิมพ์ locator และความสูงของสถานีคู่ติดต่อ หรือคลิกบนแผนที่ของ การคำนวณพยากรณ์: คลิกซ้าย = สถานีคู่ติดต่อ คลิกขวา = สถานีของคุณ 3) เลือกย่านความถี่ 4) พิมพ์ความยาวบูมและมุมเงยของโลบของสายอากาศคุณ 5) กด คำนวณ แถบสถานะจะยืนยันว่า "คำนวณเส้นทางแล้ว: ... km, สุ่มจุดสะท้อน ... จุด"
TAG|NOTA|การตั้งค่าจะถูกบันทึกใน data/config.ini เมื่อปิดโปรแกรมและทุกครั้งที่คำนวณ เมื่อเริ่มโปรแกรมครั้งถัดไปคุณจะพบเส้นทางเดิม
H1|5. การคำนวณพยากรณ์
P|แท็บย่อยแรกของกลุ่ม การคำนวณพยากรณ์ แสดงในหน้าจอเดียวว่าขณะนี้รอยดาวตกที่ใช้ได้ตกอยู่ที่ใด และควรชี้สายอากาศไปทางใด ทุกอย่างอ้างอิงกับเวลาที่เลือกด้วยวันที่และแถบเลื่อนชั่วโมง
H2|5.1 แถบสรุป
P|เหนือแผนที่มีแถบหนึ่งสรุปการคำนวณสำหรับเวลานั้น ได้แก่ วันที่และเวลา ดัชนีเส้นทาง (ผลรวมของ ZHR × ประสิทธิภาพของฝนดาวตกที่กำลังเกิดขึ้น) ฝนดาวตกที่มีประโยชน์ที่สุดพร้อม ZHR และประสิทธิภาพ (รวมถึงในหน่วย dB เทียบกับค่าอ้างอิงของ DJ5HG) จำนวนฝนดาวตกที่อยู่เหนือขอบฟ้า และ Hot ที่แนะนำพร้อมมุมแอซิมัท
H2|5.2 แผนที่มุมมองด้านบน
P|ด้านซ้ายคือแผนที่ยุโรปมองจากด้านบน (ทิศตะวันออกอยู่ทางขวา) มีมาตราส่วนองศาอยู่รอบ ๆ:
LI|เส้นสีเขียว: เส้นทางจริงระหว่าง locator ทั้งสอง
LI|Hot A และ Hot B: hot spot สองจุดที่อยู่ทั้งสองข้างของจุดกึ่งกลาง สีแดง = แนะนำ สีชมพู = อยู่นอกโลบของสายอากาศ สีเทา = อยู่ในโลบแล้ว (พร้อมคำเตือน)
LI|โลบของสายอากาศ: เซกเตอร์ -3 dB รอบมุมแอซิมัทของสายอากาศ
LI|ขอบเขต A และ ขอบเขต B แสดงแบบจาง: ขอบที่ไกลที่สุดของท้องฟ้าที่สถานีทั้งสองมองเห็นได้ ไม่ใช่จุดที่ต้องชี้สายอากาศไป
LI|เส้นสีเหลือง: ทิศทางที่ฝนดาวตกที่เลือก (หรือกลุ่มที่เอื้ออำนวยที่สุด) กวาดผ่านท้องฟ้า จุดสีส้ม: ทิศชี้สายอากาศสองทิศที่ตั้งฉาก (มุมแอซิมัทของจุดเรเดียนต์ ±90°)
LI|โซน PREV วงรีสีอ่อน: บริเวณที่รอยดาวตกที่มีโอกาสมากที่สุดตกอยู่ในขณะนี้ หนึ่งวงต่อแต่ละด้านของเส้นทาง
P|คลิกซ้ายบนแผนที่ = locator ของสถานีคู่ติดต่อ คลิกขวา = locator ของสถานีคุณ เส้นทางจะคำนวณใหม่ทันที คำอธิบายสัญลักษณ์เป็นคอลัมน์ที่พับได้อยู่ทางขวาของแผนที่ ช่องทำเครื่องหมายเหนือรายการฝนดาวตกใช้เปิดและปิดทิศทางของ Hot แผนที่ยุโรป และมุมมองจากด้านบน
H2|5.3 รายการฝนดาวตก
P|สำหรับฝนดาวตกแต่ละกลุ่ม: ชื่อและรหัส IMO, ZHR ในขณะนี้, มุมแอซิมัทและมุมเงยของจุดเรเดียนต์จากสถานีของคุณ, ประสิทธิภาพสำหรับเส้นทาง, ด้านที่เด่น (A หรือ B), ทิศชี้ที่ดีที่สุด, เวลาขึ้นและตกของจุดเรเดียนต์ คลิกที่แถวหนึ่งเพื่อเลือกฝนดาวตกนั้น เส้นสีเหลืองและจุดสีส้มจะเปลี่ยนตาม
H2|5.4 ทรงกลมฟ้าขนาดเล็กและข้อความการคำนวณ
P|จุดเรเดียนต์ที่มองเห็นจากสถานีของคุณ พร้อมรหัส IMO และเส้นทางรายวันเป็นสีฟ้าอมเขียว สีเหลือง = ประสิทธิภาพอย่างน้อย 50 % และ ZHR อย่างน้อย 2 สีส้ม = อย่างน้อย 20 % สีแดงเข้ม = น้อยกว่านั้น สีเทา = แทบไม่มีกิจกรรม เส้นสีส้มที่ผ่านจุดจอมฟ้าให้ทิศทางสายอากาศที่ถูกต้อง ซึ่งตั้งฉากกับการเคลื่อนที่ของฝนดาวตก ข้าง ๆ กันคือข้อความการคำนวณ: เส้นทาง จุดกึ่งกลาง Hot ที่แนะนำพร้อมเปอร์เซ็นต์ของการสะท้อนที่คาดไว้ และขอบเขตของโซนร่วม
H2|5.5 ภาพตัดขวาง
P|ที่มุมขวาล่างคือรอยดาวตกที่มีโอกาสมากที่สุดเมื่อมองจากสายอากาศไปทางสถานีคู่ติดต่อ แกนนอนคือมุมแอซิมัทเทียบกับสถานีคู่ติดต่อ (A อยู่ซ้าย B อยู่ขวา) แกนตั้งคือมุมเงย รอยดาวตกแต่ละรอยเป็นส่วนของเส้นตรงที่ชี้ไปทางจุดเรเดียนต์ ยิ่งหนายิ่งมีโอกาสมาก นอกจากนี้ยังวาดโลบของสายอากาศ สถานีคู่ติดต่อ และ Hot ด้วย
H2|5.6 คำเตือน
LI|คำเตือน: Hot A (หรือ Hot B) อยู่ในโลบของสายอากาศ ด้วยการชี้นี้ hot spot นั้นครอบคลุมอยู่แล้ว
LI|จุดเรเดียนต์สูงเกินไป: จุดเรเดียนต์ที่มีประโยชน์อยู่สูงกว่า 70° รอยดาวตกตกลงมาเกือบแนวดิ่งและสะท้อนไปทางเส้นทางได้น้อย
LI|จุดเรเดียนต์ต่ำตามแนวเส้นทาง: ประสิทธิภาพที่คำนวณได้ยังคงต่ำ แต่ด้วยรอยดาวตกที่ลาดต่ำและอยู่ในแนวเดียวกับเส้นทาง DJ5HG คาดว่าจะมีการสะท้อนที่เกิดไม่บ่อยแต่แรง จึงคุ้มค่าที่จะรับฟัง
LI|เส้นทางเกินขอบฟ้าของรอยดาวตก: ที่ความสูงของรอยดาวตก จุดกึ่งกลางอยู่ต่ำกว่าขอบฟ้า คำเตือนจะบอกว่าต้องใช้ความสูงเท่าใด
LI|ไม่มีพื้นที่ร่วม: ไม่มีจุดใดของชั้นที่สถานีทั้งสองมองเห็นได้ คำเตือนจะบอกว่าขาดไปเท่าใดและต้องใช้อะไร
H1|6. เรขาคณิตและการลดทอน
P|รายงานแบบข้อความของเส้นทาง ซึ่งเลือกและคัดลอกได้ และทางขวาคือกราฟมุมเงยของสายอากาศตามระยะทางจากจุดสะท้อน สำหรับความสูงของรอยดาวตกสามระดับ
H2|6.1 ข้อมูลของแท็บนี้
LI|กำลังส่ง W (400), อัตราขยายสายอากาศ dBi (14; สายอากาศแบบเดียวกันทั้งสองฝั่ง), สัญญาณต่ำสุด dBm (-130), ความหนาแน่นของรอยดาวตก q = 10^14 อิเล็กตรอน/m ใช้สำหรับงบประมาณลิงก์
LI|รัศมีเริ่มต้นของรอยดาวตก: สองเท่าของ ITU (Stober 2021, ระมัดระวัง, ค่าเริ่มต้น), ITU-R P.843 หรือ ไม่รวม ยิ่งรัศมีใหญ่ ยิ่งสูญเสียมากที่ความถี่สูง
LI|ระยะเวลาของ ping ระหว่างย่าน: เชิงทฤษฎี λ² (McKinley, SM6FHZ; ระมัดระวัง, ค่าเริ่มต้น) หรือ ที่สังเกตได้ (การวัด HamSCI MSQP ของ NN4SA, เพอร์ซิอิด 2026: จาก 50 ถึง 144 MHz ping สั้นลง 1,5 เท่า แทนที่จะเป็น 8 เท่า)
H2|6.2 รายงาน
LI|เรขาคณิตของเส้นทาง: สถานีและความสูง ระยะทาง มุมแอซิมัท จุดกึ่งกลาง ความสูงของรอยดาวตก มุมเงยของสายอากาศไปยังจุดกึ่งกลาง
LI|HOT A / HOT B: locator มุมแอซิมัท ค่าเบี่ยงจากทิศทางตรง ระยะทาง และมุมเงยของ hot spot แต่ละจุด
LI|ขอบเขตโซนร่วม: ระยะที่ไปถึงได้ที่ความสูงของรอยดาวตกจนถึงขอบฟ้า โลบของสายอากาศพร้อมจุดสูงสุดและความกว้างแนวตั้ง ขอบเขต A และ ขอบเขต B อัตราขยายและโลบของยากิ
LI|การลดทอนของเส้นทาง: สำหรับจุดกึ่งกลาง Hot A และ Hot B ที่ 28, 50, 70, 144, 222 และ 432 MHz (รอยดาวตกที่ตัดผ่านระนาบของเส้นทาง ซึ่งเป็นกรณีที่ไม่เอื้ออำนวยที่สุด)
LI|งบประมาณลิงก์: กำลังส่งและ EIRP การลดทอน สัญญาณที่สายอากาศ สัญญาณต่ำสุดและค่าเผื่อ (margin) กรณีที่ดีที่สุด (รอยดาวตกอยู่ในระนาบของเส้นทาง) และค่าเผื่อเมื่อใช้การลดทอนเฉลี่ยของ OH5IY
LI|กฎเชิงทดลองระหว่างย่านความถี่: จำนวน ความแรง และระยะเวลาของการสะท้อนเทียบกับ 144 MHz, ping สูงสุดตาม IARU, ระยะเวลาที่สังเกตได้จากการวัด MSQP
TAG|NOTA|ค่าเผื่อที่เป็นบวกหมายความว่ารอยดาวตกความหนาแน่นต่ำ (underdense) โดยเฉลี่ยก็เพียงพอที่จะทำให้เส้นทางติดต่อได้ด้วยสถานีของคุณ ค่าเผื่อที่เป็นลบหมายความว่าต้องใช้รอยดาวตกที่หนาแน่นกว่าหรือดาวตกความหนาแน่นสูง (overdense) นี่เป็นเพียงการประมาณ ค่าอ้างอิงที่แท้จริงยังคงเป็นประสบการณ์บนย่านความถี่
H1|7. การคำนวณประสิทธิภาพ
P|ประสิทธิภาพบอกเป็นเปอร์เซ็นต์ว่าตำแหน่งจุดเรเดียนต์ของฝนดาวตกกลุ่มหนึ่งเอื้อให้เกิดการสะท้อนบนเส้นทางของคุณมากเพียงใด 100 % คือตำแหน่งที่เอื้ออำนวยที่สุดสำหรับเส้นทางนั้น แท็บย่อยนี้แสดงค่าเป็นรายชั่วโมงสำหรับวันที่ใน "วันที่คำนวณ" โดยใช้ค่าที่กึ่งกลางของแต่ละชั่วโมง
H2|7.1 แผงทั้งสี่
LI|เวลาที่ดีที่สุดของวัน: ชั่วโมงที่มีดัชนีเส้นทางสูงสุดและด้านที่เด่น
LI|ฝนดาวตกที่เอื้ออำนวยที่สุด: ฝนดาวตกที่มีส่วนมากที่สุด พร้อมชั่วโมง ด้าน และทิศชี้ที่ดีที่สุดสองทิศ
LI|ตอนนี้: ดัชนีและด้านในชั่วโมงนี้ และ Hot ที่แนะนำ (เฉพาะเมื่อวันที่เลือกคือวันนี้)
LI|การพยากรณ์ทดลอง: จำนวนการสะท้อนต่อชั่วโมงที่คาดไว้ตอนนี้ ในอีก 1 ชั่วโมง และในอีก 2 ชั่วโมง (บทที่ 8)
P|เมื่อแผงใดไม่มีค่า แผงนั้นจะบอกเหตุผล ได้แก่ ไม่มีพื้นที่ร่วม ไม่มีฝนดาวตกที่กำลังเกิดขึ้น หรือจุดเรเดียนต์ไม่เอื้ออำนวยตลอดทั้งวัน คำแนะนำเครื่องมือของแต่ละแผงอธิบายว่าแผงนั้นแสดงอะไร ใต้แผง เมื่อจำเป็น จะมีคำเตือน ไม่มีพื้นที่ร่วม และแถบที่อธิบายความหมายของตัวอักษร A และ B
H2|7.2 การตั้งค่าการคำนวณ
LI|ระมัดระวัง (ค่าเริ่มต้น): ความสูงของรอยดาวตกจากเรดาร์ รอยดาวตกปกติ เปิดมุม β ให้ค่าต่ำที่สุด
LI|แบบ DJ5HG: ความสูงคงที่ 102 km รอยดาวตกยาวขึ้นเมื่อจุดเรเดียนต์ต่ำ เปิดมุม β เลียนแบบโปรแกรม QTFGUI
LI|กำหนดเอง: จะถูกเลือกโดยอัตโนมัติเมื่อคุณเปลี่ยนช่องทำเครื่องหมายช่องใดช่องหนึ่งหรือความสูงด้วยตนเอง
LI|รอยดาวตกยาวขึ้นเมื่อจุดเรเดียนต์ต่ำ (DJ5HG): เมื่อจุดเรเดียนต์ต่ำ ดาวตกจะตกน้อยลง แต่รอยดาวตกยาวขึ้นและสะท้อนบ่อยขึ้น เมื่อสูงกว่าประมาณ 9° ผลทั้งสองจะหักล้างกัน
LI|มุม β ระหว่างรอยดาวตกกับเส้นทาง (McKinley แบบเต็ม) อยู่ในกรอบสีส้มที่มีข้อความ "ตัวเลือกที่มีผลมากที่สุด": เมื่อเปิด รอยดาวตกที่ตัดผ่านระนาบของเส้นทางจะมีค่าต่ำกว่ารอยที่อยู่ในระนาบ 10-15 dB และจุดเรเดียนต์ที่อยู่ในแนวเดียวกับเส้นทางจะมีผลเด่น เมื่อปิด จะใช้กฎแบบดั้งเดิม: จุดเรเดียนต์ที่ดีที่สุดสูง 15-70° และอยู่ขวางกับเส้นทาง
LI|คำตัดสินแบบดั้งเดิม: เพิ่มแถว "ดั้งเดิม" ใต้ฝนดาวตกแต่ละกลุ่ม พร้อมคำตัดสินตามกฎของนักวิทยุสมัครเล่นที่จุดกึ่งกลางของเส้นทาง: ✗ จุดเรเดียนต์อยู่ใต้ขอบฟ้า, ◐ ก้ำกึ่ง (ต่ำเกินไป สูงเกินไป หรือเกือบอยู่ในแนวเดียวกับเส้นทาง), ● ดี, ★ ดีมาก (อยู่ขวางกับเส้นทาง) ไม่เปลี่ยนแปลงการคำนวณ
TAG|ATTENZIONE|มุม β เปลี่ยนค่าบนเส้นทางยาวได้มาก: JN70CN - JO76QP (1791 km), ฝนดาวตกเจมินิดส์วันที่ 14/12/2026 ได้ 98 % เมื่อปิด β และ 13 % เมื่อเปิด β แนวคิดทั้งสองมีแหล่งอ้างอิงต่างกัน และการเปรียบเทียบครั้งแรกกับจำนวนนับของ BRAMS ยังแยกแยะไม่ได้ ให้เปรียบเทียบทั้งสองกรณีกับประสบการณ์บนย่านความถี่ เปอร์เซ็นต์เป็นค่าสัมพัทธ์กับตำแหน่งจุดเรเดียนต์ที่ดีที่สุดสำหรับเส้นทางนั้น หากต้องการเปรียบเทียบเส้นทางที่ต่างกันให้ใช้ประสิทธิภาพในหน่วย dB
H2|7.3 เชื่อถือตัวเลขได้มากเพียงใด
P|ชั่วโมงที่ดีที่สุดและด้านเป็นข้อมูลที่เชื่อถือได้มากที่สุด เพราะเปลี่ยนแปลงเพียงเล็กน้อยตามการตั้งค่าการคำนวณ ส่วนเปอร์เซ็นต์นั้นขึ้นอยู่กับตัวเลือกอย่างมาก โดยเฉพาะมุม β การเปรียบเทียบกับสปอต MSK144 จริง 181 767 รายการบน 50 MHz (HamSCI, ฝนดาวตกเพอร์ซิอิด 11-12 สิงหาคม 2025) ยืนยันรูปแบบรายชั่วโมงของดัชนีเส้นทาง แต่ก็แสดงด้วยว่าคู่สถานีใดได้ยินกันในชั่วโมงหนึ่ง ๆ ขึ้นอยู่กับดาวตกประปราย (sporadic) และกิจกรรมบนอากาศเป็นหลัก ซึ่งไม่ได้รวมอยู่ในแบบจำลอง
TAG|NOTA|ใช้โปรแกรมเพื่อเลือกชั่วโมงและด้านที่จะหันสายอากาศไป อย่าตีความเปอร์เซ็นต์ว่าเป็นความน่าจะเป็นที่การติดต่อจะสำเร็จ
H2|7.4 กราฟ
P|สำหรับฝนดาวตกไม่เกินห้ากลุ่ม: ประสิทธิภาพแสดงเป็นเส้นทึบ และสูตรของ DH9GCD แสดงเป็นเส้นประจุดสีเดียวกัน ดัชนีเส้นทางแสดงเป็นแท่งบนมาตราส่วนด้านขวา เวลาท้องถิ่นเขียนไว้ใต้เวลา UTC
H2|7.5 ตาราง 24 ชั่วโมง
LI|หนึ่งแถวสำหรับฝนดาวตกแต่ละกลุ่มที่เกิดขึ้นในวันนั้น 24 คอลัมน์สำหรับชั่วโมง UTC
LI|63A: ประสิทธิภาพ 63 % การสะท้อนส่วนใหญ่มาจากด้าน A, 41B: ด้าน B, ตัวเลขที่ไม่มีตัวอักษร: ต่ำกว่า 5 %, ช่องว่าง: ต่ำกว่า 1 %, ↑: จุดเรเดียนต์สูงกว่า 70° (สูงเกินไป), สีที่อุ่นกว่า = ประสิทธิภาพสูงกว่า
LI|A = ทางซ้ายเมื่อมองจากสถานีของคุณไปทางสถานีคู่ติดต่อ (โซน Hot A), B = ทางขวา (โซน Hot B) ควรหันสายอากาศไปทางด้านนั้น 10-30° (side-scatter)
LI|แถวสีฟ้าอ่อน DH9GCD %: สูตรทิศทางที่ดีที่สุดของ DH9GCD ใช้สำหรับเปรียบเทียบ ไม่ได้คำนึงถึงขอบฟ้าหรือโลบ
LI|แถว Σ: ดัชนีเส้นทาง ผลรวมของ ZHR × ประสิทธิภาพของฝนดาวตกทุกกลุ่มที่กำลังเกิดขึ้น
LI|แถวสีส้ม: การพยากรณ์ทดลองของจำนวนการสะท้อนต่อชั่วโมง สำหรับชั่วโมงที่มีข้อมูล
TAG|PROCEDURA|การเลือกเวลาสำหรับนัดหมายติดต่อ (sked): ตั้งวันที่ ดูแถว Σ และแผง เวลาที่ดีที่สุดของวัน ในแถวของฝนดาวตกที่เลือกให้อ่านตัวอักษร A หรือ B แล้วหันสายอากาศไปทางด้านนั้น 10-30° วางเมาส์ค้างไว้บนช่องตารางเพื่ออ่านรายละเอียดของ Hot ในชั่วโมงนั้น
H1|8. การพยากรณ์ทดลอง
P|แปลงจำนวนนับของเรดาร์ Collm (36,2 MHz) เป็นค่าประมาณจำนวนการสะท้อนต่อชั่วโมงบนย่านความถี่วิทยุสมัครเล่น (ค่าเริ่มต้น 144 MHz ตั้งแต่ 28 ถึง 1300 MHz) พยากรณ์ 24 ชั่วโมงข้างหน้าสำหรับเส้นทางของคุณ และเปรียบเทียบกับผู้สังเกต RMOB ทุกอย่างในส่วนนี้เป็นการทดลอง ตัวเลขมีไว้เพื่อเปรียบเทียบระหว่างชั่วโมงและวัน
H2|8.1 การควบคุม
LI|ความถี่ปลายทาง MHz: ความถี่ของการพยากรณ์
LI|เลขชี้กำลัง λ^k (3, SM6FHZ) และ ตัวประกอบสถานี K (1): กฎความถี่และการแก้ไขสำหรับสถานีของคุณ
LI|k จากดัชนีประชากร: เสนอค่า k จากดัชนีประชากร r ของฝนดาวตกที่กำลังเกิดขึ้น (GMN หรือหากไม่มีใช้ IMO; k = 3,75 · log10 r ถ่วงน้ำหนักด้วย ZHR) และขอให้ยืนยันก่อนนำไปใช้
LI|โหลดไฟล์ RMOB จากดิสก์ และ หาเลขชี้กำลังจากไฟล์ RMOB: อ่านไฟล์รายเดือนของ RMOB และหาค่า k จากชั่วโมงที่ตรงกับ Collm
LI|ผู้สังเกต RMOB, ดาวน์โหลด RMOB ตอนนี้ และ ดาวน์โหลดอัตโนมัติทุก 5 นาที: การดาวน์โหลดอัตโนมัติปิดอยู่ และควรเปิดเฉพาะเมื่อได้รับอนุญาตจาก RMOB
H2|8.2 ผลลัพธ์
LI|กราฟของเมื่อวานและวันนี้: จำนวนดาวตกต่อชั่วโมงที่ Collm ค่าที่แปลงไปยังความถี่ของคุณ และจำนวนนับของ RMOB หากโหลดไว้
LI|การพยากรณ์ 24 ชั่วโมงข้างหน้า: ใช้ชั่วโมงเดียวกันของวันก่อนหน้า แก้ไขตามการเปลี่ยนแปลงของดัชนีฝนดาวตกของเส้นทาง
LI|ตารางพร้อมการประเมิน: ดี ปานกลาง หรือแย่ เมื่อเทียบกับค่าเฉลี่ย 24 ชั่วโมง
TAG|NOTA|ระยะเวลาของการสะท้อนเป็นไปตามตัวเลือก "ระยะเวลาของ ping ระหว่างย่าน" ใน เรขาคณิตและการลดทอน ใน forward scatter ระยะเวลายังเพิ่มขึ้นตาม sec²φ ที่จุดกึ่งกลางของเส้นทางด้วย
H1|9. สดและข้อมูลเรียลไทม์
H2|9.1 ทราฟฟิกสด
P|แผนที่แบบ azimuthal equidistant ที่มีศูนย์กลางอยู่ที่สถานีของคุณ แสดงทราฟฟิก meteor scatter ทั้งหมดที่รวบรวมได้ สำหรับการติดต่อแต่ละครั้งจะแสดงเส้นทางด้วยสีของย่านความถี่ (28 น้ำตาล, 50 เขียว, 70 ฟ้าอมเขียว, 144 ส้ม, 222 ชมพู, 432 ม่วง) สถานีทั้งสอง และกลุ่มรอยดาวตกที่มีโอกาสมากที่สุดในชั่วโมงนั้น สปอตที่เพิ่งเข้ามาจะกะพริบเป็นเวลาหนึ่งนาที
LI|รัศมีแผนที่: 600-3500 km สปอตที่จะแสดง: 15 หรือ 30 นาทีล่าสุด ชั่วโมงล่าสุด 3 หรือ 24 ชั่วโมงล่าสุด
LI|คลิกที่เส้นทางหรือแถวในตารางเพื่อเน้นการติดต่อนั้น และแสดงจุดศูนย์กลางของกลุ่มรอยดาวตก ความสูง และขนาด
H2|9.2 ฟลักซ์เรดาร์
P|จำนวนดาวตกรายชั่วโมงและความสูงของรอยดาวตกจากเรดาร์ SKiYMET ที่ Collm (36,2 MHz) และภาพล่าสุดของเรดาร์ Sodankylä (36,9 MHz)
LI|ดาวน์โหลดตอนนี้ และ อัปเดตแหล่งข้อมูลทั้งหมดอัตโนมัติทุก 5 นาที: แต่ละแหล่งจะดาวน์โหลดใหม่เฉพาะเมื่อมีการเปลี่ยนแปลง
LI|เลขชี้กำลัง λ (SM6FHZ): เลขชี้กำลังของการประมาณบนย่านความถี่ของคุณ (เส้นสีส้มบนมาตราส่วนด้านขวา)
LI|ความสูงของรอยดาวตก: ฮิสโทแกรมพร้อมฐานนิยม ค่าเฉลี่ย มัธยฐาน และส่วนเบี่ยงเบนมาตรฐาน เมื่อเลือก "จากเรดาร์" ฐานนิยมจะเป็นความสูงที่ใช้ในการคำนวณทั้งหมด
TAG|ATTENZIONE|หากอ่านมาตราส่วนของกราฟ Collm ไม่ได้ จะมีคำเตือนสีส้มปรากฏขึ้นและควรตรวจสอบค่าต่าง ๆ เมื่อไม่มีการเชื่อมต่อ โปรแกรมจะใช้ข้อมูลล่าสุดที่บันทึกไว้ แจ้งให้ทราบหนึ่งครั้ง และลองใหม่เองทุก 5 นาที แถบสถานะจะเป็นสีแดงจนกว่าการเชื่อมต่อจะกลับมา
H2|9.3 เรดาร์ GRAVES
P|GRAVES ส่ง CW ที่ 143,050 MHz จาก Broye-lès-Pesmes (JN27SI) แท็บย่อยนี้ถือว่า GRAVES → คุณ เป็นเส้นทาง meteor scatter อีกเส้นทางหนึ่ง โดยคำนวณประสิทธิภาพ Hot ที่แนะนำ และโซน PREV ตรวจสอบว่าโซนอยู่ในลำคลื่นหรือไม่ และลำคลื่นจะส่องถึงเมื่อใด
LI|ตอนนี้: นำการคำนวณกลับไปที่เวลาจริง ตั้ง GRAVES เป็น DX: สถานีคู่ติดต่อจะกลายเป็น GRAVES ลำดับของลำคลื่น: 0,8 s ต่อขั้น (PE1ITR 2021) หรือ 3,2 s (2007)
LI|การ์ดต่าง ๆ: โซนที่ใช้ได้ในลำคลื่น, ประสิทธิภาพของเส้นทาง GRAVES → คุณ ตอนนี้ (พร้อมเสียงสะท้อนที่คาดไว้ เป็นการทดลอง), เส้นทาง (ควรชี้สายอากาศไปทางใด), ลำคลื่นผ่านโซนครั้งถัดไป
LI|การสร้างลำดับเหตุการณ์ของวันนั้นขึ้นใหม่ และรายละเอียดของไม่กี่วินาทีข้างหน้า
TAG|PROCEDURA|การฟัง GRAVES: USB ที่ 143,049 MHz (เสียงโทนประมาณ 1 kHz), AGC ช้าหรือปิด, แบนด์วิดท์เสียงอย่างน้อย 2,4 kHz สายอากาศชี้ไปทาง hot spot ที่แนะนำในการ์ด เส้นทาง ที่มุมเงยต่ำ นาฬิกาของพีซีต้องซิงโครไนซ์แล้ว ping จะปรากฏเป็นเส้นสั้น ๆ ใกล้คลื่นพาห์ใน waterfall
H2|9.4 การเก็บข้อมูล
P|รวบรวมสปอต meteor scatter จากสตรีม telnet สามสตรีม (DX cluster, RBN, DM4X พร้อมสปอตของ PSKReporter) และจากสตรีม MQTT ของ PSKReporter แต่ละสตรีมอยู่ในแท็บย่อยของตนเอง แล้วกรองสปอตเหล่านั้น
LI|พิมพ์นามเรียกขานของคุณที่ด้านบนเพื่อใช้ล็อกอิน แต่ละสตรีมมีโฮสต์ พอร์ต คำสั่งหลังล็อกอิน เชื่อมต่อใหม่ เชื่อมต่อเมื่อเริ่มโปรแกรม และคอนโซล
LI|ตัวกรองจะรับสปอตในความถี่ที่ใช้กันทั่วไปสำหรับ meteor scatter (50190-50300, 70100-70400, 144290-144399 kHz) หรือที่ใช้โหมด MS (MSK144, FSK441, PSK2K, JTMS, JT6M, <MS>) และทิ้งสปอตที่ระบุการแพร่กระจายแบบอื่น ช่วงความถี่และคำต่าง ๆ แก้ไขได้ และแต่ละรายการมีตัวนับของตนเอง
LI|locator ที่ขาดหายจะนำมาจากคลังข้อมูล CALL3 สปอตที่ผ่านการกรองจะถูกเก็บไว้ใน data/spot_ms วันละหนึ่งไฟล์ และแสดงบนแผนที่ของ ทราฟฟิกสด
H1|10. ฝนดาวตกสดและแค็ตตาล็อกฝนดาวตก
H2|10.1 ฝนดาวตกสด
P|ทางซ้ายคือฟลักซ์และ ZHR ที่ Global Meteor Network วัดได้สำหรับฝนดาวตกที่กำลังเกิดขึ้น พร้อมจำนวนนับรายวันจากกล้อง GMN ต่อฝนดาวตกแต่ละกลุ่ม (เป็นจำนวนนับ ไม่ใช่ฟลักซ์ ขึ้นอยู่กับว่ามีสถานีกี่แห่งที่เห็นท้องฟ้าแจ่มใส) ทางขวาคือแผนที่จุดเรเดียนต์ของเรดาร์ CMOR รวมถึงฝนดาวตกกลางวัน ไฟล์จะดาวน์โหลดใหม่เฉพาะเมื่อมีการเปลี่ยนแปลง ไม่บ่อยกว่าทุก 30 นาที หรือเมื่อกด ดาวน์โหลดตอนนี้
H2|10.2 ฝนดาวตก
P|แค็ตตาล็อกที่การคำนวณทั้งหมดใช้: ฝนดาวตกจากปฏิทิน IMO 2026 และ 2027 รวมกับ แหล่งแอนติฮีเลียน ฝนดาวตกที่เกิดขึ้นในวันนี้จะถูกเน้นไว้
LI|รหัส ชื่อ ช่วงเวลาที่เกิด ลองจิจูดสุริยะของจุดสูงสุด จุดสูงสุดครั้งถัดไป (UTC) และแหล่งที่มา (IMO หรือคำนวณ) จุดเรเดียนต์ ความเร็ว ดัชนีประชากร r, ZHR ประเภท (ทัศนวิสัยหรือวิทยุกลางวัน)
LI|k: เลขชี้กำลังของการแปลงความถี่จากดัชนีประชากร (GMN หากมี มิฉะนั้นใช้ IMO)
LI|IAU MDC: คำตอบ, Δ จุดเรเดียนต์, Δλ, Δv: การเปรียบเทียบกับแค็ตตาล็อกของ IAU Meteor Data Center (คำตอบที่ตีพิมพ์และส่วนต่างของแค็ตตาล็อกในโปรแกรมจากค่ามัธยฐานของคำตอบเหล่านั้น)
LI|GMN วันนี้: วิถีโคจรที่ยืนยันแล้วในไฟล์รายวันล่าสุดของ Global Meteor Network
TAG|NOTA|แค็ตตาล็อกคือไฟล์ data/sciami.csv และจุดสูงสุดของ IMO อยู่ใน data/massimi_imo.csv ซึ่งแก้ไขได้ด้วยโปรแกรมแก้ไขข้อความ บรรทัดที่ผิดจะถูกแจ้งเมื่อเริ่มโปรแกรมและถูกข้ามไป
H1|11. แผนที่ช่องกริด
P|ช่องกริด Maidenhead ที่ติดต่อแล้ว (สีส้ม) และยืนยันแล้ว (สีเขียว QSL หรือ LoTW) ซึ่งอ่านจากไฟล์ ADIF ของล็อกของคุณ บนแผนที่ยุโรป โดยมีแท็บย่อยแยกตามย่านความถี่: 50, 70, 144, 222 และ 432 MHz
LI|โหลดไฟล์ ADIF: อ่านไฟล์ .adi หรือ .adif ไฟล์ใหม่จะแทนที่ไฟล์ก่อนหน้า ล้างหน่วยความจำ: ลบช่องกริดที่โหลดไว้
LI|ล้อเมาส์ = ซูม, ลาก = เลื่อน, เมาส์เหนือช่องกริด = QSO ของช่องกริดนั้น
TAG|NOTA|YA-MS ไม่ได้เชื่อมต่อกับ LoTW ให้ส่งออก ADIF จากโปรแกรมล็อกของคุณหรือจาก LoTW แล้วโหลดเข้ามาที่นี่
H1|12. เอกสารทางเทคนิค
LI|คู่มือการใช้งาน: เอกสารฉบับนี้
LI|แหล่งอ้างอิง: แหล่งข้อมูลทั้งหมดของโปรแกรม พร้อมการอ้างอิง
LI|แผนที่เรดาร์ในยุโรป: ตำแหน่งของ Collm, Sodankylä, GRAVES และ CMOR เมื่อเทียบกับสถานีของคุณ พร้อมท้องฟ้าที่เรดาร์แต่ละแห่งมองเห็น
LI|คำอธิบายการคำนวณประสิทธิภาพ: วิธีคำนวณประสิทธิภาพทีละขั้นตอน พร้อมป้ายกำกับ แหล่งที่มา ตรวจสอบ และ ทางเลือก
P|เอกสารจะเป็นไปตามภาษาของส่วนติดต่อผู้ใช้เมื่อมีคำแปล มิฉะนั้นจะเป็นภาษาอิตาลี "ส่งออกเป็น Word (.docx)" บันทึกสำเนาไว้ในที่ที่คุณต้องการ "เปิดใน Word" เปิดเอกสารด้วยโปรแกรมเริ่มต้น คู่มือการคำนวณซึ่งมีสมการทั้งหมดอยู่ในโฟลเดอร์ doc (ภาษาอิตาลี) และ doc/manuali (ภาษาอื่น)
H1|13. โฟลเดอร์ data และการตั้งค่า
H2|13.1 ไฟล์หลัก
LI|config.ini: การตั้งค่าทั้งหมด (ข้อความ แบบ คีย์=ค่า)
LI|lingue/: คำแปลของส่วนติดต่อผู้ใช้; mappa/: แผนที่ยุโรป
LI|sciami.csv, massimi_imo.csv, ant_radiante.csv: แค็ตตาล็อกฝนดาวตกและตำแหน่งของแหล่งแอนติฮีเลียน; regole_sperimentali.csv: กฎระหว่างย่านความถี่
LI|flusso_collm.csv, quote_collm.csv: คลังข้อมูลของเรดาร์ Collm; radar/: ภาพล่าสุด ไฟล์ RMOB และข้อมูลของแหล่งข้อมูลสด; fonti_radar.csv: ที่อยู่ของแหล่งข้อมูล ซึ่งเปิดใช้ได้ทีละรายการ
LI|cataloghi/: แค็ตตาล็อก IAU MDC; radar/diretta/: ข้อมูล GMN และ CMOR
LI|call3.txt: คลังข้อมูล locator; spot_ms/: สปอต meteor scatter ที่รวบรวมไว้; adif_quadrati.csv: ช่องกริดจาก ADIF
LI|efficienza_spiegazione.*, spiegazione/, manuale_uso.*, manuale_uso/: เอกสารทางเทคนิค
LI|backup/: สำเนาของไฟล์ที่ถูกแทนที่โดยการอัปเดต; aggiornamento/: แพ็กเกจที่ดาวน์โหลดมา (ถูกลบเมื่อเริ่มโปรแกรมใหม่)
H2|13.2 คีย์บางส่วนของ config.ini
LI|controlla_aggiornamenti=0: ไม่ตรวจสอบรุ่นใหม่; aggiornamenti_salta: รุ่นที่ข้ามไป
LI|lobo_diagramma, angolo_beta, lunghezza_scie, giudizio_classico: ช่องทำเครื่องหมายของการคำนวณ
LI|raggio_iniziale (0 = สองเท่าของ ITU, 1 = ITU, 2 = ไม่รวม), durata_ping (0 = λ², 1 = ที่สังเกตได้)
LI|rmob_osservatore, rmob_automatico, rmob_url: การตั้งค่า RMOB
TAG|ATTENZIONE|แก้ไข config.ini เฉพาะเมื่อปิดโปรแกรมแล้วเท่านั้น เพราะเมื่อปิด YA-MS จะเขียนไฟล์นี้ใหม่
H1|14. ขั้นตอนที่ใช้บ่อย
H2|14.1 การเตรียมนัดหมายติดต่อ (sked) ในช่วงฝนดาวตก
TAG|PROCEDURA|1) ตั้งค่าสถานีทั้งสองแล้วกด คำนวณ 2) ใน ฝนดาวตก ตรวจสอบจุดสูงสุดครั้งถัดไปของฝนดาวตกนั้น 3) ใส่วันที่นั้นใน วันที่คำนวณ 4) ใน การคำนวณประสิทธิภาพ ดูแถวของฝนดาวตกนั้นและแถว Σ แล้วเลือกชั่วโมงที่มีประสิทธิภาพสูงสุด 5) จดด้าน (A หรือ B) และหันสายอากาศไปทางด้านนั้น 10-30° 6) ใน เรขาคณิตและการลดทอน ตรวจสอบค่าเผื่อของงบประมาณลิงก์
H2|14.2 การติดตามเซสชันแบบสด
TAG|PROCEDURA|1) กด เวลาจริง 2) ใน การคำนวณพยากรณ์ ติดตาม Hot ที่แนะนำและโซน PREV ซึ่งอัปเดตทุกนาที 3) ใน ฟลักซ์เรดาร์ ตรวจสอบว่าเรดาร์ Collm กำลังนับดาวตกอยู่ 4) ใน ทราฟฟิกสด ดูว่าใครกำลังติดต่ออยู่และรอยดาวตกของพวกเขาตกอยู่ที่ใด
H2|14.3 การทดสอบสถานีด้วย GRAVES
TAG|PROCEDURA|1) ใน เรดาร์ GRAVES ตรวจสอบการ์ด โซนที่ใช้ได้ในลำคลื่น 2) ชี้สายอากาศตามที่การ์ด เส้นทาง ระบุ 3) ฟังในโหมด USB ที่ 143,049 MHz ในช่วงเวลาที่ลำคลื่นจะผ่านครั้งถัดไป 4) เปรียบเทียบ ping กับเสียงสะท้อนที่คาดไว้และกับผู้สังเกต RMOB
H2|14.4 การปรับเทียบการพยากรณ์ด้วย RMOB
TAG|PROCEDURA|1) ใน การพยากรณ์ทดลอง โหลดไฟล์ RMOB รายเดือนของผู้สังเกตที่อยู่บนย่านความถี่ของคุณ 2) กด หาเลขชี้กำลังจากไฟล์ RMOB และยอมรับค่า k หากมีชั่วโมงที่ตรงกันมากพอ 3) ปรับตัวประกอบสถานี K เป็นค่าที่แนะนำ
H1|15. ปัญหาที่พบบ่อย
LI|ประสิทธิภาพทั้งหมดเป็น 0: อ่านคำเตือน ไม่มีพื้นที่ร่วม หากปิด "แบบรูปสายอากาศ" ให้ลดมุมเงยของโลบลง มิฉะนั้นแสดงว่าเส้นทางอยู่เกินขอบฟ้าที่ความสูงของรอยดาวตก
LI|ค่าที่ได้ต่ำกว่าค่าของ DH9GCD หรือของรุ่นเก่ามาก: ตรวจสอบช่องทำเครื่องหมายของมุม β (บทที่ 7.2)
LI|"locator ของสถานีไม่ถูกต้อง": พิมพ์ locator ขนาด 4, 6 หรือ 8 ตัวอักษร (เช่น JN70CN หรือ JN70CN83)
LI|Hot A และ Hot B เป็นสีเทา: เมื่อสายอากาศชี้ไปทางสถานีคู่ติดต่อ ทั้งสองจุดอยู่ในโลบแล้ว จึงไม่จำเป็นต้องหันสายอากาศ
LI|ไม่มีแผนที่ยุโรป: ต้องมีการเชื่อมต่อในการเริ่มโปรแกรมครั้งแรก โปรแกรมจะลองใหม่เอง
LI|ข้อความเล็กเกินไปหรือกราฟมีพื้นที่ไม่พอ: ใช้ แบบอักษร และปุ่ม การควบคุม
LI|การผ่านของลำคลื่น GRAVES ดูเหมือนเลื่อนไป: ซิงโครไนซ์นาฬิกาของพีซีกับเซิร์ฟเวอร์ NTP บางครั้งสถานีควบคุมก็เลื่อนลำดับของลำคลื่น
LI|Linux แสดงข้อความภาษาจีนหรือญี่ปุ่นเป็นสี่เหลี่ยม: ติดตั้งฟอนต์ Noto CJK
