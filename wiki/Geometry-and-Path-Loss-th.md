# เรขาคณิตและการสูญเสียตามเส้นทาง

*แท็บ: การคำนวณการพยากรณ์ › เรขาคณิตและการสูญเสียตามเส้นทาง*

[![เรขาคณิตและการสูญเสียตามเส้นทาง](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_2.png)](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_2.png)

รายงานข้อความของเส้นทาง (เลือกข้อความได้ จึงคัดลอกได้) และทางขวาคือกราฟ **มุมเงยของสายอากาศเทียบกับระยะทางจากจุดกระเจิง** ตัวเลขในวงเล็บเหลี่ยมอ้างอิงสมการในคู่มือการคำนวณ (`doc/YA-MS_manuale_calcoli.docx`)

## ข้อมูลป้อนเข้าของแท็บนี้

| ช่อง | ค่าเริ่มต้น | การใช้งาน |
|---|---|---|
| **กำลังส่ง W** | 400 | กำลังของเครื่องส่งสำหรับงบประมาณลิงก์ |
| **อัตราขยายสายอากาศ dBi (tx = rx)** | 14 | สายอากาศเหมือนกันทั้งสองฝั่ง |
| **สัญญาณต่ำสุด dBm** | −130 | สัญญาณต่ำสุดที่ตรวจจับได้ (บทความ: สายอากาศยากิ 8 อิลิเมนต์ + ปรีแอมป์) |
| **ความหนาแน่นของรอยทาง q = 10^ … อิเล็กตรอน/m** | 14 | ความหนาแน่นเชิงเส้นของอิเล็กตรอนในรอยทางแบบ underdense |

สถานี ย่านความถี่ ความสูงของรอยทาง มุมเงยของลำคลื่น บูม และระยะของจุดร้อน มาจาก [แถวการควบคุม](Getting-Started-th#1-แถวการควบคุมสามแถว)

## ส่วนต่าง ๆ ของรายงาน

| ส่วน | เนื้อหา |
|---|---|
| **เรขาคณิตของเส้นทาง (โลกทรงกลม, R = 6372.7955 km)** | สถานีและ DX พร้อมความสูง; ระยะทาง อะซิมุท และอะซิมุทย้อนกลับ; จุดกึ่งกลาง (โลเคเตอร์และพิกัด); ความสูงของรอยทาง (*← ฐานนิยม (mode) ที่วัดโดยเรดาร์ Collm* เมื่อนำมาจากเรดาร์); มุมเงยของสายอากาศไปยังจุดกึ่งกลาง |
| **HOT A / HOT B (จุดร้อนแบบดั้งเดิม สำหรับการหันสายอากาศ)** | สำหรับแต่ละจุด: โลเคเตอร์ อะซิมุทจากคุณและค่าเยื้องจากเส้นทางตรง อะซิมุทจาก DX ระยะทาง มุมเงย |
| **ขอบเขตโซนร่วม** | ระยะที่ความสูงของรอยทางด้วยมุมเงยของลำคลื่น; ขอบเขต A / ขอบเขต B พร้อมอะซิมุท |
| สายอากาศ | บูมเป็น λ อัตราขยาย ลำคลื่นแนวนอน / แนวตั้ง; Hot A และ Hot B อยู่ภายในหรือนอกลำคลื่น |
| **การสูญเสียตามเส้นทาง (รอยทางแบบ underdense, McKinley 1961; ไม่รวมอัตราขยายสายอากาศ)** | ตารางสำหรับจุดกึ่งกลาง (ไปข้างหน้า), Hot A และ Hot B ที่ 28, 50, 70, 144, 222 และ 432 MHz |
| **งบประมาณลิงก์ (link budget) ที่ … MHz (จุดกึ่งกลาง)** | กำลังส่งและ EIRP การสูญเสียตามเส้นทาง สัญญาณที่สายอากาศ ค่าต่ำสุดที่ตรวจจับได้ **ส่วนเผื่อ**; และส่วนเผื่อเดียวกันเมื่อใช้การสูญเสียเฉลี่ยของ OH5IY |
| **กฎเชิงทดลองระหว่างย่านความถี่ (SM6FHZ, VUSHF 2025)** | จำนวน/ความแรงและระยะเวลาเทียบกับ 144 MHz; ping สูงสุดตาม IARU |

## โลเคเตอร์และเส้นทาง

โลเคเตอร์ (4, 6 หรือ 8 ตัวอักษร; จุดศูนย์กลางของช่องกริด ระบบ IARU Maidenhead) [14] ระยะทาง อะซิมุท และจุดกึ่งกลางคำนวณด้วยสูตรวงกลมใหญ่บนทรงกลมรัศมี **r = 6372.7955 km** (บทความของ Cerrotta–Sartori) [15–16] การคำนวณที่ขึ้นกับเวลาอ้างอิง **จุดกึ่งกลาง** เพราะเวลาที่ดีที่สุดอาจต่างกันได้ถึง 1.5 ชั่วโมงระหว่างปลายทั้งสองข้าง (SM6FHZ)

## มุมเงยของสายอากาศ

**แหล่งที่มา:** สูตรจากบทความของ Cerrotta–Sartori (รูปที่ 7) โดย x = d/r, d คือระยะทางบนพื้นถึงจุดสะท้อน H คือความสูงของรอยทาง และ h คือความสูงของสถานี [17]:

```
e = 90° − 57.3 · arctan[ ( r·tan x + (H − r(1 − cos x)/cos x)·sin x ) / ( H − r(1 − cos x)/cos x − h·sin x ) ]
```

**การตรวจสอบ:** ตรงกับเรขาคณิตทรงกลมที่แม่นยำภายใน 0.03° โปรแกรมใช้อาร์กแทนเจนต์แบบสองอาร์กิวเมนต์ ซึ่งให้ค่าติดลบเมื่อเลยขอบฟ้าและหลีกเลี่ยงปัญหาคาบซ้ำที่กล่าวไว้ในบทความ มุมเงยติดลบไปยังจุดกึ่งกลางหมายความว่า *เส้นทางเกินระยะเชิงเรขาคณิตของการสะท้อนครั้งเดียว (single hop)*

## ระยะถึงขอบฟ้า

ระยะทางบนพื้นที่รังสีซึ่งมีมุมเงย e ไปถึงความสูง H (ผกผันเชิงเรขาคณิตของสูตรข้างต้น) [18]:

```
d_H = r · [ π/2 − e − arcsin( (r + h)·cos e / (r + H) ) ]
```

**การตรวจสอบ:** H = 89.5 km, e = 0° → **1062 km** ในตัวอย่างของบทความ (JN44BB–IO53RT) ภาพวาดวางจุดตัดขอบฟ้าไว้ห่างจากสถานีประมาณ 870 km ซึ่งตรงกับลำคลื่นที่ยกขึ้นประมาณ 2° (865 km)

## ขอบเขตโซนร่วม

**แหล่งที่มา:** บทความระบุตำแหน่งจุดตัดของเส้นโค้งที่ขอบฟ้าของแต่ละสถานีบรรจบกับชั้น E: คือจุดตัดของวงกลมสองวงที่มีรัศมีเชิงมุม ρ = d_H/r ซึ่งมีศูนย์กลางที่ A และ B [19–20]:

```
p0 = cos ρ / (1 + û_A·û_B) · (û_A + û_B)
p_A,B = p0 ± sqrt( (1 − |p0|²) / |û_A × û_B|² ) · (û_A × û_B)
```

หาก 1 − |p0|² < 0 เส้นทางจะยาวกว่า 2·d_H และสถานีทั้งสอง **ไม่เห็นโซนร่วมในชั้น E**

**การตรวจสอบ:** จุดเหล่านี้คือ **ขอบที่ไกลที่สุด** ของท้องฟ้าที่ทั้งสองสถานีมองเห็น **ไม่ใช่จุดสำหรับเล็งสายอากาศ** บนเส้นทาง JN70CN–IN78UO (1710 km อะซิมุท 308°) จุดเหล่านี้อยู่ห่างจากสถานี 1062 km เยื้องไปทางซ้ายและขวาของเส้นทางตรง 37° ขณะที่ MSHV แนะนำ 10° นี่คือเหตุผลที่เรียกว่า *ขอบเขต A* / *ขอบเขต B* และวาดเป็นสีจาง ๆ บนแผนที่

## Hot A และ Hot B

**แหล่งที่มา:** การสะท้อนรวมตัวกันในสองโซน ("จุดร้อน") ห่างประมาณ **50–150 km ทั้งสองข้างของจุดกึ่งกลาง** นี่คือพื้นฐานของตารางค่าเยื้องสายอากาศใน AMS Bulletin No. 203 ซึ่ง W8WN นำมาใช้ต่อ (เยื้อง 10° สำหรับเส้นทาง 1500 และ 1800 km); MSHV ของ LZ2HV ใช้เกณฑ์เดียวกัน

**การเลือก:** Hot A และ Hot B คือจุดที่ห่างจากจุดกึ่งกลาง M เป็นระยะ s ตั้งฉากกับเส้นทาง (s = 150 km ปรับได้ 30–400 km); A อยู่ทางซ้ายเมื่อมองจากสถานีของคุณไปยัง DX ส่วน B อยู่ทางขวา [21] ค่าเยื้องเมื่อมองจากสถานีมีค่าประมาณ [22]:

```
ΔAz_hot ≈ arctan( s / (D/2) )
```

**การตรวจสอบ:** JN70CN–IN78UO, D = 1710 km: 6.7° เมื่อ s = 100 km, **10.0° เมื่อ s = 150 km** (เท่ากับ MSHV และ AMS/W8WN), 13.2° เมื่อ s = 200 km

## การสูญเสียตามเส้นทางแบบ underdense

**แหล่งที่มา:** สมการของ McKinley สำหรับรอยทางแบบ underdense (β = 0, sin α = 1) ไม่รวมอัตราขยายสายอากาศ; q = ความหนาแน่นเชิงเส้นของอิเล็กตรอน, r_e = รัศมีคลาสสิกของอิเล็กตรอน = 2.818·10⁻¹⁵ m, R1, R2 คือระยะทางจากรอยทาง, φ คือครึ่งหนึ่งของมุมกระเจิง [36]:

```
L = 10·log10[ 16·π²·R1·R2·(R1 + R2)·cos²φ / ( λ³·q²·r_e² ) ]   dB
```

**การตรวจสอบ:** เมื่อ q = 10¹⁴ อิเล็กตรอน/m ที่ 144 MHz: **181–192 dB** ระหว่าง 600 ถึง 2200 km สอดคล้องกับค่าอ้างอิงในบทความที่ 144 MHz: **ต่ำสุด 182 dB** (GM8JBJ จาก Kaiser & Closs 1952) และ **เฉลี่ย 200 dB** (OH5IY)

## งบประมาณลิงก์

```
P_rx = P_tx(dBm) + G_tx − 2.15 − L + G_rx − 2.15        margin = P_rx − P_min,   P_min = −130 dBm
```

[37–38] อัตราขยายป้อนเป็น dBi และใช้เป็น dBd (dBi − 2.15) รายงานยังให้ส่วนเผื่อเมื่อใช้ **การสูญเสียตามเส้นทางเฉลี่ยของ OH5IY** (200 dB ที่ 144 MHz ปรับสเกลด้วย λ³ ไปยังย่านความถี่ที่เลือก) ค่าอ้างอิงในบทความ: ต้องใช้ประมาณ **70 dBm EIRP** (−130 dBm + 200 dB เช่น ประมาณ 400 W เข้าสายอากาศ 14 dBi)

## อัตราขยายและลำคลื่นของสายอากาศ

**อัตราขยาย – แหล่งที่มา:** เส้นโค้งของ Günter Hoch **DL6WU** สำหรับสายอากาศยากิแบบยาวเป็นฟังก์ชันของความยาวบูม L ตามที่ W8IO รายงาน (ใช้ได้ตั้งแต่ประมาณ 2 λ) [39]:

```
G = 7.773 · log10(L/λ) + 11.43   dBi
```

**ตรวจสอบเทียบกับแบบจำลอง NEC ของ L.B. Cebik W4RNL ที่ 432 MHz** (*Appreciating DL6WU Wide-Band Long-Boom Yagi Design*; *70-CM Yagi Stacks Part 2*):

| สายอากาศยากิ | อิลิเมนต์ | บูม (λ) | W4RNL NEC (dBi) | สูตร (dBi) |
|---|---|---|---|---|
| DL6WU | 13 / 22 / 31 | 3.23 / 6.82 / 10.42 | 15.28 / 17.82 / 19.35 | 15.38 / 17.91 / 19.34 |
| VK3AUU (David Tanner) | 16 / 28 / 40 | 3.12 / 6.88 / 10.79 | 15.17 / 17.91 / 19.46 | 15.27 / 17.94 / 19.45 |

ความต่างไม่เคยเกิน **0.1 dB**: อัตราขยายขึ้นกับความยาวบูมมากกว่าการออกแบบ (สายอากาศยากิของ VK3AUU มีบูมสั้นกว่าเมื่อมีจำนวนอิลิเมนต์เท่ากัน) Yagi Calculator ของ VK5DJ ยังให้ค่าประมาณสำหรับแบบ VK3AUU, WA2PHW และ DJ9BV ซึ่งไม่ได้เผยแพร่สูตรไว้

**ลำคลื่น – แหล่งที่มา:** กฎของ Kraus โดยใช้ลำคลื่นวงกลม θE = θH = θK [40]:

```
G_lin = 41253 / (θE · θH)   ⇒   θK = sqrt( 41253 / 10^(G/10) )
```

**การตรวจสอบ:** แบบจำลอง NEC ของ W4RNL สำหรับสายอากาศยากิ DL6WU ให้ **ลำคลื่นแนวนอนแคบกว่า** Kraus **5–10 %**: 33.8° / 26.4° / 22.6° สำหรับ 12, 19 และ 26 อิลิเมนต์ เทียบกับ 37.3° / 28.0° / 23.9° สูตรอย่างง่ายไม่คำนึงถึงโลบข้างด้านหน้า (W4RNL, *Long-Boom Yagi Rules of Thumb*) บนบูมยาว ลำคลื่นแนวตั้งกว้างกว่าแนวนอนเล็กน้อย (14 λ: 18.4° / 18.8°)

**การเลือก** [41]:

```
θ_horizontal = 0.93 · θK        θ_vertical = θK
```

ตัวอย่าง: สายอากาศยากิ 14 λ ที่ 432 MHz → 20.3 dBi ลำคลื่น 18.1° แนวนอน และ 19.5° แนวตั้ง; แบบจำลองของ W4RNL ให้ 20.4 dBi และ 18.4° / 18.8° สิ่งเหล่านี้เป็นกฎโดยประมาณที่ได้จากสายอากาศ DL6WU ไม่กี่ต้น

สายอากาศถือว่าหันไปยัง DX เสมอ จุดร้อนจะอยู่ **ภายในลำคลื่น** หาก |Az(Hot) − Az(antenna)| ≤ θ_horizontal/2: จากนั้นจะวาดเป็นสีเทาบน [โดมท้องฟ้า](Sky-View-th) และมีคำเตือนปรากฏขึ้น ในการคำนวณประสิทธิภาพ สายอากาศเป็นแบบไอโซทรอปิก; ลำคลื่นจริงใช้เฉพาะสำหรับการตรวจสอบนี้

## กฎเชิงทดลองระหว่างย่านความถี่

เทียบกับ 144 MHz: จำนวน/ความแรง × (144/f)³ (เป็น dB), ระยะเวลา × (144/f)² (SM6FHZ, VUSHF 2025) ระยะเวลา ping สูงสุดตาม IARU Region 1: 1000 ms ที่ 50 MHz, 500 ms ที่ 70 MHz, 100 ms ที่ 144 MHz, 13 ms ที่ 432 MHz (VHF Handbook อ้างในบทความ) ดูเพิ่มเติมที่ [การพยากรณ์เชิงทดลอง](Experimental-Forecasts-th)
