TITLE|YA-MS ユーザーマニュアル
SUB|バージョン 1.8.3 - Costantino IC8TEM 編 - 2026 年 11 月
H1|1. はじめに
H2|1.1 YA-MS の用途
P|YA-MS は、自局と相手局のあいだの流星散乱（meteor scatter）のコンディションを、28 MHz から 432 MHz まで予測し、リアルタイムで追跡するためのプログラムです。活動中の各流星群について、その放射点の位置があなたのパスにどれだけ有利か（効率）、それがどの時間帯か、パスのどちら側から反射が来るか、アンテナをどこに向けるとよいかを示します。予測と並べて、リアルタイムの実測データも表示します。Collm 流星レーダーのカウント、Global Meteor Network のカメラ、CMOR レーダー、GRAVES 送信所、そして DX クラスターと PSKReporter から集めた流星散乱のトラフィックです。
P|このプログラムは無料で、Windows、Linux（Raspberry Pi を含む）、macOS で動作し、36 の言語に翻訳されています。無線機やローテーターは制御しません。交信には、いつものデジタルモード用プログラム（MSHV、WSJT-X）を使います。
H2|1.2 本マニュアルの読み方
P|本マニュアルでは、予測計算から始めて、タブを 1 つずつ説明します。各章では、そのタブに何が表示されるか、各コマンドが何をするか、結果をどう読むかを説明します。第 14 章によく使う手順を、第 15 章によくある問題をまとめています。効率の計算方法は、出典と検証も含めて「効率の計算の説明」という資料で説明しています。完全な数式は計算マニュアル（doc フォルダー）にあります。
TAG|PROCEDURA|順番に行う手順。
TAG|NOTA|機能を理解したり、うまく使ったりするのに役立つ情報。
TAG|ATTENZIONE|よくある間違い、計算の限界、または知っておくべき動作。
P|コマンド名は、日本語版のプログラムに表示されるとおりに記載しています。ほかの言語でも、位置と順序は同じです。
H1|2. インストール、起動、更新
H2|2.1 ダウンロードするパッケージ
P|すべてのパッケージは GitHub のリリースページ（github.com/ic8tem/YA-MS/releases）にあります。.NET をインストールする必要はありません。パッケージに含まれています。
LI|Windows 64 ビット: YA-MS-<バージョン>-windows-x64-setup.exe（C:\YA-MS にインストール、管理者権限は不要）、または任意のフォルダーに展開するポータブル版の zip。32 ビット版 Windows には、同じファイルの x86 版を使います。
LI|Linux（Debian、Ubuntu、Mint）: .deb パッケージを sudo apt install ./ya-ms_<バージョン>_amd64.deb でインストールします。初回起動時に、プログラムは自身を ~/YA-MS にコピーします。その他のディストリビューションでは .tar.gz を展開し、./YA-MS で実行します。
LI|Raspberry Pi 3、4、5、400、500: raspberry-pi-64bit パッケージ（Raspberry Pi OS 64 ビット）または raspberry-pi-32bit を、.tar.gz か .deb で使います。
LI|その他の ARM Linux（例: Slackware ARM64 や armv7l ボード）: linux-arm64 または linux-armv7l の .tar.gz パッケージを Linux と同様に使います。
LI|ARM 版 Windows（Snapdragon 搭載 PC）: windows-arm64 パッケージ。Fedora と openSUSE: .rpm パッケージ（x86_64 または aarch64）を sudo dnf install または sudo zypper install でインストールします。
LI|Arch、Manjaro、Arch Linux ARM: .pkg.tar.zst パッケージを sudo pacman -U でインストールします。Slackware64 と Slackware ARM64: .txz パッケージを root で installpkg します。どの Linux でも: AppImage（x86_64 または aarch64）に実行権を付けて起動します。Alpine Linux: .tar.gz の alpine-x64 または alpine-arm64 パッケージ。
LI|macOS: Apple Silicon（M1 以降）用または Intel 用の .dmg、あるいは app.zip。YA-MS.app を自分のフォルダー（例: ~/YA-MS）にドラッグしてください。data フォルダーはアプリの隣に作成されます。
TAG|ATTENZIONE|Windows では「Windows によって PC が保護されました」と表示されることがあります。「詳細情報」を選び、続いて「実行」を押してください。macOS では、初回はアプリを右クリックして「開く」を選んでください。このプログラムは有料の証明書で署名されていません。
H2|2.2 初回起動
P|起動時に、ESO の VLT の上空を流れるペルセウス座流星群の画面が数秒間表示されます。初回起動時、YA-MS はシステムの言語が 36 言語のいずれかであればその言語を、そうでなければイタリア語を選びます。また、ヨーロッパ地図（Natural Earth）を data/mappa フォルダーにダウンロードし、サンプルのパスを表示します。自局用の設定は数分で終わります（第 4 章）。
H2|2.3 data フォルダー
P|すべての設定とデータは、プログラムの隣にある 1 つの data フォルダーに保存されます。AppData もシステムフォルダーも使いません。YA-MS を別のコンピューターに移すには、プログラムのフォルダーを data フォルダーごとコピーするだけです。フォルダーの内容は第 13 章で説明します。
H2|2.4 自動更新
P|バージョン 1.8.0 から、YA-MS は起動時に（多くても 1 日 1 回）、新しいバージョンが出ていないかを GitHub で自動的に確認します。新しいバージョンがあれば、変更点と 3 つのボタンを備えた「更新があります」ウィンドウが表示されます。
LI|今すぐ更新: お使いのシステムに合ったパッケージをダウンロードし、プログラムのファイルを置き換え、data フォルダーは残したまま YA-MS を再起動します。data フォルダー内のプログラムのファイルのうち、新しいバージョンで変更されるものは、先に data/backup/v<旧バージョン> にコピーされます。あなたのファイル（設定、アーカイブ、スポット、ADIF）には手を加えません。
LI|後で: ウィンドウを閉じます。確認は翌日にもう一度行われます。
LI|このバージョンをスキップ: 起動時にそのバージョンを再び案内しなくなります。
P|ステータスバー右下の「更新」ボタンでも、同じ確認を手動で行えます。スキップしたバージョンも対象になります。
TAG|ATTENZIONE|自動更新には、プログラムのフォルダーに書き込めることが必要です。書き込めない場合（たとえばプログラムをシステムフォルダーにコピーした場合）、YA-MS はその旨を表示し、手動でインストールするためにリリースページを開くよう提案します。バージョン 1.7.0 までにはこの機能がありません。最初の 1 回は、前のバージョンの上に手動でインストールして更新してください。
TAG|NOTA|新しいバージョンの確認をやめるには、data/config.ini ファイルに controlla_aggiornamenti=0 と書いてください。
H2|2.5 プログラムのファイルが不足している場合
P|起動時に YA-MS は、自身のファイル（翻訳、カタログ、資料）がすべてそろっているかを確認します。たとえばコピーが不完全だったために不足しているファイルがあると、「不足しているファイル」ウィンドウにその一覧が表示され、プログラムと同じバージョンのファイルを GitHub から取得する「不足しているファイルをダウンロード」か、「ダウンロードせずに続行」を選べます。「更新」を押すと、同じ確認がもう一度行われます。
H1|3. メインウィンドウ
H2|3.1 ウィンドウの構成
LI|上部には、すべてのタブに共通する 3 行のコマンドがあります。局とバンド、E 層とアンテナ、計算時刻です（第 4 章）。
LI|メインタブのバー。右端に「操作」ボタン、配色（テーマ）、言語があります。
LI|サブタブ。サブタブを持つタブでは、明るい色の行に表示されます。
LI|下部のステータスバー: 計算のメッセージ、接続に関する警告、「更新」ボタン。
H2|3.2 タブ
LI|ライブとリアルタイムデータ: ライブトラフィック、レーダーフラックス、GRAVES レーダー、データ収集（第 9 章）。
LI|予測計算: 予測計算、幾何と損失、効率の計算、実験的予報（第 5〜8 章）。
LI|流星群ライブ、流星群、グリッド地図（第 10〜11 章）。
LI|技術資料（最後のタブ）: ユーザーマニュアル、出典、ヨーロッパのレーダー地図、効率の計算の説明（第 12 章）。
H2|3.3 言語、配色、フォント
LI|言語: 36 言語。言語を切り替えると、再起動せずに、同じ位置・同じタブのままウィンドウが再構築されます。数値と日付は選んだ言語の書式に従います（イタリア語では小数点にコンマ、英語ではピリオド）。
LI|テーマ: 12 種類の配色。「ライト」が初期設定で、「夜間」と「ブラック」は暗い場所向け、「流星痕」は YA-MS 本来のスタイルです。
LI|フォント（コマンド 1 行目の末尾）: すべての文字を 100〜300 % に拡大します。文字を大きくすると、タブは折り返して表示されます。
LI|操作: 3 行のコマンドを折りたたんだり再び開いたりして、地図やグラフの表示領域を広げます。選択は記憶されます。
TAG|NOTA|ほとんどのコマンドにはツールチップがあります。コマンドの上でマウスを止めると、その用途と初期値の出典が表示されます。
H1|4. 局とパスの設定
H2|4.1 1 行目: 局とバンド
LI|自局ロケーターと標高 m: 自局の Maidenhead ロケーター（4、6 または 8 文字。グリッドの中心を使います）と、局の海抜高度。
LI|相手局と標高 m: 交信相手の局のロケーターと標高。
LI|バンド MHz: 28、50、70、144、222 または 432 MHz。アンテナの利得とビーム、損失と回線計算、フラックスの推定に使われます。
LI|計算: パスを再計算します（E 層のサンプリング、1 秒未満）。
LI|アンテナ方位: アンテナの方位角。常に相手局の方向です。
H2|4.2 2 行目: E 層とアンテナ
LI|流星痕高度 km と「レーダーより」: 流星痕の高度。「レーダーより」にチェックを入れると、Collm レーダーで測定された最頻高度（通常 88〜90 km）を使います。手入力するにはチェックを外してください。
LI|ビーム仰角 °: 自局アンテナの垂直ビームの最大点の仰角。0° に固定した指向性アンテナでも、大地反射のため、主ビームは水平線より数度上にあります。通常は、波長単位で表したアンテナの高さに応じて 3〜8° です。
LI|アンテナパターン: オン（初期設定）のとき、反射点は両局のアンテナの垂直利得で重み付けされます。ビームの最大点付近では満額、水平線や上方に向かうほど小さくなります。オフのときは、ビーム仰角が明確な境界となり、それより低く見える点は数えません。
LI|八木アンテナ: ブーム長 m: ブームの長さ。その隣に、波長単位の長さ、利得（DL6WU の曲線）、水平・垂直の -3 dB ビーム幅が表示されます。2 λ 未満では推定の精度が低くなります。
LI|中間点からのホットスポット km と「自動 (AMS)」: 中間点から Hot A と Hot B までの距離。「自動 (AMS)」にチェックを入れると、DJ5HG が引用した J. Richardson の表に従います（1000 km で 13° のずれ、1500 km 超で 10°）。30〜400 km を手入力するにはチェックを外してください（MSHV は 150 km を使います）。
TAG|ATTENZIONE|「アンテナパターン」がオフでビーム仰角が数度の場合、長いパスでは両局が E 層の共通点を 1 つも見られないことがあります。このときすべての効率は 0 になり、「共通領域なし」の警告が、必要となるビーム仰角または流星痕高度とともに表示されます。例: JN70CN - JO76QP、1791 km、ビーム仰角 3°、流星痕高度 88.5 km。
H2|4.3 3 行目: 計算時刻
LI|現在時刻: UTC の時計。
LI|計算日 (UTC): 計算する日。予測計算、効率の計算の 24 時間表、GRAVES レーダーの時系列に適用されます。初期値は今日で、午前 0 時になると新しい日に切り替わります。
LI|時間 (−12〜+36 h): 計算する時刻を 15 分刻みでずらします。隣に「計算時刻: 現在」または選んだ日付と時刻が表示されます。
LI|リアルタイム: 現在の時刻に戻します。
H2|4.4 自局の設定
TAG|PROCEDURA|1) 自局ロケーターと標高を入力します。2) 相手局のロケーターと標高を入力するか、予測計算の地図をクリックします（左クリック = 相手局、右クリック = 自局）。3) バンドを選びます。4) 自局アンテナのブーム長とビーム仰角を入力します。5) 「計算」を押します。ステータスバーに「パス計算完了: ... km、反射点 ... 個をサンプリング」と表示されます。
TAG|NOTA|設定は終了時と計算のたびに data/config.ini に保存されます。次回の起動時も同じパスが表示されます。
H1|5. 予測計算
P|予測計算グループの最初のサブタブは、有効な流星痕がいまどこに現れ、どこにアンテナを向けるべきかを 1 画面にまとめて示します。すべては、日付と時間スライダーで選んだ時刻に対するものです。
H2|5.1 概要の帯
P|地図の上の帯に、その時刻の計算結果がまとめられています。日付と時刻、パス指数（活動中の流星群の ZHR × 効率の合計）、最も有効な流星群とその ZHR と効率（DJ5HG の基準に対する dB 値も）、水平線より上にある流星群の数、推奨 Hot とその方位角です。
H2|5.2 平面図
P|左側は上空から見たヨーロッパ地図（東が右）で、周囲に度の目盛りがあります。
LI|緑の線: 2 つのロケーター間の実際のパス。
LI|Hot A と Hot B: 中間点の両側にある 2 つのホットスポット。赤 = 推奨、ピンク = アンテナのビーム外、灰色 = すでにビーム内（警告あり）。
LI|アンテナのビーム: アンテナの方位角を中心とした -3 dB の扇形。
LI|限界 A と限界 B（淡い色）: 両局から見える空の最も遠い端。アンテナを向ける点ではありません。
LI|黄色の線: 選択した流星群（または最も有利な流星群）が空を掃く方向。オレンジの点: それに垂直な 2 つの向け方（放射点の方位角 ±90°）。
LI|PREV 領域（淡い楕円）: 最も可能性の高い流星痕がいま現れる場所。パスの片側に 1 つずつあります。
P|地図を左クリックすると相手局のロケーター、右クリックすると自局のロケーターになり、パスはすぐに再計算されます。凡例は地図の右側にある折りたたみ可能な列です。流星群一覧の上のチェックボックスで、Hot の方向、ヨーロッパ地図、上空からの表示をオン・オフします。
H2|5.3 流星群の一覧
P|各流星群について、名前と IMO の略号、現在の ZHR、自局から見た放射点の方位角と仰角、パスに対する効率、優勢側（A または B）、最適な向き、放射点の出と入りを表示します。行をクリックするとその流星群が選択され、黄色の線とオレンジの点がそれに追従します。
H2|5.4 小さな天球図と計算テキスト
P|自局から見た放射点を、IMO コードと 1 日の経路（シアン）とともに表示します。黄色 = 効率 50 % 以上かつ ZHR 2 以上、オレンジ = 20 % 以上、暗い赤 = それ未満、灰色 = ほぼ不活発。天頂を通るオレンジの線は、流星群の流れに直交する、正しいアンテナの方向を示します。その隣の計算テキストには、パス、中間点、予想反射の割合を添えた推奨 Hot、共通領域の限界が表示されます。
H2|5.5 断面図
P|右下には、相手局方向のアンテナから見た、最も可能性の高い流星痕が表示されます。横軸は相手局方向を基準とした方位角（左が A、右が B）、縦軸は仰角です。各流星痕は放射点の方向を向いた線分で、可能性が高いほど太く描かれます。アンテナのビーム、相手局、Hot も描かれます。
H2|5.6 警告
LI|注意: Hot A（または Hot B）がアンテナのビームに入っています。この向きでは、そのホットスポットはすでにカバーされています。
LI|放射点が高すぎる: 有効な放射点が 70° より上にあります。流星痕はほぼ垂直に落ち、パス方向への反射はわずかです。
LI|パスに沿った低い放射点: 計算上の効率は低いままですが、パスに沿ってかすめるように流れる流星痕について、DJ5HG はまれで強い反射を予測しています。聞いてみる価値があります。
LI|パスが流星痕の水平線を越えている: 流星痕の高度では、中間点が水平線の下にあります。警告には、必要となる高度が示されます。
LI|共通領域なし: E 層のどの点も両局から見えません。警告には、どれだけ足りないか、何が必要かが示されます。
H1|6. 幾何と損失
P|パスの説明テキスト（選択・コピー可能）と、右側に、反射点までの距離に対するアンテナ仰角のグラフが、3 つの流星痕高度について表示されます。
H2|6.1 このタブの入力値
LI|送信電力 W（400）、アンテナ利得 dBi（14、両端で同じアンテナ）、最小信号 dBm（-130）、流星痕密度 q = 10^14 電子/m: 回線計算に使います。
LI|流星痕の初期半径: ITU の 2 倍（Stober 2021、慎重、初期設定）、ITU-R P.843、または除外。半径が大きいほど、高い周波数での損失が大きくなります。
LI|バンド間の ping 継続時間: 理論値 λ²（McKinley、SM6FHZ、慎重、初期設定）または観測値（NN4SA による HamSCI MSQP の測定、2026 年のペルセウス座流星群: 50 MHz から 144 MHz で ping の長さは 8 分の 1 ではなく 1.5 分の 1 になる）。
H2|6.2 説明テキスト
LI|パスの幾何: 局と標高、距離、方位角、中間点、流星痕高度、中間点へのアンテナ仰角。
LI|HOT A / HOT B: 各ホットスポットのロケーター、方位角、直接方向からのずれ、距離、仰角。
LI|共通領域の限界: 流星痕高度で水平線までの到達距離、アンテナのビーム（最大点と垂直幅）、限界 A と限界 B。八木アンテナの利得とビーム。
LI|パス損失: 中間点、Hot A、Hot B について、28、50、70、144、222、432 MHz での値（流星痕がパスの面を横切る、最も不利な場合）。
LI|回線計算: 送信電力と EIRP、損失、アンテナでの信号、最小信号とマージン。最も有利な場合（流星痕がパスの面内にある場合）と、OH5IY の平均損失を用いたマージン。
LI|バンド間の経験則: 144 MHz に対する反射の数、強さ、継続時間。IARU の最大 ping。MSQP の測定による観測継続時間。
TAG|NOTA|マージンが正であれば、平均的なアンダーデンス流星痕で自局とのパスが成立することを意味します。マージンが負であれば、より高密度の流星痕かオーバーデンス流星が必要です。これは推定値であり、基準はあくまでバンドでの実際の経験です。
H1|7. 効率の計算
P|効率は、ある流星群の放射点の位置が、あなたのパスでの反射をどれだけ可能にするかを百分率で示します。100 % はそのパスにとって最も有利な位置です。このサブタブでは、「計算日 (UTC)」の日について、各時の 30 分の値を 1 時間ごとに表示します。
H2|7.1 4 つの枠
LI|本日の最良時間帯: パス指数が最も高い時間帯とその優勢側。
LI|最も有利な流星群: 最も寄与の大きい流星群と、その時間帯、側、2 つの最適な向き。
LI|現在: この時間帯の指数と側、および推奨 Hot（選んだ日が今日の場合のみ）。
LI|実験的予報: 現在、1 時間後、2 時間後に予想される 1 時間あたりの反射数（第 8 章）。
P|枠に値がない場合は、その理由が表示されます。共通領域がない、活動中の流星群がない、または 1 日を通して放射点が不利、のいずれかです。各枠のツールチップに、表示内容の説明があります。必要に応じて、枠の下に「共通領域なし」の警告と、A と B の意味を説明する帯が表示されます。
H2|7.2 計算の設定
LI|慎重（初期設定）: 流星痕高度はレーダーより、通常の流星痕、角 β オン。最も低い値になります。
LI|DJ5HG 方式: 高度は 102 km 固定、低い放射点で流星痕が長い、角 β オン。QTFGUI プログラムを再現します。
LI|カスタム: チェックボックスや高度を手動で変更すると、自動的に選択されます。
LI|低い放射点で流星痕が長い (DJ5HG): 放射点が低いと落ちてくる流星は少なくなりますが、流星痕は長くなり、反射する頻度が高くなります。約 9° より上では、2 つの効果が打ち消し合います。
LI|流星痕とパスのなす角 β (McKinley の完全式)。「最も影響の大きい選択」と書かれたオレンジの枠内にあります。オンでは、パスの面を横切る流星痕は面内にある流星痕より 10〜15 dB 低く評価され、パスに沿った放射点が優勢になります。オフでは古典的な規則に従います。最適な放射点は高さ 15〜70° で、パスに対して横向きのものです。
LI|古典的判定: 各流星群の下に「古典」の行を追加し、パスの中間点におけるアマチュア無線家の経験則による判定を示します。✗ 放射点が水平線の下、◐ 微妙（低すぎる、高すぎる、またはパスにほぼ沿っている）、● 良好、★ 最良（パスに対して横向き）。計算そのものは変わりません。
TAG|ATTENZIONE|角 β は長いパスで値を大きく変えます。JN70CN - JO76QP（1791 km）、2026 年 12 月 14 日のふたご座流星群では、β オフで 98 %、β オンで 13 % になります。2 つの考え方は出典が異なり、BRAMS のカウントとの最初の比較でもどちらとも決められません。両方の結果をバンドでの経験と比べてください。百分率はそのパスにとって最も有利な放射点の位置に対する相対値です。異なるパスを比較するには、dB 単位の効率を使います。
H2|7.3 数値をどこまで信頼できるか
P|最良の時間帯と側は最も確かな情報で、計算の設定を変えてもあまり変わりません。一方、百分率は設定、特に角 β に大きく左右されます。50 MHz での実際の MSK144 スポット 181,767 件（HamSCI、2025 年 8 月 11〜12 日のペルセウス座流星群）との比較により、パス指数の時間変化は確認されました。しかし、ある時間帯にどの局の組み合わせが聞こえるかは、主に散在流星と実際の運用状況によって決まり、これらはモデルに含まれていないこともわかりました。
TAG|NOTA|プログラムは、時間帯とアンテナを向ける側を選ぶために使ってください。百分率を交信の成功確率として読まないでください。
H2|7.4 グラフ
P|最大 5 つの流星群について、効率を実線で、DH9GCD の式を同じ色の点線で表示します。パス指数は右側の目盛りの棒グラフで表示されます。UTC 時刻の下に現地時刻が表示されます。
H2|7.5 24 時間表
LI|その日に活動する流星群ごとに 1 行、UTC の各時に対応する 24 列があります。
LI|63A: 効率 63 %、反射の大部分は A 側から。41B: B 側。空欄: 1 % 未満。↑: 放射点が 70° より上（高すぎる）。暖色ほど効率が高いことを示します。
LI|A = 自局から相手局を見て左側（Hot A の領域）、B = 右側（Hot B の領域）。アンテナをその側へ 10〜30° 振るとよいでしょう（サイドスキャッター）。
LI|水色の DH9GCD % の行: 比較用の、DH9GCD による最適方向の式。水平線もビームも考慮しません。
LI|Σ の行: パス指数。活動中のすべての流星群の ZHR × 効率の合計です。
LI|オレンジの行: 1 時間あたりの反射数の実験的予報（予報がある時間帯のみ）。
TAG|PROCEDURA|スケジュールの時刻を選ぶには、日付を設定し、Σ の行と「本日の最良時間帯」の枠を見ます。選んだ流星群の行で A または B の文字を読み取り、アンテナをその側へ 10〜30° 振ります。セルの上にマウスを置くと、その時間帯の Hot の詳細が表示されます。
H1|8. 実験的予報
P|Collm レーダー（36.2 MHz）のカウントを、アマチュアバンド（初期設定は 144 MHz、28〜1300 MHz）での 1 時間あたりの反射数の推定値に変換し、あなたのパスについて今後 24 時間の予報を出し、RMOB の観測者のデータと比較します。ここにあるものはすべて実験的なもので、数値は時間帯や日どうしの比較に使うためのものです。
H2|8.1 コマンド
LI|換算先周波数 MHz: 予報の周波数。
LI|λ^k の指数（3、SM6FHZ）と局係数 K（1）: 周波数に関する規則と、自局に合わせた補正。
LI|個数指数から k: 活動中の流星群の個数指数 r（GMN、なければ IMO。k = 3.75 · log10 r、ZHR で重み付け）から k を提案し、適用する前に確認を求めます。
LI|RMOB ファイルをディスクから読込と RMOB ファイルから指数を算出: RMOB の月間ファイルを読み込み、Collm と共通する時間帯から k を求めます。
LI|RMOB 観測者、RMOB を今すぐ取得、5 分ごとの自動取得: 自動取得はオフになっており、RMOB の許可がある場合にのみオンにしてください。
H2|8.2 結果
LI|昨日と今日のグラフ: Collm での 1 時間あたりの流星数、あなたの周波数に換算した値、読み込んだ場合は RMOB のカウント。
LI|今後 24 時間の予報: 前日の同じ時刻の値を、パスの流星群指数の変化で補正したもの。
LI|評価付きの表: 24 時間平均に対して、良好、普通、不良。
TAG|NOTA|反射の継続時間は、幾何と損失の「バンド間の ping 継続時間」の選択に従います。前方散乱では、継続時間はパスの中間点での sec²φ にも比例して長くなります。
H1|9. ライブとリアルタイムデータ
H2|9.1 ライブトラフィック
P|自局を中心とした正距方位図法の地図に、収集したすべての流星散乱トラフィックを表示します。各交信について、バンドの色のパス（28 茶、50 緑、70 シアン、144 オレンジ、222 ピンク、432 紫）、両局、その時刻に最も可能性の高い流星痕の雲が描かれます。届いたばかりのスポットは 1 分間点滅します。
LI|地図の半径: 600〜3500 km。表示するスポット: 直近 15 分または 30 分、直近 1 時間、直近 3 時間または 24 時間。
LI|パスまたは表の行をクリックすると、その交信が強調表示され、雲の中心、その高度、大きさが表示されます。
H2|9.2 レーダーフラックス
P|Collm の SKiYMET レーダー（36.2 MHz）による 1 時間ごとの流星数と流星痕高度、および Sodankylä レーダー（36.9 MHz）の最新画像。
LI|今すぐ取得と、全データソースを 5 分ごとに自動更新: 各データソースは、変更があった場合にのみ再ダウンロードされます。
LI|λ 指数 (SM6FHZ): あなたのバンドでの推定に使う指数（右側の目盛りのオレンジの線）。
LI|流星痕高度: 最頻値、平均、中央値、標準偏差を示すヒストグラム。「レーダーより」を選ぶと、最頻値がすべての計算の高度になります。
TAG|ATTENZIONE|Collm のグラフの目盛りを読み取れない場合は、オレンジの警告が表示されるので、値を確認してください。接続がない場合、プログラムは最後に保存したデータを使い、そのことを一度だけ表示して、5 分ごとに自動的に再試行します。接続が回復するまで、ステータスバーは赤になります。
H2|9.3 GRAVES レーダー
P|GRAVES は Broye-lès-Pesmes（JN27SI）から 143.050 MHz で CW を送信しています。このサブタブは、GRAVES → 自局を独立した流星散乱パスとして扱います。効率、推奨 Hot、PREV 領域を計算し、その領域がビーム内にあるか、いつビームがそこを照射するかを確認します。
LI|現在: 計算をリアルタイムに戻します。GRAVES を相手局にする: 相手局が GRAVES になります。ビームのシーケンス: 1 ステップあたり 0.8 秒（PE1ITR 2021）または 3.2 秒（2007）。
LI|カード: GRAVES のビーム内の有効ゾーン、GRAVES → 自局パスの現在の効率（予想エコー付き、実験的）、パス（アンテナを向ける方向）、ゾーン上の次のビーム通過。
LI|その日の時系列の再構成と、今後数秒間の詳細。
TAG|PROCEDURA|GRAVES を受信するには: 143.049 MHz の USB（約 1 kHz のトーン）、AGC は低速またはオフ、音声帯域幅は 2.4 kHz 以上。アンテナは「パス」カードの推奨ホットスポットに向け、仰角は低くします。PC の時計は同期させておきます。ping はウォーターフォール上で、キャリアの近くに短い線として見えます。
H2|9.4 データ収集
P|3 つの telnet フィード（DX クラスター、RBN、PSKReporter のスポットを含む DM4X）と PSKReporter の MQTT フィードから流星散乱のスポットを収集し、それぞれのサブタブでフィルターにかけます。
LI|ログイン用に、上部に自局のコールサインを入力します。各フィードには、ホスト、ポート、ログイン後のコマンド、再接続、起動時に接続、コンソールがあります。
LI|フィルターは、流星散乱で一般的な周波数（50190〜50300、70100〜70400、144290〜144399 kHz）のスポット、または MS モード（MSK144、FSK441、PSK2K、JTMS、JT6M、<MS>）のスポットを受け入れ、別の伝搬を明記しているものを除外します。周波数範囲と語句は変更でき、それぞれにカウンターがあります。
LI|不足しているロケーターは CALL3 アーカイブから補われます。受け入れたスポットは data/spot_ms（1 日 1 ファイル）と、ライブトラフィックの地図に送られます。
H1|10. 流星群ライブと流星群カタログ
H2|10.1 流星群ライブ
P|左側には、Global Meteor Network が測定した活動中の流星群のフラックスと ZHR、および流星群ごとの GMN カメラによるその日のカウントを表示します（これはカウントでありフラックスではありません。晴れた空を見ている観測局の数によって変わります）。右側には、昼間流星群を含む CMOR レーダーの放射点マップを表示します。ファイルは変更があった場合にのみ、最短 30 分ごとに、または「今すぐ取得」で再ダウンロードされます。
H2|10.2 流星群
P|すべての計算で使われるカタログ: IMO の 2026 年と 2027 年のカレンダーにある流星群と、反太陽源。今日活動している流星群は強調表示されます。
LI|略号、名前、活動期間、極大の太陽黄経、次の極大（UTC）とその出典（IMO または計算値）、放射点、速度、個数指数 r、ZHR、種類（眼視または昼間電波）。
LI|k: 個数指数から求めた周波数換算の指数（GMN があれば GMN、なければ IMO）。
LI|IAU MDC：解、Δ 放射点、Δλ、Δv: IAU Meteor Data Center のカタログとの比較（公表されている解と、それらの中央値に対するプログラムのカタログの差）。
LI|GMN 本日: Global Meteor Network の最新の日次ファイルで確認された軌道の数。
TAG|NOTA|カタログは data/sciami.csv ファイル、IMO の極大は data/massimi_imo.csv にあり、テキストエディターで編集できます。誤った行は起動時に報告され、無視されます。
H1|11. グリッド地図

H1|14. よく使う手順
H2|14.1 流星群でのスケジュールの準備
TAG|PROCEDURA|1) 両局を設定して「計算」を押します。2) 流星群タブで、その流星群の次の極大を確認します。3) その日付を計算日 (UTC) に設定します。4) 効率の計算で、その流星群の行と Σ の行を見て、効率の最も高い時間帯を選びます。5) 側（A または B）を書き留め、アンテナをその側へ 10〜30° 振ります。6) 幾何と損失で、回線計算のマージンを確認します。
H2|14.2 ライブでセッションを追う
TAG|PROCEDURA|1) 「リアルタイム」を押します。2) 予測計算で、毎分更新される推奨 Hot と PREV 領域を追います。3) レーダーフラックスで、Collm レーダーが流星をカウントしていることを確認します。4) ライブトラフィックで、誰が運用していて、その流星痕がどこに現れているかを見ます。
H2|14.3 GRAVES で局をテストする
TAG|PROCEDURA|1) GRAVES レーダーで「GRAVES のビーム内の有効ゾーン」カードを確認します。2) 「パス」カードの指示どおりにアンテナを向けます。3) 次のビーム通過の時間帯に、143.049 MHz を USB で受信します。4) ping を予想エコーや RMOB の観測者のデータと比較します。
H2|14.4 RMOB で予報を校正する
TAG|PROCEDURA|1) 実験的予報で、あなたのバンドを観測している観測者の RMOB 月間ファイルを読み込みます。2) 「RMOB ファイルから指数を算出」を押し、共通する時間帯が十分にあれば k を受け入れます。3) 局係数 K を提案された値に合わせます。
H1|15. よくある問題
LI|すべての効率が 0 になる: 「共通領域なし」の警告を読んでください。「アンテナパターン」がオフならビーム仰角を下げてください。そうでなければ、流星痕高度ではパスが水平線を越えています。
LI|値が DH9GCD や古いバージョンの値よりずっと低い: 角 β のチェックボックスを確認してください（第 7.2 節）。
LI|「自局のロケーターが無効です」: 4、6 または 8 文字のロケーターを入力してください（例: JN70CN または JN70CN83）。
LI|Hot A と Hot B が灰色: アンテナを相手局に向けた状態で、すでにビーム内に入っています。アンテナを振る必要はありません。
LI|ヨーロッパ地図が表示されない: 初回起動時にネット接続が必要です。プログラムは自動的に再試行します。
LI|文字が小さすぎる、またはグラフの表示領域が足りない: 「フォント」と「操作」ボタンを使ってください。
LI|GRAVES のビーム通過の時刻がずれているように見える: PC の時計を NTP サーバーと同期させてください。ビームのシーケンスは、管制局によってずらされることがあります。
LI|Linux で中国語や日本語の文字が四角で表示される: Noto CJK フォントをインストールしてください。
