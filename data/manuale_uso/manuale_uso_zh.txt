TITLE|YA-MS 使用手册
SUB|版本 1.8.1 - Costantino IC8TEM 编写 - 2026 年 11 月
H1|1. 引言
H2|1.1 YA-MS 的用途
P|YA-MS 帮助你预测并实时跟踪你的电台与对方电台之间 28 至 432 MHz 的流星余迹散射（meteor scatter）条件。对于每个活跃的流星雨，它会告诉你其辐射点的位置对你的路径有多有利（效率）、在哪些时段、反射从路径的哪一侧到来，以及天线最好指向哪里。在预报旁边，它还显示实时测量的数据：Collm 流星雷达的计数、Global Meteor Network 的摄像机、CMOR 雷达、GRAVES 发射机，以及从集群（cluster）和 PSKReporter 收集到的流星余迹散射通信。
P|本程序免费，可在 Windows、Linux（包括 Raspberry Pi）和 macOS 上运行，并已翻译成 36 种语言。它既不控制电台，也不控制旋转器：通联时使用常用的数字模式程序（MSHV、WSJT-X）。
H2|1.2 如何阅读本手册
P|本手册从预报计算开始，逐一介绍各个选项卡。每一章说明该选项卡显示什么、每个控件的作用以及如何解读结果。第 14 章汇集最常用的操作步骤，第 15 章汇集常见问题。效率如何计算（包括来源和核查）在文档“效率计算说明”中解释；完整的公式见《计算手册》（doc 文件夹）。
TAG|PROCEDURA|需要按顺序执行的步骤。
TAG|NOTA|有助于更好地理解或使用某项功能的信息。
TAG|ATTENZIONE|常见错误、计算的局限或需要了解的程序行为。
P|控件名称按程序中文界面中的显示方式书写；在其他语言中，它们的位置和顺序相同。
H1|2. 安装、启动与更新
H2|2.1 下载哪个软件包
P|所有软件包都在 GitHub 的发布页面上（github.com/ic8tem/YA-MS/releases）。无需安装 .NET：它已包含在软件包中。
LI|Windows 64 位：YA-MS-<版本>-windows-x64-setup.exe（安装到 C:\YA-MS，无需管理员权限），或便携版 zip，解压到任意文件夹即可。32 位 Windows 使用带 x86 的相同文件。
LI|Linux（Debian、Ubuntu、Mint）：.deb 软件包，用 sudo apt install ./ya-ms_<版本>_amd64.deb 安装；首次启动时程序会把自身复制到 ~/YA-MS。其他发行版使用 .tar.gz，解压后用 ./YA-MS 运行。
LI|Raspberry Pi 3、4、5、400 和 500：raspberry-pi-64bit 软件包（Raspberry Pi OS 64 位）或 raspberry-pi-32bit，提供 .tar.gz 或 .deb 格式。
LI|其他 ARM Linux 系统（例如 Slackware ARM64 或 armv7l 开发板）：使用 .tar.gz 格式的 linux-arm64 或 linux-armv7l 安装包，用法同 Linux。
LI|ARM 上的 Windows（Snapdragon 电脑）：windows-arm64 安装包。Fedora 和 openSUSE：.rpm 安装包（x86_64 或 aarch64），用 sudo dnf install 或 sudo zypper install 安装。
LI|Arch、Manjaro 和 Arch Linux ARM：.pkg.tar.zst 安装包，用 sudo pacman -U 安装。Slackware64 和 Slackware ARM64：.txz 安装包，以 root 身份用 installpkg 安装。任意 Linux：AppImage（x86_64 或 aarch64），设为可执行后直接运行。Alpine Linux：.tar.gz 格式的 alpine-x64 或 alpine-arm64 安装包。
LI|macOS：适用于 Apple Silicon（M1 及更新机型）或 Intel 的 .dmg，或 app.zip。将 YA-MS.app 拖到你自己的文件夹中（例如 ~/YA-MS）：data 文件夹会在应用旁边创建。
TAG|ATTENZIONE|Windows 可能显示“Windows 已保护你的电脑”：选择“更多信息”，然后选择“仍要运行”。在 macOS 上，第一次请用右键单击应用并选择“打开”。本程序没有使用付费证书签名。
H2|2.2 首次启动
P|启动时会显示几秒钟的启动画面：ESO 的 VLT 上空的英仙座流星雨。首次启动时，如果系统语言属于 36 种语言之一，YA-MS 会选择系统语言，否则选择意大利语；它会把欧洲地图（Natural Earth）下载到 data/mappa 文件夹，并显示一条示例路径。只需几分钟即可针对你的电台完成设置（第 4 章）。
H2|2.3 data 文件夹
P|所有设置和所有数据都保存在程序旁边的同一个 data 文件夹中：不使用 AppData，也不使用系统文件夹。要把 YA-MS 移到另一台计算机，只需复制程序文件夹及其 data 文件夹。该文件夹的内容在第 13 章中介绍。
H2|2.4 自动更新
P|从 1.8.0 版起，YA-MS 会在启动时自动到 GitHub 检查是否发布了新版本，每天最多一次。如果有新版本，会出现“有可用更新”窗口，显示更新内容和三个按钮：
LI|立即更新：下载适合你系统的软件包，替换程序文件，保留 data 文件夹并重新启动 YA-MS。新版本要更改的 data 文件夹中的程序文件会先复制到 data/backup/v<旧版本>；你自己的文件（设置、存档、spot、ADIF）不会被改动。
LI|稍后：关闭窗口；第二天会再次检查。
LI|跳过此版本：启动时不再提示该版本。
P|状态栏右下角的“更新”按钮可手动执行同样的检查，对已跳过的版本也有效。
TAG|ATTENZIONE|自动更新需要能够写入程序文件夹。如果无法写入（例如程序被复制到了系统文件夹中），YA-MS 会提示这一点，并建议打开发布页面手动安装。1.7.0 及更早的版本没有此功能：第一次必须手动更新，在旧版本上覆盖安装。
TAG|NOTA|如果不想再检查新版本，请在 data/config.ini 文件中写入 controlla_aggiornamenti=0。
H2|2.5 缺少程序文件
P|启动时，YA-MS 会检查自己的所有文件（翻译、星表、文档）是否齐全。如果缺少某些文件（例如复制不完整之后），“缺少的文件”窗口会列出它们，并提供“下载缺少的文件”（从 GitHub 下载与程序相同版本的文件）或“不下载，继续”。按“更新”时会再次执行同样的检查。
H1|3. 主窗口
H2|3.1 窗口的组成部分
LI|顶部是对所有选项卡都有效的三行控件：电台与波段、E 层与天线、计算时间（第 4 章）。
LI|主选项卡栏，右侧是“控制”按钮、配色方案（主题）和语言。
LI|子选项卡位于颜色较浅的一行中，仅用于带有子选项卡的选项卡。
LI|底部是状态栏：计算消息、连接警告以及“更新”按钮。
H2|3.2 选项卡
LI|实况与实时数据：实时通信、雷达流量、GRAVES 雷达、数据收集（第 9 章）。
LI|预报计算：预报计算、几何与路径损耗、效率计算、试验性预报（第 5-8 章）。
LI|实时流星雨、流星雨、方格地图（第 10-11 章）。
LI|技术文档（最后一个）：使用手册、来源、欧洲雷达地图、效率计算说明（第 12 章）。
H2|3.3 语言、颜色、字体
LI|语言：36 种语言。更改语言后，窗口会在原位置、原选项卡上重建，无需重新启动。数字和日期遵循所选语言（意大利语用逗号作小数点，英语用句点）。
LI|主题：12 种配色方案；“浅色”为默认方案，“夜间”和“黑色”适合在黑暗中使用，“流星余迹”是 YA-MS 的原始风格。
LI|字体（位于第一行控件的末尾）：将所有文字放大 100 至 300 %。字体较大时，选项卡会换行。
LI|控制：折叠和展开三行控件，为地图和图表腾出空间。该选择会被记住。
TAG|NOTA|几乎每个控件都有提示框：将鼠标停在控件上，即可看到它的用途以及默认值的来源。
H1|4. 设置电台与路径
H2|4.1 第 1 行：电台与波段
LI|我的网格坐标 和 海拔 m：你的 Maidenhead 网格坐标（4、6 或 8 个字符；使用方格的中心）以及电台的海拔高度。
LI|对方电台 和 海拔 m：要通联的电台的网格坐标和海拔。
LI|波段 MHz：28、50、70、144、222 或 432 MHz。用于天线增益和波瓣、路径损耗和链路预算，以及流量估算。
LI|计算：重新计算路径（E 层采样，不到一秒）。
LI|天线方位：天线的方位角，始终朝向对方电台。
H2|4.2 第 2 行：E 层与天线
LI|余迹高度 km 和 来自雷达：流星余迹的高度。勾选“来自雷达”时，使用 Collm 雷达测得的最常见高度（通常为 88-90 km）；取消勾选可手动输入。
LI|波瓣仰角 °：你的天线垂直波瓣最大值的仰角。固定在 0° 的定向天线，由于地面反射，其主瓣仍在地平线以上几度：通常为 3-8°，取决于以波长计的天线高度。
LI|天线方向图：开启（默认）时，反射点按两副天线的垂直增益计入：在波瓣最大值附近为全额，向地平线和向上逐渐减少。关闭时，波瓣仰角是一个硬性界限：低于该仰角看到的点不计入。
LI|八木天线：横梁 m：横梁长度。程序在旁边显示以波长计的长度、增益（DL6WU 曲线）以及水平和垂直的 -3 dB 波瓣宽度。低于 2 λ 时估算不太准确。
LI|热点距中点 km 和 自动（AMS）：Hot A 和 Hot B 到中点的距离。勾选“自动（AMS）”时，按照 DJ5HG 引用的 J. Richardson 表格（1000 km 时偏离 13°，1500 km 以上偏离 10°）；取消勾选可手动输入 30-400 km（MSHV 使用 150 km）。
TAG|ATTENZIONE|当“天线方向图”关闭且波瓣仰角为几度时，在长路径上两个电台可能看不到该层的任何公共点：所有效率均为 0，并出现“无公共区域”警告，给出所需的波瓣仰角或余迹高度。例如：JN70CN - JO76QP，1791 km，波瓣 3°，余迹 88.5 km。
H2|4.3 第 3 行：计算时间
LI|时间：UTC 时钟。
LI|计算日期（UTC）：计算的日期。适用于“预报计算”、“效率计算”中的 24 小时表格以及“GRAVES 雷达”的时间回顾。默认为今天，到午夜时自动切换到新的一天。
LI|小时（−12 至 +36 h）：以 15 分钟为步长移动计算时刻。旁边显示“计算时间：现在”或所选的日期和时间。
LI|实时：回到当前时刻。
H2|4.4 设置自己的电台
TAG|PROCEDURA|1) 输入“我的网格坐标”和海拔。2) 输入对方电台的网格坐标和海拔，或在“预报计算”的地图上单击：左键 = 对方电台，右键 = 你的电台。3) 选择波段。4) 输入你天线的横梁长度和波瓣仰角。5) 按“计算”：状态栏会确认“路径已计算：... km，采样了 ... 个反射点”。
TAG|NOTA|关闭程序时以及每次计算时，设置都会保存在 data/config.ini 中：下次启动时你会看到同一条路径。
H1|5. 预报计算
P|“预报计算”组的第一个子选项卡在一个画面中显示有用的余迹此刻落在哪里以及天线该指向哪里。所有内容都对应于用日期和小时滑块所选的时刻。
H2|5.1 摘要栏
P|地图上方的一条摘要栏概括该时刻的计算结果：日期和时间、路径指数（活跃流星雨的 ZHR × 效率之和）、最有用的流星雨及其 ZHR 和效率（也以相对于 DJ5HG 参考值的 dB 表示）、地平线以上的流星雨数量，以及推荐的 Hot 及其方位角。
H2|5.2 平面地图
P|左侧是从上方俯视的欧洲地图（东在右侧），四周有度数刻度：
LI|绿线：两个网格坐标之间的实际路径；
LI|Hot A 和 Hot B：中点两侧的两个热点。红色 = 推荐，粉色 = 在天线波瓣之外，灰色 = 已在波瓣之内（并有警告）；
LI|天线波瓣：围绕天线方位角的 -3 dB 扇区；
LI|边界 A 和边界 B（淡色）：两个电台都能看到的天空的最远边缘，不是要指向的点；
LI|黄线：所选流星雨（或最有利的流星雨）扫过天空的方向；橙色点：两个垂直方向的指向（辐射点方位角 ±90°）；
LI|PREV 区域（浅色椭圆）：此刻最可能出现余迹的位置，路径每一侧各一个。
P|在地图上左键单击 = 对方电台的网格坐标，右键单击 = 你的电台的网格坐标；路径会立即重新计算。图例是地图右侧可折叠的一栏。流星雨列表上方的复选框用于打开和关闭 Hot 方向、欧洲地图和俯视图。
H2|5.3 流星雨列表
P|每个流星雨显示：名称和 IMO 代码、此刻的 ZHR、从你的电台看辐射点的方位角和仰角、该路径的效率、主要一侧（A 或 B）、最佳指向、辐射点的升起和落下时间。单击某一行即选中该流星雨：黄线和橙色点随之更新。
H2|5.4 小天球图与计算文本
P|从你的电台看到的辐射点，标有 IMO 代码，青色为每日轨迹。黄色 = 效率至少 50 % 且 ZHR 至少 2；橙色 = 至少 20 %；深红色 = 更低；灰色 = 几乎不活跃。穿过天顶的橙线给出正确的天线方向，与流星雨的扫过方向正交。旁边是计算文本：路径、中点、推荐的 Hot 及预期反射的百分比、公共区域的边界。
H2|5.5 剖面图
P|右下方显示从天线朝对方电台方向看到的最可能的余迹：横轴为相对于对方电台的方位角（A 在左，B 在右），纵轴为仰角。每条余迹是一条朝向辐射点的线段，越可能出现就画得越粗。图中还画出天线波瓣、对方电台和各个 Hot。
H2|5.6 警告
LI|注意：Hot A（或 Hot B）进入天线波瓣：按此指向，该热点已被覆盖。
LI|辐射点过高：某个有用的辐射点高于 70°；余迹几乎垂直下落，向路径方向的反射很少。
LI|低辐射点沿路径方向：计算出的效率仍然很低，但对于与路径平行的掠射余迹，DJ5HG 预计会有少量但很强的反射：值得收听。
LI|路径超出余迹地平线：在余迹高度上，中点位于地平线以下；警告会说明需要多高的高度。
LI|无公共区域：该层没有任何点能被两个电台同时看到；警告会说明差多少以及需要什么条件。
H1|6. 几何与路径损耗
P|路径的文字报告（可选择和复制），右侧是三种余迹高度下天线仰角随到反射点距离变化的图表。
H2|6.1 本选项卡的数据
LI|功率 W（400）、天线增益 dBi（14；两端使用相同天线）、最小信号 dBm（-130）、余迹密度 q = 10^14 电子/m：用于链路预算。
LI|余迹初始半径：ITU 值的两倍（Stober 2021，保守，默认）、ITU-R P.843，或不计入。半径越大，高频段的损耗越大。
LI|各波段之间的 ping 持续时间：理论值 λ²（McKinley，SM6FHZ；保守，默认）或观测值（NN4SA 的 HamSCI MSQP 测量，2026 年英仙座流星雨：从 50 到 144 MHz，ping 缩短 1.5 倍而不是 8 倍）。
H2|6.2 报告
LI|路径几何：电台及其海拔、距离、方位角、中点、余迹高度、朝向中点的天线仰角。
LI|HOT A / HOT B：每个热点的网格坐标、方位角、与直接方向的偏差、距离和仰角。
LI|公共区域边界：在余迹高度上到地平线的覆盖距离、天线波瓣及其最大值和垂直宽度、边界 A 和边界 B；八木天线的增益和波瓣。
LI|路径损耗：中点、Hot A 和 Hot B 在 28、50、70、144、222 和 432 MHz 的损耗（余迹横穿路径平面，最不利的情况）。
LI|链路预算：功率和 EIRP、路径损耗、天线处的信号、最小信号和余量；最佳情况（余迹位于路径平面内）以及采用 OH5IY 平均损耗时的余量。
LI|频段间经验规则：相对于 144 MHz 的反射数量、强度和持续时间；IARU 最大 ping；由 MSQP 测量得到的观测持续时间。
TAG|NOTA|余量为正，表示一条普通的欠密余迹就足以让你的电台完成该路径的通联；余量为负，表示需要更密的余迹或过密流星。这只是估算：参考依据仍然是在波段上的实际经验。
H1|7. 效率计算
P|效率以百分比表示某个流星雨的辐射点位置在多大程度上允许在你的路径上产生反射：100 % 是该路径最有利的位置。此子选项卡按小时显示“计算日期”当天的效率，取每小时中间时刻的值。
H2|7.1 四个信息框
LI|当天最佳时段：路径指数最高的时段及主要一侧。
LI|最有利的流星雨：贡献最大的流星雨，及其时段、一侧和两个最佳指向。
LI|现在：本小时的指数和一侧，以及推荐的 Hot（仅当所选日期为今天时）。
LI|试验性预报：现在、1 小时后和 2 小时后预计的每小时反射数（第 8 章）。
P|当某个信息框没有数值时，会说明原因：无公共区域、没有活跃的流星雨，或辐射点全天都不利。每个信息框的提示框说明它显示的内容。必要时，信息框下方会出现“无公共区域”警告和一条解释字母 A 和 B 的说明栏。
H2|7.2 计算设置
LI|保守（默认）：余迹高度来自雷达、普通余迹、β 角开启。给出最低的数值。
LI|按 DJ5HG：固定高度 102 km、低辐射点时余迹更长、β 角开启；复现 QTFGUI 程序的结果。
LI|自定义：当你手动更改某个复选框或高度时会自动选中。
LI|低辐射点时余迹更长（DJ5HG）：辐射点较低时落下的流星较少，但余迹更长、反射更频繁；在约 9° 以上，两种效应相互抵消。
LI|余迹与路径之间的夹角 β（完整 McKinley 公式），位于标有“影响最大的选项”的橙色框中：开启时，横穿路径平面的余迹比位于该平面内的余迹低 10-15 dB，与路径平行的辐射点占优。关闭时，采用经典规则：最佳辐射点高度为 15-70°，且与路径横交。
LI|经典判断：在每个流星雨下方增加“经典”一行，给出业余无线电经典规则在路径中点处的判定：✗ 辐射点在地平线以下，◐ 勉强（过低、过高或几乎与路径平行），● 良好，★ 极佳（与路径横交）。不改变计算结果。
TAG|ATTENZIONE|β 角对长路径上的数值影响很大：JN70CN - JO76QP（1791 km），2026 年 12 月 14 日的双子座流星雨，β 关闭时为 98 %，β 开启时为 13 %。两种观点的来源不同，与 BRAMS 计数的初步比较也无法区分它们：请用波段上的经验比较这两种情况。百分比是相对于该路径下辐射点的最佳位置而言的；要比较不同的路径，请使用以 dB 表示的效率。
H2|7.3 这些数字可信到什么程度
P|最佳时段和一侧是最可靠的信息：它们随计算设置变化很小。而百分比则在很大程度上取决于所做的选择，尤其是 β 角。与 50 MHz 上 181 767 条真实 MSK144 spot（HamSCI，2025 年 8 月 11-12 日英仙座流星雨）的比较证实了路径指数的逐时变化趋势，但也表明在某个时段能听到哪一对电台，主要取决于偶发流星和空中的活动情况，而这些都不在模型之内。
TAG|NOTA|用本程序来选择时段以及天线要转向的一侧；不要把百分比当作通联成功的概率。
H2|7.4 图表
P|最多显示五个流星雨：效率为实线，DH9GCD 公式为同色点线；路径指数以柱状显示在右侧刻度上。本地时间写在 UTC 时间下方。
H2|7.5 24 小时表格
LI|当天每个活跃的流星雨占一行，24 列对应 UTC 小时。
LI|63A：效率 63 %，大部分反射来自 A 侧；41B：B 侧；不带字母的数字：低于 5 %；空单元格：低于 1 %；↑：辐射点高于 70°（过高）；颜色越暖 = 效率越高。
LI|A = 从你的电台看向对方电台时的左侧（Hot A 区域）；B = 右侧（Hot B 区域）。最好将天线向该侧转 10-30°（侧向散射，side-scatter）。
LI|浅蓝色行 DH9GCD %：DH9GCD 的最佳方向公式，用于比较；它既不考虑地平线也不考虑波瓣。
LI|Σ 行：路径指数，即所有活跃流星雨的 ZHR × 效率之和。
LI|橙色行：每小时反射数的试验性预报，仅在有预报的时段显示。

H1|8. 试验性预报
P|将 Collm 雷达（36.2 MHz）的计数换算为某个业余波段（默认 144 MHz，范围 28 至 1300 MHz）上每小时反射数的估计，对你的路径进行未来 24 小时的预报，并与一个 RMOB 观测者进行比较。这里的一切都是试验性的：这些数字用于比较不同的时段和日期。
H2|8.1 控件
LI|目标频率 MHz：预报的频率。
LI|λ^k 指数（3，SM6FHZ）和 电台因子 K（1）：频率规则以及针对你电台的修正。
LI|由布居指数求 k：根据活跃流星雨的布居指数 r（GMN，否则用 IMO；k = 3.75 · log10 r，按 ZHR 加权）提出 k 值，并在应用前请求确认。
LI|从磁盘载入 RMOB 文件 和 由 RMOB 文件推算指数：读取 RMOB 月度文件，并根据与 Collm 共同的时段推算 k。
LI|RMOB 观测者、立即下载 RMOB 和 每 5 分钟自动下载：自动下载默认关闭，只有在获得 RMOB 许可后才能开启。
H2|8.2 结果
LI|昨天和今天的图表：Collm 的每小时流星数、换算到你的频率的数值，以及（如已载入）RMOB 计数。
LI|未来 24 小时的预报：取前一天同一时刻的数值，按路径上流星雨指数的变化进行修正。
LI|带评价的表格：相对于 24 小时平均值为好、中或差。
TAG|NOTA|反射的持续时间遵循“几何与路径损耗”中“各波段之间的 ping 持续时间”的选择；在前向散射中，持续时间还随路径中点处的 sec²φ 增加。

H1|14. 典型操作
H2|14.1 为某个流星雨准备 sked
TAG|PROCEDURA|1) 设置两个电台并按“计算”。2) 在“流星雨”中查看该流星雨的下一次极大。3) 将该日期填入“计算日期”。4) 在“效率计算”中查看该流星雨的行和 Σ 行：选择效率最高的时段。5) 记下一侧（A 或 B），并将天线向该侧转 10-30°。6) 在“几何与路径损耗”中检查链路预算的余量。
H2|14.2 跟踪一次实时活动
TAG|PROCEDURA|1) 按“实时”。2) 在“预报计算”中跟踪推荐的 Hot 和 PREV 区域，它们每分钟更新一次。3) 在“雷达流量”中检查 Collm 雷达是否正在计数流星。4) 在“实时通信”中查看谁在通联以及他们的余迹落在哪里。
H2|14.3 用 GRAVES 测试电台
TAG|PROCEDURA|1) 在“GRAVES 雷达”中查看“GRAVES 波束中的有效区域”卡。2) 按“路径”卡的提示指向天线。3) 在波束下次扫过的时间窗口内，在 143.049 MHz 用 USB 收听。4) 将 ping 与预期回波以及 RMOB 观测者的数据进行比较。
H2|14.4 用 RMOB 校准预报
TAG|PROCEDURA|1) 在“试验性预报”中载入你所在波段某个观测者的 RMOB 月度文件。2) 按“由 RMOB 文件推算指数”，如果共同时段足够多，则接受 k。3) 将电台因子 K 调到建议值。
H1|15. 常见问题
LI|所有效率都为 0：请阅读“无公共区域”警告。如果“天线方向图”关闭，请降低波瓣仰角；否则说明在余迹高度上路径超出了地平线。
LI|数值比 DH9GCD 或旧版本的低很多：请检查 β 角复选框（第 7.2 章）。
