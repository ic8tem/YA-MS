# Ajustes y carpeta de datos

## La barra de pestañas

En el extremo derecho de la barra de pestañas, de derecha a izquierda:

| Control | Qué hace |
|---|---|
| **Idioma** (lista) | Idioma de la interfaz; ver [Idioma](#idioma) |
| **Tema** (lista) | Esquema de colores; ver [Esquemas de colores](#esquemas-de-colores) |
| **Controles ▴ / ▾** | Pliega o despliega las tres filas de controles encima de las pestañas; ver [Fuente de letra y Controles](#fuente-de-letra-y-controles) |

Al cambiar el idioma o el tema se guardan los ajustes y **se reconstruye la ventana** en la misma posición y tamaño, en la misma pestaña: no hace falta reiniciar.

## Esquemas de colores

La lista **Tema** ofrece 12 esquemas, los mismos del programa EME del autor, YAEC, más la paleta original de YA-MS:

| Esquema | Descripción |
|---|---|
| **Claro** | por defecto |
| **Noche** | tonos azul oscuro, para usar de noche |
| **Negro** | fondo negro, para la oscuridad y para pantallas OLED |
| Pastel celeste · Pastel naranja · Pastel aguamarina · Pastel verde · Pastel rosa · Pastel lila · Pastel índigo · Pastel marrón | ocho esquemas pastel claros |
| **Estela meteórica** | el estilo original de YA-MS (hasta la versión 1.2.0): violeta nocturno con celeste, violeta, verde claro, amarillo y naranja |

El esquema se aplica a todas las pestañas y se guarda en `config.ini` (clave `tema`).

## Fuente de letra y Controles

- **Fuente de letra** (al final de la primera fila de controles): amplía **todo el texto** del **100 al 300 %** en pasos del 10 %; líneas, círculos y mapas mantienen su tamaño. Con fuentes grandes las pestañas pasan a una segunda línea y las tarjetas crecen.
- **Controles**: con fuentes grandes o una pantalla pequeña, pliega las tres filas de controles para dejar sitio a mapas y gráficos. El estado se recuerda.

## Carpeta de datos

Todos los datos y ajustes están en una única carpeta **`data`** **junto al programa**, sin AppData ni carpetas del sistema:

| Sistema | Programa | Datos |
|---|---|---|
| Windows (instalador) | `C:\YA-MS\YA-MS.exe` | `C:\YA-MS\data` |
| Windows (portable) | donde lo hayas descomprimido | `data` junto a `YA-MS.exe` |
| Linux | `~/YA-MS/YA-MS` | `~/YA-MS/data` |
| macOS | `~/YA-MS/YA-MS.app` | `~/YA-MS/data` (junto a la app) |

Al arrancar, el programa crea la carpeta si hace falta y copia solo los archivos iniciales **que faltan**: los archivos que hayas modificado nunca se sobrescriben. Los archivos de traducción de `data/lingue` son archivos del programa y se sustituyen cuando los de la nueva versión son más recientes.

## config.ini

Texto plano, un `clave=valor` por línea (las líneas que empiezan por `#` o `;` son comentarios). El programa lo escribe al cerrarse, así que **edítalo con YA-MS cerrado**. Las claves que te puede interesar conocer:

| Clave | Por defecto | Significado |
|---|---|---|
| `mio_locator`, `mia_quota_m` | JN70CN, 62 | Tu locator y altura (m) |
| `dx_locator`, `dx_quota_m` | JO62QM, 50 | Locator y altura del corresponsal (m) |
| `banda_MHz` | 144 | Banda (28, 50, 70, 144, 222, 432) |
| `quota_scie_km`, `quota_da_radar` | 90, 1 | Altura de las estelas (km); 1 = usar la moda de Collm |
| `elevazione_lobo_gradi` | 0 | Elevación del lóbulo (°) |
| `boom_m` | 4.6 | Longitud del boom de la Yagi (m) |
| `hot_spot_km` | 150 | Distancia de Hot A / Hot B al punto medio (30–400 km) |
| `lingua` | sistema / `it` | Código de idioma (`it`, `en`, `de`, `es`, … – 36 códigos, ver [Idioma](#idioma)) |
| `tema` | `chiaro` | Esquema de colores: `chiaro` (Claro), `scuro` (Noche), `nero` (Negro), `pastello-azzurro`, `pastello-arancione`, `pastello-acquamarina`, `pastello-verde`, `pastello-rosa`, `pastello-lilla`, `pastello-indaco`, `pastello-marrone`, `scia` (Estela meteórica) |
| `carattere_pct` | 100 | Tamaño de letra (100–300 %) |
| `comandi_visibili` | 1 | 1 = filas de controles visibles, 0 = plegadas |
| `mostra_mappa`, `vista_alto` | 1, 1 | Mapa de Europa, vista desde arriba en la Bóveda celeste |
| `aggiornamento_automatico` | 1 | Comprobación automática de las fuentes cada 5 minutos |
| `esponente_lambda` | 3 | Exponente λ en la pestaña Flujo radar |
| `potenza_W`, `guadagno_dBi`, `sensibilita_dBm`, `densita_esponente_q` | 400, 14, −130, 14 | Datos de entrada del balance del enlace |
| `prev_frequenza_MHz`, `prev_esponente`, `prev_fattore_stazione` | 144, 3, 1 | Previsión experimental: frecuencia, k, K |
| `rmob_osservatore` | vacío | Nombre del observador RMOB |
| `rmob_automatico` | 0 | Descarga automática de RMOB (actívala solo con el permiso de RMOB) |
| `rmob_url` | `https://rmob.org/index.php/livedata/live_datas/{NOME}_{MMAAAA}rmob.TXT` | Plantilla de dirección de RMOB |
| `graves_sequenza` | 0 | Secuencia del haz de GRAVES: 0 = 0,8 s (2021), 1 = 3,2 s (2007) |

## Privacidad

YA-MS no recoge ningún dato ni muestra publicidad. Se conecta a internet solo para descargar datos públicos: las imágenes de los radares de Collm y Sodankylä, el mapa de Natural Earth (primer arranque) y, si lo pides, un archivo RMOB.
