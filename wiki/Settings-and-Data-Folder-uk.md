# Налаштування і тека даних

## Панель вкладок

На правому кінці панелі вкладок, справа наліво:

| Елемент | Що робить |
|---|---|
| **Мова** (список) | Мова інтерфейсу; див. [Мова](#мова) |
| **Тема** (список) | Колірна схема; див. [Колірні схеми](#колірні-схеми) |
| **Керування ▴ / ▾** | Згортає або розгортає три ряди елементів керування над вкладками; див. [Шрифт і Керування](#шрифт-і-керування) |

Зміна мови або теми зберігає налаштування і **перебудовує вікно** в тому самому положенні й розмірі, на тій самій вкладці: перезапуск не потрібен.

Числа й дати відповідають вибраній мові (напр. десяткова крапка в англійській, кома в італійській і німецькій). Будь-який текст, якого бракує у файлі перекладу, показується італійською. У Linux для китайської, японської, корейської, арабської, івриту, урду, гінді та бенгальської потрібні відповідні шрифти (напр. сімейства Noto): див. ## Колірні схеми

Список **Тема** пропонує 12 схем — ті самі, що в EME-програмі автора YAEC, плюс оригінальна палітра YA-MS:

| Схема | Опис |
|---|---|
| **Світла** | типова |
| **Ніч** | темно-сині тони для роботи вночі |
| **Чорна** | чорне тло для темряви та OLED-екранів |
| Пастельна блакитна · Пастельна помаранчева · Пастельна аквамаринова · Пастельна зелена · Пастельна рожева · Пастельна бузкова · Пастельна індиго · Пастельна коричнева | вісім світлих пастельних схем |
| **Метеорний слід** | оригінальний стиль YA-MS (до версії 1.2.0): нічний фіолетовий з блакитним, фіолетовим, світло-зеленим, жовтим і помаранчевим |

Схема застосовується до всіх вкладок і зберігається в `config.ini` (ключ `tema`).

## Шрифт і Керування

- **Шрифт** (у кінці першого ряду елементів керування): збільшує **весь текст** від **100 до 300 %** кроком 10 %; лінії, кола й мапи зберігають свій розмір. З великими шрифтами вкладки переносяться на другий рядок, а картки збільшуються.
- **Керування**: з великими шрифтами або на малому екрані згорніть три ряди елементів керування, щоб звільнити місце для мап і графіків. Стан запам'ятовується.

## Тека даних

Усі дані й налаштування містяться в одній теці **`data`** **поруч із програмою** — без AppData і системних тек:

| Система | Програма | Дані |
|---|---|---|
| Windows (інсталятор) | `C:\YA-MS\YA-MS.exe` | `C:\YA-MS\data` |
| Windows (портативна) | там, куди ви її розпакували | `data` поруч із `YA-MS.exe` |
| Linux | `~/YA-MS/YA-MS` | `~/YA-MS/data` |
| macOS | `~/YA-MS/YA-MS.app` | `~/YA-MS/data` (поруч із застосунком) |

Під час запуску програма за потреби створює теку і копіює лише **відсутні** початкові файли: змінені вами файли ніколи не перезаписуються. Файли перекладів у `data/lingue` є файлами програми й замінюються, якщо файли нової версії свіжіші.

### Файли, які можна редагувати

| Файл | Вміст |
|---|---|
| `sciami.csv` | Каталог потоків (значення IMO і робочі значення); див. [Потоки](Showers-uk#редагування-каталогу) |
| `massimi_imo.csv` | Дати й час максимумів, опубліковані IMO (2026, 2027): **нові роки додавайте** сюди |

| `fonti_radar.csv` | Адреси радарів; `attivo=1` — завантажувати, `0` — ігнорувати |
| `regole_sperimentali.csv` | Використані константи й правила, кожне з джерелом (довідково) |
| `lingue/<code>.txt` | Переклади інтерфейсу; див. [Участь у проєкті](Contributing-and-Contacts-uk#переклади) |

## config.ini

Простий текст, один `key=value` на рядок (рядки, що починаються з `#` або `;`, — коментарі). Програма записує його під час закриття, тому **редагуйте його, коли YA-MS закрита**. Ключі, які можуть знадобитися:

| Ключ | Типово | Значення |
|---|---|---|
| `mio_locator`, `mia_quota_m` | JN70CN, 62 | Ваш локатор і висота (m) |
| `dx_locator`, `dx_quota_m` | JO62QM, 50 | Локатор і висота кореспондента (m) |
| `banda_MHz` | 144 | Діапазон (28, 50, 70, 144, 222, 432) |
| `quota_scie_km`, `quota_da_radar` | 90, 1 | Висота слідів (km); 1 = використовувати моду Collm |
| `elevazione_lobo_gradi` | 0 | Кут місця пелюстки (°) |
| `boom_m` | 4.6 | Довжина буму Yagi (m) |
| `hot_spot_km` | 150 | Відстань Hot A / Hot B від середньої точки (30–400 km) |
| `lingua` | системна / `it` | Код мови (один із 36 кодів вище, напр. `it`, `en`, `de`) |
| `tema` | `chiaro` | Колірна схема: `chiaro` (Світла), `scuro` (Ніч), `nero` (Чорна), `pastello-azzurro`, `pastello-arancione`, `pastello-acquamarina`, `pastello-verde`, `pastello-rosa`, `pastello-lilla`, `pastello-indaco`, `pastello-marrone`, `scia` (Метеорний слід) |
| `carattere_pct` | 100 | Розмір шрифту (100–300 %) |
| `comandi_visibili` | 1 | 1 = ряди елементів керування показано, 0 = згорнуто |
| `mostra_mappa`, `vista_alto` | 1, 1 | Мапа Європи, вигляд згори на небесному склепінні |
| `aggiornamento_automatico` | 1 | Автоматична перевірка джерел кожні 5 хвилин |
| `esponente_lambda` | 3 | Показник λ у вкладці «Потік за радаром» |
| `potenza_W`, `guadagno_dBi`, `sensibilita_dBm`, `densita_esponente_q` | 400, 14, −130, 14 | Вхідні дані бюджету лінії |
| `prev_frequenza_MHz`, `prev_esponente`, `prev_fattore_stazione` | 144, 3, 1 | Експериментальний прогноз: частота, k, K |
| `rmob_osservatore` | порожньо | Ім'я спостерігача RMOB |
| `rmob_automatico` | 0 | Автоматичне завантаження RMOB (вмикати лише з дозволу RMOB) |
| `rmob_url` | `https://rmob.org/index.php/livedata/live_datas/{NOME}_{MMAAAA}rmob.TXT` | Шаблон адреси RMOB |
| `graves_sequenza` | 0 | Послідовність променя GRAVES: 0 = 0,8 с (2021), 1 = 3,2 с (2007) |
| `controlla_aggiornamenti` | 1 | Перевірка нових версій на GitHub під час запуску (раз на день); 0 = ні |
| `aggiornamenti_salta` | порожньо | Версія, для якої ви вибрали *Пропустити цю версію* |

## Конфіденційність

YA-MS не збирає жодних даних і не показує реклами. Вона підключається до інтернету лише для завантаження публічних даних: зображень радарів Collm і Соданкюля, мапи Natural Earth (під час першого запуску) і, якщо ви попросите, файлу RMOB.
