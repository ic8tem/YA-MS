# การคำนวณประสิทธิภาพ

*แท็บ: การคำนวณการพยากรณ์ › การคำนวณประสิทธิภาพ*

[![การคำนวณประสิทธิภาพ](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_3.png)](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_3.png)

**ประสิทธิภาพ** ของฝนดาวตกบอกเป็นเปอร์เซ็นต์ว่าตำแหน่งของจุดกระจายเอื้อให้เกิดการสะท้อนบนเส้นทาง **ของคุณ** ได้มากเพียงใด แนวคิดนี้เป็นของ Ilkka **OH5IY** (MS-Soft) และนำมาใช้ต่อในบทความของ Cerrotta–Sartori: จุดสูงสุดของประสิทธิภาพไม่ตรงกับจุดสูงสุดที่มองด้วยตาเปล่า (ZHR) เพราะขึ้นอยู่กับว่าจุดกระจายอยู่ที่ใดเทียบกับสองสถานี MCG_MS ของ DL5MCG ใช้แนวคิดเดียวกันกับทิศคงที่สี่ทิศ ส่วน YA-MS คำนวณสำหรับ **เส้นทางจริง** ระหว่างโลเคเตอร์ทั้งสอง

แท็บนี้แสดงประสิทธิภาพทีละชั่วโมงสำหรับวันที่เลือกใน *วันสำหรับตาราง 24 ชม. (UTC)* (ค่าที่เวลาครึ่งชั่วโมงของแต่ละชั่วโมง)

## การ์ดสรุป

| การ์ด | เนื้อหา |
|---|---|
| **ช่วงเวลาที่ดีที่สุดของวัน** | ชั่วโมงที่มีดัชนีเส้นทางสูงสุด ค่าดัชนี และด้านที่เด่น (A/B พร้อม %) |
| **ฝนดาวตกที่เอื้ออำนวยที่สุด** | ฝนดาวตกที่มีค่า ZHR × ประสิทธิภาพ สูงสุดของวัน ประสิทธิภาพ ชั่วโมงและด้านของมัน และ **ทิศที่ดีที่สุด** (อะซิมุทของจุดกระจาย +90° / −90°) |
| **ขณะนี้** | ดัชนีและด้านที่เด่นในชั่วโมงนี้ และ Hot ที่แนะนำ (เฉพาะเมื่อวันที่เลือกคือวันนี้) |
| **การพยากรณ์เชิงทดลอง** | จำนวนการสะท้อน/ชั่วโมงที่คาดไว้ขณะนี้ ใน 1 ชม. และใน 2 ชม. ที่ความถี่ของการพยากรณ์ (Collm, กฎ SM6FHZ; ดู [การพยากรณ์เชิงทดลอง](Experimental-Forecasts-th)) |

ใต้การ์ดมีแถบอธิบายตัวอักษร A และ B (ดูด้านล่าง)

## กราฟ

*ประสิทธิภาพรายชั่วโมงสำหรับ … วันที่ … (UTC, ค่าที่ครึ่งชั่วโมง)* สำหรับฝนดาวตกไม่เกินห้ากลุ่ม: ประสิทธิภาพ % เป็นเส้นทึบ และสูตร DH9GCD เป็นเส้นจุดสีเดียวกัน; **ดัชนีเส้นทาง** เป็นแท่งสีน้ำเงินบนสเกลขวา

## ตารางรายชั่วโมง

หนึ่งแถวต่อฝนดาวตกหนึ่งกลุ่มที่เกิดขึ้นในวันนั้น (เรียงตาม ZHR) 24 คอลัมน์สำหรับแต่ละชั่วโมง (UTC):

| เซลล์ | ความหมาย |
|---|---|
| `63A` | ประสิทธิภาพ 63 % การสะท้อนส่วนใหญ่มาจากด้าน **A** |
| `41B` | ประสิทธิภาพ 41 % ด้าน **B** |
| `3` | ประสิทธิภาพต่ำกว่า 5 %: ตัวเลขโดยไม่มีตัวอักษรบอกด้าน |
| ว่าง | ประสิทธิภาพต่ำกว่า 1 % |
| `…↑` | จุดกระจายอยู่ **สูงกว่า 70°** จากสถานีของคุณในชั่วโมงนั้น (สูงเกินไป) |
| ข้อความสีเหลือง | ประสิทธิภาพ ≥ 50 % |

- **A** = **ซ้าย** เมื่อมองจากสถานีของคุณไปยังสถานี DX (โซน Hot A); **B** = **ขวา** (โซน Hot B) ควรหมุนสายอากาศ **10–30° ไปทางด้านนั้น** (side-scatter, บทความของ Cerrotta–Sartori)
- **แถวสีฟ้าอ่อน** (*DH9GCD %* ใต้ฝนดาวตกแต่ละกลุ่ม): สูตรของ DH9GCD สำหรับการเปรียบเทียบ
- **แถว Σ**: *ดัชนีเส้นทาง (ZHR×ประสิทธิภาพ)*
- **แถวสีส้ม** (*พยากรณ์ … MHz (การสะท้อน/ชั่วโมง)*): การพยากรณ์เชิงทดลอง สำหรับชั่วโมงที่มีค่า (วันนี้และบางส่วนของพรุ่งนี้)

## แบบจำลอง

ทุกขั้นตอนอยู่ใน [คู่มือการคำนวณ](Efficiency-Explanation-th) (`doc/YA-MS_manuale_calcoli.docx` บทที่ 5) โดยสรุป:

**1. การสะท้อนแบบกระจกเงา (specular)** รอยทางจะส่งสัญญาณจาก A ไป B ได้ก็ต่อเมื่อสัมผัสกับทรงรี (ellipsoid) ที่มี A และ B เป็นจุดโฟกัส (McKinley 1961) รอยทางของฝนดาวตกกลุ่มหนึ่งขนานกับทิศทางของจุดกระจาย ŝ (บทความ; McKinley) สำหรับแต่ละจุด P ในชั้น E โดยมีเวกเตอร์หนึ่งหน่วยชี้ไปยังสถานี:

```
ê_A = (A − P)/|A − P|     ê_B = (B − P)/|B − P|     n̂ = (ê_A + ê_B)/|ê_A + ê_B|     specular condition: ŝ·n̂ = 0
```

กฎเดียวกันนี้เป็นพื้นฐานของ QTFGUI ของ DJ5HG (การกระเจิงแบบกรวย) เงื่อนไขนี้ยอมรับได้ด้วยค่าคลาดเคลื่อนแบบเกาส์เซียน σ = 0.05 rad (ประมาณ 3°) – *การเลือกของโปรแกรม*:

```
S_P = exp( −(ŝ·n̂)² / (2σ²) )
```

**2. น้ำหนักของแต่ละจุด** กำลังของรอยทางแบบ underdense (McKinley), φ = ครึ่งหนึ่งของมุมกระเจิง (จำกัดไว้ที่ 85°, *การเลือก*):

```
φ = ½·arccos(ê_A·ê_B)        w_P = 1 / [ R1·R2·(R1 + R2)·cos²φ ]
```

จำนวนดาวตกที่มาถึงจุดหนึ่งแปรผันตามไซน์ของมุมเงยของจุดกระจาย ณ จุดนั้น (ŝ·û_P) ซึ่งเป็นการแก้ไขแบบเดียวกับที่ IMO ใช้กับ ZHR

**3. ผลรวมและเปอร์เซ็นต์** จุดทุก ๆ 15 km ที่ความสูงของรอยทาง เฉพาะจุดที่ทั้งสองสถานีมองเห็นสูงกว่ามุมเงยของลำคลื่น (*การเลือก*) 100 % คือตำแหน่งจุดกระจายที่เอื้ออำนวยที่สุดสำหรับเส้นทางนั้น:

```
F(ŝ) = Σ_P w_P · S_P · max(0, ŝ·û_P)          η(ŝ) = 100 · F(ŝ) / max F   %
```

F คำนวณหนึ่งครั้งต่อเส้นทางบนกริดของทิศทาง (อะซิมุททุก 5° มุมเงยทุก 2.5°) แล้วประมาณค่าในช่วง (interpolate)

**4. ด้านและดัชนี**

```
f_A = Σ_{P∈A} w_P·S_P·(ŝ·û_P) / Σ_P w_P·S_P·(ŝ·û_P)          I(t) = Σ_showers ZHR(t)·η(t) / 100
```

ตัวอักษรในตารางคือด้านที่มีสัดส่วนมากกว่า *การเลือกของโปรแกรม (คู่มือ สมการ 32–33)*

## การเปรียบเทียบกับ DH9GCD

การตรวจสอบแบบอิสระ: สูตรทิศทางที่ดีที่สุดของ **DH9GCD** ตามที่ **DF5HC** รายงาน (การประชุม DARC มกราคม 2018) โดย El และ Az คือมุมเงยและอะซิมุทของจุดกระจายเมื่อมองจากสถานีของคุณ และ P คืออะซิมุทของสถานี DX:

```
E = sin El · cos El · sin(P − Az)          shown as  E% = 200 · sin El · cos El · |sin(P − Az)|
```

ค่าจะสูงสุดเมื่อจุดกระจายอยู่ที่ 45° และตั้งฉากกับเส้นทาง DF5HC ถือว่าจุดกระจายต่ำเกินไปเมื่อต่ำกว่า 20° และ **สูงเกินไปเมื่อเหนือ 70°**: ชั่วโมงเหล่านี้จะมี ↑ ในตารางและมีคำเตือนบน [โดมท้องฟ้า](Sky-View-th#คำเตือน) สูตรนี้ไม่คำนึงถึงระยะทางและความสูง แต่เป็นค่าอ้างอิงที่ดี
