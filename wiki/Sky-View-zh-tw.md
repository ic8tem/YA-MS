# 天球

*頁籤：預報計算 › 預報計算。*

[![天球](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)

這個子頁籤（即早期版本中的天球）在一個畫面上顯示有用的餘跡此刻**在哪裡**，以及天線**該指向哪裡**。左側是路徑的**平面圖**；右側是流星雨清單、含輻射點的小天球、計算文字，以及從您的天線看出去的**剖面**。所有內容都以*天球時刻*滑桿所設定的時刻為準（預設為即時；±36 h，每步 15 分鐘）。

在小天球中，一條穿過天頂的**橘色線**一律顯示**正確的天線方向**，也就是與所選流星雨（或最有利流星雨）移動方向正交的方向：輻射點方位角 ±90°，兩端標示 *天線 NNN°*，並以細線表示 ±45° 的容許範圍。天球邊緣上的橘色短刻度則顯示其他有用流星雨的正交方向。

## 平面圖（左側）

從上方俯視的歐洲地圖（**E 在右**），四周有度數刻度。地圖下方的說明列出其半徑（*地圖：邊緣 = 距電台 … km*）。

| 元素 | 繪製方式 |
|---|---|
| 路徑 / DX | 從您的電台到對方電台的綠線（一律是兩個網格座標之間的實際大圓路徑） |
| **Hot A / Hot B** | 位於中點兩側 150 km（可調整）、垂直於路徑的點。**紅色 = 建議**，**粉紅色 = 在天線波瓣外**，**灰色 = 在波瓣內**（並顯示注意訊息） |
| 天線波瓣 | 以天線方位為中心的 −3 dB 水平波瓣（天線一律指向 DX），標示為 *波瓣 …°* |
| 共同區域界限 | 淡色的 *界限 A* / *界限 B* 點，以及各電台地平線與 E 層交會形成的兩個圓（請參閱[幾何](Geometry-and-Path-Loss-zh-tw#共同區域界限)） |
| 流星雨移動軌跡 | **黃線**：所選流星雨（或最有利流星雨）掃過天空的方向，也就是輻射點方位角 |
| 最佳指向 | **橘點**：與移動方向垂直的兩個指向（輻射點方位角 ±90°，SM6FHZ） |
| **PREV 區域** | 淺色橢圓：**目前**最可能的餘跡落點，路徑每側各一個 |

標示不會互相重疊：Hot A 與 PREV A 寫在路徑左方，B 寫在右方。**圖例**是地圖右側一個可收合的欄。

**在地圖上使用滑鼠：** **左鍵 = 對方電台的網格座標**，**右鍵 = 本台的網格座標**。路徑會立即重新計算。

流星雨清單上方的選項：**Hot A / Hot B 方向**、**歐洲地圖**（Natural Earth，第一次啟動時下載到 `data/mappa`）、**俯視圖（E 在右）**。

### 建議的 Hot

對於所顯示的時刻，程式將地平線以上所有流星雨的權重 ZHR × 效率加總，並分配到 A 側（比例 f_A）與 B 側。權重較大的一側即為建議的 Hot，以紅色繪出：

```
W_A = Σ (ZHR·η/100)·f_A        W_B = Σ (ZHR·η/100)·(1 − f_A)        recommended = side with larger W
```

*程式的選擇（手冊式 23）。* 這個構想的來源：DJ5HG，由 DF5HC 轉述（DARC 研討會 2018）：依輻射點的位置，HOT-A 與 HOT-B 兩點中有一個較為有利。朝該側偏轉 10–30°（側向散射）則來自 Cerrotta–Sartori 的文章。

### PREV 區域

對 E 層上的每個點 P，將所有活躍流星雨對效率的貢獻（與[效率](Efficiency-Calculation-zh-tw#模型)相同的鏡面條件）以 ZHR 加權後加總。達到最大值至少 3 % 的點構成 PREV 區域；每個區域繪成一個橢圓，中心 = 各點的加權平均位置，軸長 = 其分散程度的兩倍。

```
W_P = Σ ZHR · c_P(ŝ)      c_P = 100 · w_P·S_P·max(0, ŝ·û_P) / max F      PREV: W_P ≥ 0.03 · max W
```

*程式的選擇（手冊式 34）。* 這就是實用規則：如果流星雨由北向南掃過，有用的餘跡就落在東側與西側。

## 流星雨清單（右上）

| 欄位 | 意義 |
|---|---|
| 流星雨、代號 | 名稱與 IMO 代號 |
| 目前 ZHR | 此刻的活動程度（IMO 峰值 ZHR 套用活動曲線） |
| 方位角、仰角 | 從您的電台看的輻射點位置 |
| 效率 % | 該流星雨對這條路徑的效率 |
| 側 | A 或 B，大多數反射到達的一側 |
| 最佳指向 | 輻射點方位角 ±90° |
| 升起、落下 | 輻射點的升起與落下時間（UTC）；適用時顯示*拱極*或*始終在下方* |

點選一列即可選取該流星雨：黃色移動軌跡線與橘點會隨之改變。

## 小天球（右側中間）

從您的電台看的天球上的輻射點，附有 **IMO 代號**與**青色的每日軌跡**（UTC 時刻）。**點選輻射點**即可選取它。顏色：

| 顏色 | 意義 |
|---|---|
| 黃色 | 效率 ≥ 50 % 且 ZHR ≥ 2 |
| 橘色 | 效率 ≥ 20 % |
| 暗紅色 | 效率 < 20 % |
| 灰色 | 幾乎不活躍 |

旁邊是計算文字：路徑長度與方位角、中點及其仰角、Hot A / Hot B 的方位角與偏移、建議的 Hot（*目前建議 …：方位 …°（預期反射的 …%）*）、共同區域界限，以及提醒：*流星雨的最佳指向：與來向垂直（輻射點方位角 ±90°，容許 ±40–50°，SM6FHZ）*。

## 剖面（右下）

*剖面 - 從天線朝對方電台看到的最可能餘跡。* 橫軸為**相對於對方電台的方位角**（← A 左，B → 右），縱軸為**仰角**。對每個流星雨取最強的 14 個反射點；每條餘跡畫成一條朝向輻射點的線段，從餘跡高度以上 10 km 延伸到以下 10 km（每側最多 60 km），可能性越高線條越粗。圖中也畫出天線波瓣（以波瓣仰角為中心的 −3 dB 圓）、對方電台以及 Hot A / Hot B。

```
Q = P ± t½·ŝ        t½ = min(60 km, 10 km / max(0.17, |ŝ·û_P|))
```

*程式的選擇（手冊式 35）。*

## 警告

| 警告 | 出現時機 |
|---|---|
| **注意：Hot A（和/或 Hot B）落在天線波瓣內 …** | 熱點位於天線方位 ±θ/2 範圍內（θ = −3 dB 水平波瓣）：以此指向已涵蓋。在地圖上以灰色標示。建議的 Hot 仍維持紅色。 |
| **輻射點太高（高於 70°）** | 某個有用的輻射點從您的電台看高於 70°：餘跡幾乎垂直落下，朝路徑方向的反射很少（DF5HC、DH9GCD）。在[每小時表格](Efficiency-Calculation-zh-tw#每小時表格)中，相同的小時以 ↑ 標示。 |
| *沒有 E 層共同區域* | 路徑長度超過餘跡高度處涵蓋距離的兩倍：兩個電台看不到 E 層的共同部分（不可能單跳）。 |
| *無建議的 Hot* | 此時幾乎沒有活躍的流星雨。 |
