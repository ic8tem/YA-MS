# 設定とデータフォルダー

## タブバー

タブバーの右端に、右から左へ次の項目があります:

| 操作 | 機能 |
|---|---|
| **表示言語** (リスト) | 表示言語; [表示言語](#表示言語) を参照 |
| **テーマ** (リスト) | 配色; [配色テーマ](#配色テーマ) を参照 |
| **操作 ▴ / ▾** | タブの上の 3 段の操作部を折りたたみ・展開します; [フォントと操作](#フォントと操作) を参照 |

表示言語やテーマを変えると設定が保存され、同じ位置・大きさ・同じタブで**ウィンドウが再構築されます**: 再起動は不要です。

## 配色テーマ

**テーマ** のリストには 12 の配色があります。作者の EME プログラム YAEC と同じものに、YA-MS 本来のパレットを加えたものです:

| 配色 | 説明 |
|---|---|
| **ライト** | 既定 |
| **夜間** | 夜間用の濃い青系 |
| **ブラック** | 黒背景。暗い場所や OLED 画面向け |
| パステル水色 · パステルオレンジ · パステルアクアマリン · パステルグリーン · パステルピンク · パステルライラック · パステルインディゴ · パステルブラウン | 8 つの明るいパステル配色 |
| **流星痕** | YA-MS 本来のスタイル (バージョン 1.2.0 まで): 夜の紫に水色、紫、黄緑、黄、橙 |

配色はすべてのタブに適用され、`config.ini` (キー `tema`) に保存されます。

## フォントと操作

- **フォント** (操作部 1 段目の右端): **すべての文字**を **100 % から 300 %** まで 10 % 刻みで拡大します。線、円、地図の大きさは変わりません。大きなフォントではタブが 2 行に折り返され、カードも大きくなります。
- **操作**: 大きなフォントや小さな画面では、3 段の操作部を折りたたんで地図やグラフの場所を確保してください。状態は記憶されます。

## データフォルダー

すべてのデータと設定は、**プログラムの隣**にある 1 つの **`data`** フォルダーに入っています – AppData もシステムフォルダーも使いません:

| システム | プログラム | データ |
|---|---|---|
| Windows (インストーラー) | `C:\YA-MS\YA-MS.exe` | `C:\YA-MS\data` |
| Windows (ポータブル版) | 展開した場所 | `YA-MS.exe` の隣の `data` |
| Linux | `~/YA-MS/YA-MS` | `~/YA-MS/data` |
| macOS | `~/YA-MS/YA-MS.app` | `~/YA-MS/data` (アプリの隣) |

起動時、プログラムは必要ならフォルダーを作成し、**欠けている**初期ファイルだけをコピーします: 変更したファイルが上書きされることはありません。`data/lingue` の翻訳ファイルはプログラムの一部であり、新しいバージョンのファイルの方が新しければ置き換えられます。

### 編集できるファイル

| `fonti_radar.csv` | レーダーのアドレス; `attivo=1` で取得、`0` で無視 |

| `lingue/<code>.txt` | 表示の翻訳; [貢献](Contributing-and-Contacts-ja#翻訳) を参照 |
| `config.ini` | 設定 (下記参照) |

## config.ini

プレーンテキストで、1 行に 1 つの `key=value` (`#` または `;` で始まる行はコメント)。プログラムは終了時にこのファイルを書き込むため、**YA-MS を閉じてから編集してください**。知っておくと便利なキー:

| キー | 既定値 | 意味 |
|---|---|---|
| `mio_locator`, `mia_quota_m` | JN70CN, 62 | 自局のロケーターと標高 (m) |
| `dx_locator`, `dx_quota_m` | JO62QM, 50 | 相手局のロケーターと標高 (m) |
| `banda_MHz` | 144 | バンド (28, 50, 70, 144, 222, 432) |
| `quota_scie_km`, `quota_da_radar` | 90, 1 | 流星痕高度 (km); 1 = Collm の最頻値を使用 |
| `elevazione_lobo_gradi` | 0 | ビーム仰角 (°) |
| `boom_m` | 4.6 | 八木アンテナのブーム長 (m) |
| `hot_spot_km` | 150 | 中間点から Hot A / Hot B までの距離 (30–400 km) |
| `lingua` | システム / `it` | 言語コード (`it`, `en`, `de`, `ja`, … – 36 個のコード、[表示言語](#表示言語) を参照) |
| `tema` | `chiaro` | 配色: `chiaro` (ライト), `scuro` (夜間), `nero` (ブラック), `pastello-azzurro`, `pastello-arancione`, `pastello-acquamarina`, `pastello-verde`, `pastello-rosa`, `pastello-lilla`, `pastello-indaco`, `pastello-marrone`, `scia` (流星痕) |
| `carattere_pct` | 100 | フォントサイズ (100–300 %) |
| `comandi_visibili` | 1 | 1 = 操作部を表示、0 = 折りたたみ |
| `mostra_mappa`, `vista_alto` | 1, 1 | 天球図のヨーロッパ地図、上空から見た図 |
| `aggiornamento_automatico` | 1 | 5 分ごとのソースの自動確認 |
| `esponente_lambda` | 3 | レーダーフラックス タブの λ 指数 |
| `potenza_W`, `guadagno_dBi`, `sensibilita_dBm`, `densita_esponente_q` | 400, 14, −130, 14 | 回線計算の入力値 |
| `prev_frequenza_MHz`, `prev_esponente`, `prev_fattore_stazione` | 144, 3, 1 | 実験的予報: 周波数、k、K |
| `rmob_osservatore` | 空 | RMOB 観測者名 |
| `rmob_automatico` | 0 | RMOB の自動取得 (RMOB の許可がある場合のみ有効にすること) |
| `rmob_url` | `https://rmob.org/index.php/livedata/live_datas/{NOME}_{MMAAAA}rmob.TXT` | RMOB アドレスのテンプレート |
| `graves_sequenza` | 0 | GRAVES のビームのシーケンス: 0 = 0.8 s (2021), 1 = 3.2 s (2007) |

## プライバシー

YA-MS はデータを収集せず、広告も表示しません。インターネットに接続するのは公開データのダウンロードのためだけです: Collm と Sodankylä のレーダー画像、Natural Earth の地図 (初回起動時)、そして要求した場合の RMOB ファイル。
