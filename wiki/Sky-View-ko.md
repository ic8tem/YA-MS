# 천구

*탭: 예보 계산 › 예보 계산.*

[![천구](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)

이 하위 탭(이전 버전의 천구)은 지금 유효한 흔적이 **어디에** 있고 **어디로** 안테나를 향해야 하는지를 한 화면에 보여 줍니다. 왼쪽은 경로의 **평면도**, 오른쪽은 유성우 목록, 복사점이 표시된 작은 천구, 계산 내용 텍스트, 그리고 안테나에서 본 **단면**입니다. 모든 것은 *계산 날짜 (UTC)*와 *시간 (−12 ~ +36 h)* 슬라이더로 선택한 시점을 기준으로 합니다(기본값은 실시간, 15분 단위).

**평면도 위의 띠**에 그 시점의 계산 결과가 요약됩니다: 날짜와 시각(*지금* 또는 지금부터 몇 시간), **경로 지수 Σ ZHR×η**, ZHR과 효율이 함께 표시된 **가장 유용한 유성우**, 수평선 위 유성우의 수, 방위각이 함께 표시된 **추천 Hot**.

작은 천구에서는 천정을 지나는 **주황 선**이 항상 **올바른 안테나 방향**을 보여 줍니다. 이 방향은 선택한 유성우(또는 가장 유리한 유성우)의 이동 방향에 직교하며(복사점 방위 ±90°), 양 끝에 *안테나 NNN°* 레이블이 붙고 ±45° 허용 범위가 가는 선으로 표시됩니다. 테두리의 짧은 주황 눈금은 다른 유효 유성우의 직교 방향을 나타냅니다.

## 평면도 (왼쪽)

위에서 본 유럽 지도(**동쪽이 오른쪽**)이며 주위에 각도 눈금이 있습니다. 지도 아래 캡션에 반경이 표시됩니다(*지도: 가장자리 = 국에서 … km*).

| 요소 | 그림 |
|---|---|
| 경로 / DX | 내 국에서 상대국까지의 초록 선(항상 두 로케이터 사이의 실제 대권 경로) |
| **Hot A / Hot B** | 중간점 양쪽으로 경로에 수직인 150 km(조정 가능) 지점. **빨강 = 추천**, **분홍 = 안테나 로브 밖**, **회색 = 로브 안**(경고 표시) |
| 안테나 로브 | 안테나 방위 주위의 −3 dB 수평 로브(안테나는 항상 DX를 향함). *로브 …°* 레이블 |
| 공통 영역 한계 | 흐린 *한계 A* / *한계 B* 점과 각 국의 수평선이 E층과 만나는 두 원([기하](Geometry-and-Path-Loss-ko#공통-영역-한계) 참조) |
| 유성우 이동 | **노란 선**: 선택한 유성우(또는 가장 유리한 유성우)가 하늘을 쓸고 지나가는 방향, 즉 복사점 방위 |
| 최적 지향 | **주황 점**: 이동 방향에 수직인 두 지향(복사점 방위 ±90°, SM6FHZ) |
| **PREV 영역** | 옅은 타원: **지금** 가장 가능성 높은 흔적이 떨어지는 곳. 경로의 각 쪽에 하나씩 |

레이블은 겹치지 않습니다: Hot A와 PREV A는 경로 왼쪽에, B는 오른쪽에 씁니다. **범례**는 지도 오른쪽의 접을 수 있는 열입니다.

**지도 위 마우스:** **왼쪽 클릭 = 상대국 로케이터**, **오른쪽 클릭 = 내 국 로케이터**. 경로가 즉시 다시 계산됩니다.

유성우 목록 위의 옵션: **Hot A / Hot B 방향**, **유럽 지도**(Natural Earth, 첫 실행 시 `data/mappa`에 다운로드), **위에서 본 모습 (동쪽이 오른쪽)**.

### 추천 Hot

표시 중인 시각에 대해 프로그램은 수평선 위에 있는 모든 유성우의 가중치 ZHR × 효율을 A쪽(비율 f_A)과 B쪽으로 나누어 합산합니다. 가중치가 더 큰 쪽이 추천 Hot이 되며 빨간색으로 그립니다:

```math
W_A = \sum \frac{ZHR\,\eta}{100}\,f_A,\qquad W_B = \sum \frac{ZHR\,\eta}{100}\,(1-f_A),\qquad \mathrm{Hot} = \arg\max(W_A,\ W_B)
```

*프로그램의 선택 (매뉴얼 식 23).* 아이디어의 출처: DF5HC가 소개한 DJ5HG(DARC 컨퍼런스 2018) – 복사점 위치에 따라 HOT-A와 HOT-B 두 점 중 하나가 더 유리합니다. 그쪽으로 10–30° 돌리는 것(사이드 스캐터)은 Cerrotta–Sartori 논문에서 왔습니다.

### PREV 영역

E층의 각 점 P에 대해 활동 중인 모든 유성우가 효율에 기여하는 값([효율](Efficiency-Calculation-ko#모델)과 같은 정반사 조건)을 ZHR로 가중하여 합산합니다. 최대값의 3 % 이상인 점들이 PREV 영역을 이루며, 각 영역은 중심 = 점들의 가중 평균, 축 = 분산의 두 배인 타원으로 그립니다.

```math
W_P = \sum ZHR\; c_P(\hat{s}),\qquad c_P = 100\,\frac{w_P S_P \max(0,\ \hat{s}\cdot\hat{u}_P)}{\max F},\qquad PREV:\ W_P \ge 0{.}03\,\max W
```

*프로그램의 선택 (매뉴얼 식 34).* 이것이 실전 규칙입니다: 유성우가 북에서 남으로 쓸고 지나가면 유효한 흔적은 동쪽과 서쪽에 떨어집니다.

## 유성우 목록 (오른쪽 위)

| 열 | 의미 |
|---|---|
| 유성우, 약칭 | 이름과 IMO 약칭 |
| 현재 ZHR | 이 순간의 활동도(IMO 극대 ZHR과 활동 프로필) |
| 방위각, 앙각 | 내 국에서 본 복사점 위치 |
| 효율 % | 이 경로에 대한 유성우의 효율 |
| 쪽 | A 또는 B, 반사가 가장 많이 오는 쪽 |
| 최적 지향 | 복사점 방위 ±90° |
| 뜨는 시각, 지는 시각 | 복사점이 뜨고 지는 시각(UTC). 해당하면 *주극* 또는 *항상 아래* |

행을 클릭하면 유성우가 선택되고, 노란 이동 선과 주황 점이 그 유성우를 따릅니다.

## 작은 천구 (오른쪽 가운데)

내 국에서 본 천구 위의 복사점과 **IMO 약칭**, **청록색 일주 궤적**(UTC 시각). **복사점을 클릭**하면 선택됩니다. 색:

| 색 | 의미 |
|---|---|
| 노랑 | 효율 ≥ 50 %이고 ZHR ≥ 2 |
| 주황 | 효율 ≥ 20 % |
| 진한 빨강 | 효율 < 20 % |
| 회색 | 거의 비활동 |

옆에는 계산 내용 텍스트가 있습니다: 경로 길이와 방위, 중간점과 그 앙각, Hot A / Hot B의 방위와 오프셋, 추천 Hot(*현재 추천 …: 방위 …° (예상 반사의 …%)*), 공통 영역 한계, 그리고 *유성우에 대한 최적 지향: 도래 방향에 직각(복사점 방위 ±90°, 허용 범위 ±40–50°, SM6FHZ)*이라는 알림입니다.

## 단면 (오른쪽 아래)

*단면 – 상대국 방향 안테나에서 본 가장 가능성 높은 흔적.* 가로축은 **상대국 기준 방위**(← A 왼쪽, B → 오른쪽), 세로축은 **앙각**입니다. 각 유성우마다 가장 강한 반사점 14개를 취합니다. 각 흔적은 복사점 방향의 선분으로, 흔적 고도 위 10 km에서 아래 10 km까지(한쪽 최대 60 km) 그리며 가능성이 클수록 굵게 그립니다. 안테나 로브(로브 앙각 주위의 −3 dB 원), 상대국, Hot A / Hot B도 함께 그립니다.

```math
Q = P \pm t_{1/2}\,\hat{s},\qquad t_{1/2} = \min\left(60\ \mathrm{km},\ \frac{10\ \mathrm{km}}{\max(0{.}17,\ |\hat{s}\cdot\hat{u}_P|)}\right)
```

*프로그램의 선택 (매뉴얼 식 35).*

## 경고

| 경고 | 표시 조건 |
|---|---|
| **주의: Hot A(또는 Hot B)가 안테나 로브 안에 들어갑니다 …** | 핫스폿이 안테나 방위의 ±θ/2 이내(θ = 수평 −3 dB 로브): 이 지향으로 이미 커버됩니다. 지도에 회색으로 표시됩니다. 추천 Hot은 빨간색으로 유지됩니다. |
| **복사점이 너무 높음 (70° 이상)** | 유효한 복사점이 내 국에서 70° 이상: 흔적이 거의 수직으로 떨어져 경로 쪽으로 반사가 적습니다(DF5HC, DH9GCD). 같은 시간대가 [시간별 표](Efficiency-Calculation-ko#시간별-표)에 ↑로 표시됩니다. |
| *E층 공통 영역 없음* | 경로가 흔적 고도에서의 도달 거리의 두 배보다 깁니다: 두 국이 E층의 공통 부분을 볼 수 없습니다(단일 홉 불가). |
| *추천 Hot 없음* | 현재 활동 중인 유성우가 거의 없습니다. |

천구 그래픽의 참고 자료: DL1DBC의 Swan Meteor Skyview(swan.ms). 최적 방향을 보여 주는 극좌표 그래프: SM6FHZ의 RadiantCalc.
