# 設定與資料資料夾

## 分頁列

在分頁列的右端，從右到左依序為：

| 控制項 | 作用 |
|---|---|
| **介面語言**（清單） | 介面語言；請參閱[介面語言](#介面語言) |
| **主題**（清單） | 配色方案；請參閱[配色方案](#配色方案) |
| **控制 ▴ / ▾** | 收合或展開分頁上方的三列控制項；請參閱[字型與控制](#字型與控制) |

變更語言或主題時會儲存設定，並以相同的位置和大小、在同一個分頁上**重建視窗**：無需重新啟動。

## 配色方案

**主題**清單提供 12 種方案，與作者的 EME 程式 YAEC 相同，另加 YA-MS 原有的配色：

| 方案 | 說明 |
|---|---|
| **淺色** | 預設 |
| **夜間** | 深藍色調，適合夜間使用 |
| **黑色** | 黑色背景，適合暗處和 OLED 螢幕 |
| 粉彩淺藍 · 粉彩橘 · 粉彩海藍 · 粉彩綠 · 粉彩粉紅 · 粉彩淡紫 · 粉彩靛藍 · 粉彩棕 | 八種淺色粉彩方案 |
| **流星餘跡** | YA-MS 原有風格（至 1.2.0 版）：夜紫色，搭配淺藍、紫、淺綠、黃和橘色 |

方案適用於所有分頁，並儲存在 `config.ini` 中（鍵 `tema`）。

## 字型與控制

- **字型**（第一列控制項末尾）：將**所有文字**從 **100 % 放大到 300 %**，步長 10 %；線條、圓和地圖保持原有大小。使用大字型時，分頁會換到第二列，卡片也會變大。
- **控制**：在使用大字型或螢幕較小時，收合三列控制項，為地圖和圖表騰出空間。該狀態會被記住。

## 資料資料夾

所有資料和設定都在**程式旁**的一個 **`data`** 資料夾中——不使用 AppData，不使用系統資料夾：

| 系統 | 程式 | 資料 |
|---|---|---|
| Windows（安裝程式） | `C:\YA-MS\YA-MS.exe` | `C:\YA-MS\data` |
| Windows（可攜版） | 解壓縮到的位置 | `YA-MS.exe` 旁的 `data` |
| Linux | `~/YA-MS/YA-MS` | `~/YA-MS/data` |
| macOS | `~/YA-MS/YA-MS.app` | `~/YA-MS/data`（在應用程式旁邊） |

啟動時，程式會在需要時建立該資料夾，並只複製**缺少的**初始檔案：您修改過的檔案永遠不會被覆寫。`data/lingue` 中的翻譯檔屬於程式檔案，如果新版本的檔案較新，則會被取代。

## config.ini

純文字檔，每行一個 `key=value`（以 `#` 或 `;` 開頭的行為註解）。程式在關閉時寫入該檔案，因此**請在 YA-MS 關閉時編輯它**。您可能需要了解的鍵：

| 鍵 | 預設 | 含義 |
|---|---|---|
| `mio_locator`、`mia_quota_m` | JN70CN, 62 | 本台網格座標和高度（m） |
| `dx_locator`、`dx_quota_m` | JO62QM, 50 | 對方電台網格座標和高度（m） |
| `banda_MHz` | 144 | 頻段（28、50、70、144、222、432） |
| `quota_scie_km`、`quota_da_radar` | 90, 1 | 餘跡高度（km）；1 = 使用 Collm 眾數 |
| `elevazione_lobo_gradi` | 0 | 波瓣仰角（°） |
| `boom_m` | 4.6 | 八木天線橫桿長度（m） |
| `hot_spot_km` | 150 | Hot A / Hot B 到中點的距離（30–400 km） |
| `lingua` | 系統 / `it` | 語言代碼（上表 36 個代碼之一，例如 `it`、`en`、`de`） |
| `tema` | `chiaro` | 配色方案：`chiaro`（淺色）、`scuro`（夜間）、`nero`（黑色）、`pastello-azzurro`、`pastello-arancione`、`pastello-acquamarina`、`pastello-verde`、`pastello-rosa`、`pastello-lilla`、`pastello-indaco`、`pastello-marrone`、`scia`（流星餘跡） |
| `carattere_pct` | 100 | 字型大小（100–300 %） |
| `comandi_visibili` | 1 | 1 = 顯示控制項列，0 = 收合 |
| `mostra_mappa`、`vista_alto` | 1, 1 | 天穹中的歐洲地圖、俯視圖 |
| `aggiornamento_automatico` | 1 | 每 5 分鐘自動檢查資料來源 |
| `esponente_lambda` | 3 | 雷達流量分頁中的 λ 指數 |
| `potenza_W`、`guadagno_dBi`、`sensibilita_dBm`、`densita_esponente_q` | 400, 14, −130, 14 | 鏈路預算輸入 |
| `prev_frequenza_MHz`、`prev_esponente`、`prev_fattore_stazione` | 144, 3, 1 | 試驗性預報：頻率、k、K |
| `rmob_osservatore` | 空白 | RMOB 觀測者名稱 |
| `rmob_automatico` | 0 | 自動下載 RMOB（僅在獲得 RMOB 許可後啟用） |
| `rmob_url` | `https://rmob.org/index.php/livedata/live_datas/{NOME}_{MMAAAA}rmob.TXT` | RMOB 網址範本 |
| `graves_sequenza` | 0 | GRAVES 波束序列：0 = 0.8 s（2021），1 = 3.2 s（2007） |
| `controlla_aggiornamenti` | 1 | 啟動時在 GitHub 上檢查新版本（每天一次）；0 = 否 |
| `aggiornamenti_salta` | 空白 | 您選擇了「略過此版本」的版本 |

## 隱私

YA-MS 不收集任何資料，也不顯示廣告。它只在下載公開資料時連線到網際網路：Collm 和 Sodankylä 雷達影像、Natural Earth 地圖（首次啟動時），以及在您要求時下載的 RMOB 檔案。
