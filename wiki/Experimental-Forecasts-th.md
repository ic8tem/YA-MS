# การพยากรณ์เชิงทดลอง

*แท็บ: การคำนวณการพยากรณ์ › การพยากรณ์เชิงทดลอง*

[![การพยากรณ์เชิงทดลอง](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_4.png)](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_4.png)

แท็บนี้แปลงจำนวนนับดาวตกของ **เรดาร์ Collm (36.2 MHz)** เป็นค่าประมาณของ **จำนวนการสะท้อนต่อชั่วโมงบนย่านความถี่สมัครเล่น** (ค่าเริ่มต้น 144 MHz หรือความถี่ใดก็ได้ตั้งแต่ 28 ถึง 1300 MHz) พยากรณ์ **24 ชั่วโมงข้างหน้า** สำหรับเส้นทางของคุณ และให้คุณ **เปรียบเทียบ** ค่าประมาณกับผู้สังเกตของ **RMOB** – เช่น ผู้สังเกตที่ฟัง GRAVES บนความถี่ 143.050 MHz

> ทุกอย่างในที่นี้เป็น **เชิงทดลอง**: กฎความถี่เป็นกฎเชิงประจักษ์ และค่าคงที่สถานีขึ้นอยู่กับสถานีของคุณ ใช้ตัวเลขเพื่อเปรียบเทียบระหว่างชั่วโมงและวัน และตรวจสอบบนอากาศ

## การควบคุม

| การควบคุม | ค่าเริ่มต้น | หน้าที่ |
|---|---|---|
| **ความถี่เป้าหมาย MHz** | 144 | ความถี่ของการพยากรณ์ (28–1300 MHz) |
| **เลขชี้กำลัง λ^k** | 3 | เลขชี้กำลัง k ของกฎความถี่ (SM6FHZ: 3) |
| **ค่าคงที่สถานี K** | 1 | คิดรวมสถานีรับ (กำลังส่ง สายอากาศ); ได้จากการเปรียบเทียบกับผู้สังเกต RMOB บนย่านเดียวกัน |
| **โหลดไฟล์ RMOB จากดิสก์...** | | อ่านไฟล์ข้อความรายเดือนของ RMOB (ดูด้านล่าง) |
| **หาค่าเลขชี้กำลังจากไฟล์ RMOB** | | ปรับค่า k ให้เข้ากับชั่วโมงร่วมของ Collm และ RMOB |
| **ผู้สังเกต RMOB** | ว่าง | ชื่อผู้สังเกตตามที่ปรากฏในชื่อไฟล์ (เช่น `NAME_112026rmob.TXT` → `NAME`) |
| **ดาวน์โหลด RMOB เดี๋ยวนี้** | | ดาวน์โหลดไฟล์ของเดือนปัจจุบันของผู้สังเกตนั้นหนึ่งครั้ง |
| **ดาวน์โหลดอัตโนมัติทุก 5 นาที (เปิดใช้เฉพาะเมื่อได้รับอนุญาตจาก RMOB)** | **ปิด** | ดู [RMOB และโปรแกรมอัตโนมัติ](#rmob-และโปรแกรมอัตโนมัติ) |

เส้นสีส้มใต้การควบคุมแสดงกฎพร้อมตัวเลขปัจจุบัน เช่น *N(144 MHz) = N(Collm 36.2 MHz) x (36.2/144)^3.00 x K = N x 0.01589 x 1.00* การปรับสเกลระยะเวลา และ ping สูงสุดตาม IARU ที่ความถี่นั้น

## จากเรดาร์สู่ย่านความถี่สมัครเล่น

```
N(f) = N(36.2 MHz) · (36.2 / f)^k · K        k = 3
τ(f) = τ(36.2 MHz) · (36.2 / f)²
```

**แหล่งที่มา:** SM6FHZ, *"432 MHz Meteorscatter, Challenges and Techniques"*, 45th Nordic VUSHF พฤษภาคม 2025 – จำนวนและความแรงของการสะท้อนแปรตาม **λ³** ระยะเวลาแปรตาม **λ²** (432 MHz ต่ำกว่า 144 MHz 14–15 dB และนาน 1/9) **การตรวจสอบ:** การขึ้นกับ λ³ นี้เหมือนกับในสมการ underdense ของ McKinley เมื่อ k = 3 ดาวตก 1000 ดวง/ชั่วโมงที่ Collm จะกลายเป็นประมาณ **16 การสะท้อน/ชั่วโมงที่ 144 MHz**; ผู้สังเกต GRAVES ของ RMOB บนความถี่ 143.050 MHz มักนับได้ **20 ถึง 140 เสียงสะท้อน/ชั่วโมง** (วารสาร RMOB มิถุนายน 2018): ลำดับขนาดเข้ากันได้ และความต่างคือค่าคงที่สถานี K (คู่มือ สมการ 44–45)

## 24 ชั่วโมงข้างหน้า

```
N_forecast(t) = N(f, t − 24 h) · (I(t) + 10) / (I(t − 24 h) + 10)
```

**ความต่อเนื่อง (persistence):** ค่าที่ปรับสเกลแล้วของชั่วโมงเดียวกันของวันก่อนหน้า (หรือสองวันก่อนหน้าหากไม่มีข้อมูล) แก้ไขด้วยการเปลี่ยนแปลงของ **ดัชนีฝนดาวตกของเส้นทาง** I (Σ ZHR × ประสิทธิภาพ ดู [การคำนวณประสิทธิภาพ](Efficiency-Calculation-th#แบบจำลอง)) ค่าคงที่ 10 แทนพื้นหลังของดาวตกประปราย และจำกัดการแก้ไขเมื่อดัชนีมีค่าน้อย *การเลือกของโปรแกรม (คู่มือ สมการ 47)*

| แผง | เนื้อหา |
|---|---|
| **วัดที่ Collm และปรับสเกลเป็น f MHz – เมื่อวานและวันนี้ (UTC)** | ดาวตก/ชั่วโมงจากเรดาร์ Collm; ค่าที่ปรับสเกลแล้ว (สีส้ม สเกลขวา); จำนวนนับของ RMOB หากโหลดไว้ (สีเขียว สเกลขวา) |
| **การพยากรณ์เชิงทดลองสำหรับ 24 ชั่วโมงข้างหน้าที่ f MHz สำหรับ …** | จำนวนการสะท้อน/ชั่วโมงที่พยากรณ์ (แท่ง) และดัชนีฝนดาวตกของเส้นทาง (สเกลขวา) |
| ตาราง | เวลา UTC · Collm ชั่วโมงเดียวกัน · ปรับสเกลแล้ว · ดัชนีฝนดาวตกของเส้นทาง · พยากรณ์ /ชั่วโมง · **คะแนน** |

**คะแนน:** *ดี* เมื่อค่าพยากรณ์อย่างน้อย 1.3 × ค่าเฉลี่ย 24 ชั่วโมง, *ปานกลาง* ตั้งแต่ 0.8 ×, *ต่ำ* เมื่อต่ำกว่านั้น การพยากรณ์เดียวกันนี้ปรากฏในการ์ด **การพยากรณ์เชิงทดลอง** และในแถวสีส้มของ [การคำนวณประสิทธิภาพ](Efficiency-Calculation-th) และเป็นฐานของเสียงสะท้อนที่คาดไว้ในแท็บ [เรดาร์ GRAVES](GRAVES-Radar-th#เสียงสะท้อนที่คาดไว้-เชิงทดลอง)

## การเปรียบเทียบกับ RMOB

[RMOB](https://www.rmob.org) (Radio Meteor Observatories On Line, Pierre Terrier) รวบรวมจำนวนนับดาวตกรายชั่วโมงของผู้สังเกตทางวิทยุ หลายรายในอิตาลีฟัง GRAVES บนความถี่ 143.050 MHz (Venice Planetarium, Faenza, Rovereto และอื่น ๆ)

**การอ่านไฟล์ RMOB** รองรับรูปแบบข้อความสองแบบ:

| รูปแบบ | ลักษณะ | หมายเหตุ |
|---|---|---|
| ไฟล์รายเดือน (Colorgramme / Spectrum Lab) | หนึ่งแถวต่อวัน `day| n| n| …` พร้อมค่ารายชั่วโมง 24 ค่า | ไฟล์ `NAME_MMYYYYrmob.TXT` ตามปกติ |
| ตารางวารสาร | ส่วนหัว ` UT |  1   2   3 …` แถว `0h|175 166 …` | หากไฟล์มีผู้สังเกตหลายคน จะอ่านต่อกันไปทีละคน: ให้ใช้ไฟล์ที่มีผู้สังเกตคนเดียว |

เดือนและปีนำมาจากชื่อไฟล์ (`…_MMYYYYrmob…`) หรือจากส่วนหัว มิฉะนั้นจะใช้เดือนปัจจุบัน (และโปรแกรมจะแจ้งให้ทราบ)

**การปรับค่าเลขชี้กำลัง** เมื่อ K = 1 จากมัธยฐานของอัตราส่วน RMOB/Collm ตลอดชั่วโมงร่วม (อย่างน้อย 3 ชั่วโมง):

```
k_emp = − ln( median(N_RMOB / N_Collm) ) / ln( f / 36.2 )
```

*การเลือกของโปรแกรม (คู่มือ สมการ 46)* กล่องโต้ตอบจะแสดงชั่วโมงร่วม มัธยฐานของอัตราส่วน และ k; **ใช่** จะใช้ค่า k (และตั้ง K = 1) **ไม่** จะคง k = 3 ไว้ – จากนั้นให้ปรับ K ด้วยตนเองเป็นค่าที่แนะนำในกล่องโต้ตอบเดียวกัน

## RMOB และโปรแกรมอัตโนมัติ

RMOB ขอให้ **โปรแกรมอัตโนมัติไม่ดึงไฟล์ของ RMOB** ด้วยเหตุนี้ **การดาวน์โหลดอัตโนมัติจึงปิดอยู่** ตั้งแต่เริ่มต้น และควรเปิดใช้ **หลังจากขออนุญาตจาก RMOB แล้วเท่านั้น** หากไม่ได้รับอนุญาต คุณยังคงใช้ **โหลดไฟล์ RMOB จากดิสก์...** หรือกด **ดาวน์โหลด RMOB เดี๋ยวนี้** เมื่อต้องการได้เสมอ

ที่อยู่สำหรับดาวน์โหลดเป็นแม่แบบใน `config.ini` (คีย์ `rmob_url` ค่าเริ่มต้น `https://rmob.org/index.php/livedata/live_datas/{NOME}_{MMAAAA}rmob.TXT` โดย `{NOME}` คือผู้สังเกต และ `{MMAAAA}` คือเดือนและปี) ไฟล์ที่ดาวน์โหลดจะเก็บไว้ใน `data/radar/`
