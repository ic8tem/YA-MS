# โดมท้องฟ้า

*แท็บ: การคำนวณพยากรณ์ › การคำนวณพยากรณ์*

[![Sky dome](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)

แท็บย่อยนี้ (โดมท้องฟ้าในเวอร์ชันก่อน ๆ) รวมไว้ในหน้าจอเดียวว่าตอนนี้รอยดาวตกที่ใช้ได้อยู่ **ที่ไหน** และควร **หันไปทางไหน** ด้านซ้ายคือ **มุมมองระนาบ** ของเส้นทาง ด้านขวาคือรายชื่อฝนดาวตก โดมท้องฟ้าขนาดเล็กพร้อมจุดเรเดียนต์ ข้อความของการคำนวณ และ **ภาพตัดขวาง** ที่มองจากสายอากาศของคุณ ทุกอย่างอ้างอิงช่วงเวลาที่เลือกด้วย *วันที่คำนวณ (UTC)* และแถบเลื่อน *ชั่วโมง (−12 ถึง +36 h)* (ค่าเริ่มต้นคือเวลาจริง ทีละ 15 นาที)

**แถบเหนือมุมมองระนาบ** สรุปการคำนวณสำหรับช่วงเวลานั้น: วันที่และเวลา (*ตอนนี้* หรือจำนวนชั่วโมงจากตอนนี้) **ดัชนีเส้นทาง Σ ZHR×η** **ฝนดาวตกที่มีประโยชน์ที่สุด** พร้อม ZHR และประสิทธิภาพ (เป็น dB เทียบกับค่าอ้างอิงของ DJ5HG ด้วย ดูที่ [การคำนวณประสิทธิภาพ](Efficiency-Calculation-th)) จำนวนฝนดาวตกที่อยู่เหนือขอบฟ้า และ **Hot ที่แนะนำ** พร้อมแอซิมัท

ในโดมท้องฟ้าขนาดเล็ก **เส้นสีส้ม** ที่ผ่านจุดเหนือศีรษะจะแสดง **ทิศสายอากาศที่เหมาะสม** เสมอ ซึ่งตั้งฉากกับการเคลื่อนของฝนดาวตกที่เลือก (หรือกลุ่มที่เอื้ออำนวยที่สุด): แอซิมัทของจุดเรเดียนต์ ±90° มีป้ายกำกับ *สายอากาศ NNN°* ที่ปลายทั้งสองข้าง พร้อมค่าคลาดเคลื่อน ±45° เป็นเส้นบาง ขีดสั้นสีส้มบนขอบวงแสดงทิศตั้งฉากของฝนดาวตกอื่นที่ใช้ได้

## มุมมองระนาบ (ซ้าย)

แผนที่ยุโรปมองจากด้านบน (**E อยู่ทางขวา**) มีสเกลองศาล้อมรอบ คำบรรยายใต้แผนที่บอกรัศมีของแผนที่ (*แผนที่: ขอบ = … km จากสถานี*)

| องค์ประกอบ | การวาด |
|---|---|
| เส้นทาง / DX | เส้นสีเขียวจากสถานีของคุณไปยังสถานี DX (เป็นเส้นทางวงกลมใหญ่จริงระหว่าง locator เสมอ) |
| **Hot A / Hot B** | จุดทั้งสองข้างของจุดกึ่งกลาง ตั้งฉากกับเส้นทาง ที่ระยะตามตารางการเบี่ยงของ AMS (หรือป้อนด้วยตนเอง) **แดง = แนะนำ** **ชมพู = อยู่นอกโลบสายอากาศ** **เทา = อยู่ในโลบ** (พร้อมคำเตือน) |
| โลบสายอากาศ | โลบแนวนอน −3 dB รอบแอซิมัทของสายอากาศ (สายอากาศหันไปทาง DX เสมอ) มีป้ายกำกับ *โลบ …°* |
| ขอบเขตของโซนร่วม | จุด *ขอบ A* / *ขอบ B* แบบจาง ๆ และวงกลมสองวงที่ขอบฟ้าของแต่ละสถานีพบกับชั้น E (ดูที่ [เรขาคณิต](Geometry-and-Path-Loss-th#ขอบเขตของโซนร่วม)) |
| การเคลื่อนของฝนดาวตก | **เส้นสีเหลือง**: ทิศที่ฝนดาวตกที่เลือก (หรือกลุ่มที่เอื้ออำนวยที่สุด) กวาดผ่านท้องฟ้า กล่าวคือแอซิมัทของจุดเรเดียนต์ |
| ทิศที่ดีที่สุด | **จุดสีส้ม**: สองทิศที่ตั้งฉากกับการเคลื่อน (แอซิมัทของจุดเรเดียนต์ ±90°, SM6FHZ) |
| **โซน PREV** | วงรีสีอ่อน: บริเวณที่รอยดาวตกที่น่าจะเป็นที่สุดตก **ตอนนี้** หนึ่งวงต่อด้านของเส้นทาง |

ป้ายกำกับไม่ทับกัน: Hot A และ PREV A เขียนไว้ทางซ้ายของเส้นทาง B ทางขวา **คำอธิบายสัญลักษณ์** เป็นคอลัมน์ที่พับได้ทางขวาของแผนที่

**เมาส์บนแผนที่:** **คลิกซ้าย = locator สถานี DX**, **คลิกขวา = locator สถานีของฉัน** เส้นทางจะถูกคำนวณใหม่ทันที

ตัวเลือกเหนือรายชื่อฝนดาวตก: **ทิศทาง Hot A / Hot B**, **แผนที่ยุโรป** (Natural Earth ดาวน์โหลดลงใน `data/mappa` เมื่อเริ่มครั้งแรก), **มุมมองจากด้านบน (ทิศตะวันออกอยู่ขวา)**

### Hot ที่แนะนำ

สำหรับเวลาที่แสดง โปรแกรมจะรวมน้ำหนัก ZHR × ประสิทธิภาพ ของฝนดาวตกทุกกลุ่มที่อยู่เหนือขอบฟ้า แบ่งระหว่างด้าน A (สัดส่วน f_A) และด้าน B ด้านที่มีน้ำหนักมากกว่าจะเป็น Hot ที่แนะนำ ซึ่งวาดเป็นสีแดง:

```math
W_A = \sum \frac{ZHR\,\eta}{100}\,f_A,\qquad W_B = \sum \frac{ZHR\,\eta}{100}\,(1-f_A),\qquad \mathrm{Hot} = \arg\max(W_A,\ W_B)
```

*การเลือกของโปรแกรม (คู่มือ สมการ 23)* ที่มาของแนวคิด: DJ5HG รายงานโดย DF5HC (การประชุม DARC 2018) – ขึ้นกับตำแหน่งของจุดเรเดียนต์ จุดหนึ่งในสองจุด HOT-A หรือ HOT-B จะเอื้ออำนวยมากกว่า การหมุน 10–30° ไปทางด้านนั้น (side-scatter) มาจากบทความของ Cerrotta–Sartori

### โซน PREV

สำหรับแต่ละจุด P บนชั้น E จะรวมส่วนร่วมต่อประสิทธิภาพของฝนดาวตกทุกกลุ่มที่กำลังเกิดขึ้น (เงื่อนไขสเปคูลาร์เดียวกับ [ประสิทธิภาพ](Efficiency-Calculation-th#แบบจำลอง)) ถ่วงน้ำหนักด้วย ZHR จุดที่มีอย่างน้อย 3 % ของค่าสูงสุดจะรวมเป็นโซน PREV แต่ละโซนวาดเป็นวงรีที่มีศูนย์กลาง = ค่าเฉลี่ยถ่วงน้ำหนักของจุด และแกน = สองเท่าของการกระจาย

```math
W_P = \sum ZHR\; c_P(\hat{s}),\qquad c_P = 100\,\frac{w_P S_P \max(0,\ \hat{s}\cdot\hat{u}_P)}{\max F},\qquad PREV:\ W_P \ge 0{.}03\,\max W
```

*การเลือกของโปรแกรม (คู่มือ สมการ 34)* นี่คือกฎปฏิบัติ: หากฝนดาวตกกวาดจากเหนือไปใต้ รอยดาวตกที่ใช้ได้จะตกทางตะวันออกและตะวันตก

## รายชื่อฝนดาวตก (ขวาบน)

| คอลัมน์ | ความหมาย |
|---|---|
| ฝนดาวตก, รหัส | ชื่อและรหัสของ IMO |
| ZHR ตอนนี้ | กิจกรรม ณ ขณะนี้ (ZHR ที่จุดสูงสุดของ IMO ร่วมกับโปรไฟล์กิจกรรม) |
| แอซิมัท, มุมเงย | ตำแหน่งของจุดเรเดียนต์เมื่อมองจากสถานีของคุณ |
| ประสิทธิภาพ % | ประสิทธิภาพของฝนดาวตกสำหรับเส้นทางนี้ |
| ด้าน | A หรือ B ด้านที่การสะท้อนส่วนใหญ่มาถึง |
| ทิศชี้ดีที่สุด | แอซิมัทของจุดเรเดียนต์ ±90° |
| ขึ้น, ตก | เวลาขึ้นและตกของจุดเรเดียนต์ (UTC) *ไม่ตกขอบฟ้า* หรือ *อยู่ใต้ขอบฟ้าตลอด* เมื่อเข้าเงื่อนไข |

คลิกแถวเพื่อเลือกฝนดาวตก: เส้นการเคลื่อนสีเหลืองและจุดสีส้มจะเปลี่ยนตาม

## โดมท้องฟ้าขนาดเล็ก (ขวากลาง)

จุดเรเดียนต์บนโดมท้องฟ้าที่มองจากสถานีของคุณ พร้อม **รหัส IMO** และ **เส้นทางรายวันสีฟ้าอมเขียว** (ชั่วโมง UTC) **คลิกที่จุดเรเดียนต์** เพื่อเลือก สี:

| สี | ความหมาย |
|---|---|
| เหลือง | ประสิทธิภาพ ≥ 50 % และ ZHR ≥ 2 |
| ส้ม | ประสิทธิภาพ ≥ 20 % |
| แดงเข้ม | ประสิทธิภาพ < 20 % |
| เทา | แทบไม่มีกิจกรรม |

ข้าง ๆ คือข้อความของการคำนวณ: ความยาวและแอซิมัทของเส้นทาง จุดกึ่งกลางและมุมเงย แอซิมัทและการเบี่ยงของ Hot A / Hot B, Hot ที่แนะนำ (*… แนะนำตอนนี้: az. …° (…% ของการสะท้อนที่คาดไว้)*) ขอบเขตของโซนร่วม และข้อเตือนใจ: *การหันสายอากาศที่ดีที่สุดสำหรับฝนดาวตก: ตั้งฉากกับทิศที่มาถึง (แอซิมัทของจุดเรเดียนต์ ±90°, ค่าคลาดเคลื่อน ±40–50°, SM6FHZ)*

## ภาพตัดขวาง (ขวาล่าง)

*ภาพตัดขวาง – รอยดาวตกที่น่าจะเป็นที่สุดเมื่อมองจากสายอากาศไปยังสถานี DX* แนวนอนคือ **แอซิมัทเทียบกับสถานี DX** (← A ซ้าย, B → ขวา) แนวตั้งคือ **มุมเงย** สำหรับฝนดาวตกแต่ละกลุ่มจะใช้จุดสะท้อนที่แรงที่สุด 14 จุด รอยดาวตกแต่ละรอยเป็นส่วนของเส้นตรงที่วางแนวไปทางจุดเรเดียนต์ ตั้งแต่ 10 km เหนือถึง 10 km ใต้ความสูงของรอยดาวตก (สูงสุด 60 km ต่อข้าง) หนาขึ้นเมื่อมีโอกาสมากขึ้น วาดไว้ด้วย: โลบสายอากาศ (วงกลม −3 dB รอบมุมเงยของโลบ) สถานี DX และ Hot A / Hot B

```math
Q = P \pm t_{1/2}\,\hat{s},\qquad t_{1/2} = \min\left(60\ \mathrm{km},\ \frac{10\ \mathrm{km}}{\max(0{.}17,\ |\hat{s}\cdot\hat{u}_P|)}\right)
```

*การเลือกของโปรแกรม (คู่มือ สมการ 35)*

## คำเตือน

| คำเตือน | เมื่อใด |
|---|---|
| **คำเตือน: Hot A (และ/หรือ Hot B) อยู่ภายในโลบสายอากาศ …** | hot spot อยู่ภายใน ±θ/2 ของแอซิมัทสายอากาศ (θ = โลบแนวนอน −3 dB): ด้วยทิศนี้ครอบคลุมอยู่แล้ว แสดงเป็นสีเทาบนแผนที่ Hot ที่แนะนำยังคงเป็นสีแดง |
| **จุดเรเดียนต์สูงเกินไป (เกิน 70°)** | จุดเรเดียนต์ที่ใช้ได้อยู่สูงเกิน 70° เมื่อมองจากสถานีของคุณ: รอยดาวตกตกเกือบในแนวดิ่งและสะท้อนไปทางเส้นทางได้น้อย (DF5HC, DH9GCD) ชั่วโมงเดียวกันจะมีเครื่องหมาย ↑ ใน [ตารางรายชั่วโมง](Efficiency-Calculation-th#ตารางรายชั่วโมง) |
| **จุดเรเดียนต์ต่ำตามแนวเส้นทาง** | จุดเรเดียนต์ที่มีกิจกรรมอยู่ต่ำกว่า 20° และอยู่ภายใน 30° จากทิศของเส้นทาง ประสิทธิภาพที่คำนวณได้ยังคงต่ำ (แบบระมัดระวัง) แต่ DJ5HG คาดว่าจะมีการสะท้อนที่แรงแต่นาน ๆ ครั้งจากรอยดาวตกที่เฉียดและอยู่แนวเดียวกับเส้นทาง (Hamburg–Narvik, Quadrantids, ราว 19 UTC): ควรรับฟัง |
| **เส้นทางเกินขอบฟ้าของรอยดาวตก** | ที่ความสูงของรอยดาวตก จุดกึ่งกลางของเส้นทางอยู่ใต้ขอบฟ้าของทั้งสองสถานี (ประมาณ 2120 km เมื่อรอยดาวตกอยู่ที่ 90 km) คำเตือนจะบอกความสูงของรอยดาวตกขั้นต่ำที่ต้องการ (ประมาณ 96 km สำหรับ 2200 km, 105 km สำหรับ 2300 km): การเชื่อมต่อเป็นไปได้เฉพาะกับรอยดาวตกที่สูงที่สุด และประสิทธิภาพและการลดทอนอยู่ที่ขีดจำกัดของแบบจำลอง |
| *ไม่มีโซนร่วมของชั้น E* | เส้นทางยาวกว่าสองเท่าของระยะที่ความสูงของรอยดาวตก: สองสถานีไม่เห็นส่วนร่วมของชั้น E (การกระโดดครั้งเดียวเป็นไปไม่ได้) |
| *ไม่มี Hot ที่แนะนำ* | แทบไม่มีฝนดาวตกที่มีกิจกรรมในเวลานี้ |
