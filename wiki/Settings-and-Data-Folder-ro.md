# Setări și dosarul de date

## Bara de file

La capătul din dreapta al barei de file, de la dreapta la stânga:

| Comandă | Ce face |
|---|---|
| **Limba** (listă) | Limba interfeței; vezi [Limba](#limba) |
| **Temă** (listă) | Schema de culori; vezi [Scheme de culori](#scheme-de-culori) |
| **Comenzi ▴ / ▾** | Pliază sau depliază cele trei rânduri de comenzi de deasupra filelor; vezi [Font și comenzi](#font-și-comenzi) |

Schimbarea limbii sau a temei salvează setările și **reconstruiește fereastra** în aceeași poziție și cu aceeași mărime, pe aceeași filă: nu este nevoie de repornire.

La prima pornire YA-MS folosește **limba sistemului** dacă este una dintre acestea, altfel italiana. Numerele și datele urmează limba aleasă (de ex. punct zecimal în engleză, virgulă în italiană, germană și română). Orice text care lipsește dintr-un fișier de traducere este afișat în italiană. ## Scheme de culori

Lista **Temă** oferă 12 scheme, aceleași ca în programul EME al autorului, YAEC, plus paleta originală YA-MS:

| Schemă | Descriere |
|---|---|
| **Luminos** | implicită |
| **Noapte** | tonuri de albastru închis, pentru folosirea noaptea |
| **Negru** | fundal negru, pentru întuneric și pentru ecranele OLED |
| Pastel bleu · Pastel portocaliu · Pastel acvamarin · Pastel verde · Pastel roz · Pastel liliachiu · Pastel indigo · Pastel maro | opt scheme pastel deschise |
| **Urmă meteorică** | stilul original YA-MS (până la versiunea 1.2.0): violet de noapte cu bleu, violet, verde deschis, galben și portocaliu |

Schema se aplică tuturor filelor și se salvează în `config.ini` (cheia `tema`).

## Font și comenzi

- **Font** (la capătul primului rând de comenzi): mărește **tot textul** de la **100 la 300 %** în pași de 10 %; liniile, cercurile și hărțile își păstrează mărimea. Cu fonturi mari, filele trec pe un al doilea rând, iar casetele cresc.
- **Comenzi**: cu fonturi mari sau un ecran mic, pliază cele trei rânduri de comenzi pentru a lăsa loc hărților și graficelor. Starea este memorată.

## Dosarul de date

Toate datele și setările se află într-un singur dosar **`data`** **lângă program** – fără AppData, fără dosare de sistem:

| Sistem | Program | Date |
|---|---|---|
| Windows (program de instalare) | `C:\YA-MS\YA-MS.exe` | `C:\YA-MS\data` |
| Windows (portabil) | unde l-ai extras | `data` lângă `YA-MS.exe` |
| Linux | `~/YA-MS/YA-MS` | `~/YA-MS/data` |
| macOS | `~/YA-MS/YA-MS.app` | `~/YA-MS/data` (lângă aplicație) |

La pornire, programul creează dosarul dacă este nevoie și copiază doar fișierele inițiale **lipsă**: fișierele pe care le-ai modificat nu sunt niciodată suprascrise. Fișierele de traducere din `data/lingue` sunt fișiere ale programului și se înlocuiesc atunci când fișierele noii versiuni sunt mai recente.

## config.ini

Text simplu, câte o pereche `key=value` pe rând (rândurile care încep cu `#` sau `;` sunt comentarii). Programul îl scrie la închidere, așa că **editează-l cu YA-MS închis**. Cheile pe care s-ar putea să vrei să le cunoști:

| Cheie | Implicit | Semnificație |
|---|---|---|
| `mio_locator`, `mia_quota_m` | JN70CN, 62 | Locatorul și altitudinea ta (m) |
| `dx_locator`, `dx_quota_m` | JO62QM, 50 | Locatorul și altitudinea corespondentului (m) |
| `banda_MHz` | 144 | Banda (28, 50, 70, 144, 222, 432) |
| `quota_scie_km`, `quota_da_radar` | 90, 1 | Altitudinea urmelor (km); 1 = folosește moda Collm |
| `elevazione_lobo_gradi` | 0 | Elevația lobului (°) |
| `boom_m` | 4.6 | Lungimea boom-ului antenei Yagi (m) |
| `hot_spot_km` | 150 | Distanța Hot A / Hot B de la punctul median (30–400 km) |
| `lingua` | sistem / `it` | Codul limbii (`it`, `en`, `de`, `ro`, … – 36 de coduri, vezi [Limba](#limba)) |
| `tema` | `chiaro` | Schema de culori: `chiaro` (Luminos), `scuro` (Noapte), `nero` (Negru), `pastello-azzurro`, `pastello-arancione`, `pastello-acquamarina`, `pastello-verde`, `pastello-rosa`, `pastello-lilla`, `pastello-indaco`, `pastello-marrone`, `scia` (Urmă meteorică) |
| `carattere_pct` | 100 | Mărimea fontului (100–300 %) |
| `comandi_visibili` | 1 | 1 = rândurile de comenzi afișate, 0 = pliate |
| `mostra_mappa`, `vista_alto` | 1, 1 | Harta Europei, vederea de sus în Bolta cerească |
| `aggiornamento_automatico` | 1 | Verificarea automată a surselor la fiecare 5 minute |
| `esponente_lambda` | 3 | Exponentul λ în fila Flux radar |
| `potenza_W`, `guadagno_dBi`, `sensibilita_dBm`, `densita_esponente_q` | 400, 14, −130, 14 | Datele de intrare ale bilanțului legăturii |
| `prev_frequenza_MHz`, `prev_esponente`, `prev_fattore_stazione` | 144, 3, 1 | Prognoza experimentală: frecvența, k, K |
| `rmob_osservatore` | gol | Numele observatorului RMOB |
| `rmob_automatico` | 0 | Descărcarea automată RMOB (activează doar cu permisiunea RMOB) |
| `rmob_url` | `https://rmob.org/index.php/livedata/live_datas/{NOME}_{MMAAAA}rmob.TXT` | Modelul adresei RMOB |
| `graves_sequenza` | 0 | Secvența fasciculului GRAVES: 0 = 0,8 s (2021), 1 = 3,2 s (2007) |

## Confidențialitate

YA-MS nu colectează date și nu afișează reclame. Se conectează la internet doar pentru a descărca date publice: imaginile radarelor Collm și Sodankylä, harta Natural Earth (la prima pornire) și, dacă o ceri, un fișier RMOB.
