# โดมท้องฟ้า

*แท็บ: การคำนวณการพยากรณ์ › การคำนวณการพยากรณ์*

[![โดมท้องฟ้า](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)

แท็บย่อยนี้ (โดมท้องฟ้าในเวอร์ชันก่อน ๆ) รวมไว้ในหน้าจอเดียวว่าขณะนี้รอยทางที่ใช้ได้อยู่ **ที่ไหน** และควร **หันสายอากาศไปทางใด** ด้านซ้ายคือ **มุมมองแผนผัง** ของเส้นทาง ด้านขวาคือรายการฝนดาวตก โดมท้องฟ้าขนาดเล็กพร้อมจุดกระจาย ข้อความของการคำนวณ และ **ภาพตัด** ที่มองจากสายอากาศของคุณ ทุกอย่างอ้างอิงเวลาของแถบเลื่อน *เวลาของโดมท้องฟ้า* (ค่าเริ่มต้นคือเวลาจริง; ±36 ชม. ทีละ 15 นาที)

ในโดมท้องฟ้าขนาดเล็ก **เส้นสีส้ม** ที่ผ่านจุดเหนือศีรษะ (zenith) จะแสดง **ทิศสายอากาศที่ถูกต้อง** เสมอ ซึ่งตั้งฉากกับการเคลื่อนตัวของฝนดาวตกที่เลือก (หรือกลุ่มที่เอื้ออำนวยที่สุด): อะซิมุทของจุดกระจาย ±90° มีป้าย *สายอากาศ NNN°* ที่ปลายทั้งสองข้าง และมีค่าคลาดเคลื่อนที่ยอมรับได้ ±45° เป็นเส้นบาง ๆ ขีดสั้นสีส้มบนขอบวงแสดงทิศตั้งฉากของฝนดาวตกกลุ่มอื่นที่ใช้ได้

## มุมมองแผนผัง (ซ้าย)

แผนที่ยุโรปที่มองจากด้านบน (**E อยู่ทางขวา**) พร้อมสเกลองศาโดยรอบ คำบรรยายใต้แผนที่บอกรัศมีของแผนที่ (*แผนที่: ขอบ = … km จากสถานี*)

| องค์ประกอบ | การวาด |
|---|---|
| เส้นทาง / DX | เส้นสีเขียวจากสถานีของคุณไปยังสถานี DX (เป็นเส้นทางวงกลมใหญ่จริงระหว่างโลเคเตอร์เสมอ) |
| **Hot A / Hot B** | จุดห่าง 150 km (ปรับได้) ทั้งสองข้างของจุดกึ่งกลาง ตั้งฉากกับเส้นทาง **สีแดง = แนะนำ**, **สีชมพู = อยู่นอกลำคลื่นสายอากาศ**, **สีเทา = อยู่ภายในลำคลื่น** (พร้อมคำเตือน) |
| ลำคลื่นสายอากาศ | ลำคลื่นแนวนอนที่ −3 dB รอบอะซิมุทของสายอากาศ (สายอากาศหันไปยังสถานี DX เสมอ) มีป้าย *ลำคลื่น …°* |
| ขอบเขตโซนร่วม | จุดจาง ๆ *ขอบ A* / *ขอบ B* และวงกลมสองวงที่ขอบฟ้าของแต่ละสถานีบรรจบกับชั้น E (ดู [เรขาคณิต](Geometry-and-Path-Loss-th#ขอบเขตโซนร่วม)) |
| การเคลื่อนตัวของฝนดาวตก | **เส้นสีเหลือง**: ทิศทางที่ฝนดาวตกที่เลือก (หรือกลุ่มที่เอื้ออำนวยที่สุด) กวาดผ่านท้องฟ้า กล่าวคืออะซิมุทของจุดกระจาย |
| ทิศที่ดีที่สุด | **จุดสีส้ม**: ทิศสองทิศที่ตั้งฉากกับการเคลื่อนตัว (อะซิมุทของจุดกระจาย ±90°, SM6FHZ) |
| **โซน PREV** | วงรีสีอ่อน: ตำแหน่งที่รอยทางที่น่าจะเกิดมากที่สุดตกอยู่ **ขณะนี้** ด้านละหนึ่งวงของเส้นทาง |

ป้ายจะไม่ซ้อนทับกัน: Hot A และ PREV A เขียนไว้ทางซ้ายของเส้นทาง ส่วน B อยู่ทางขวา **คำอธิบายสัญลักษณ์** เป็นคอลัมน์ที่พับได้อยู่ทางขวาของแผนที่

**เมาส์บนแผนที่:** **คลิกซ้าย = โลเคเตอร์สถานี DX**, **คลิกขวา = โลเคเตอร์สถานีของฉัน** เส้นทางจะถูกคำนวณใหม่ทันที

ตัวเลือกเหนือรายการฝนดาวตก: **ทิศทาง Hot A / Hot B**, **แผนที่ยุโรป** (Natural Earth ดาวน์โหลดลงใน `data/mappa` ในการเริ่มโปรแกรมครั้งแรก), **มุมมองจากด้านบน (E อยู่ทางขวา)**

### Hot ที่แนะนำ

สำหรับเวลาที่แสดง โปรแกรมจะรวมน้ำหนัก ZHR × ประสิทธิภาพ ของฝนดาวตกทุกกลุ่มที่อยู่เหนือขอบฟ้า โดยแบ่งระหว่างด้าน A (สัดส่วน f_A) และด้าน B ด้านที่มีน้ำหนักมากกว่าจะเป็น Hot ที่แนะนำ ซึ่งวาดเป็นสีแดง:

```
W_A = Σ (ZHR·η/100)·f_A        W_B = Σ (ZHR·η/100)·(1 − f_A)        recommended = side with larger W
```

*การเลือกของโปรแกรม (คู่มือ สมการ 23)* ที่มาของแนวคิด: DJ5HG ตามที่ DF5HC รายงาน (การประชุม DARC 2018) – ขึ้นอยู่กับตำแหน่งของจุดกระจาย จุดใดจุดหนึ่งในสองจุด HOT-A หรือ HOT-B จะเอื้ออำนวยกว่า การหมุนสายอากาศ 10–30° ไปทางด้านนั้น (side-scatter) มาจากบทความของ Cerrotta–Sartori

### โซน PREV

สำหรับแต่ละจุด P ในชั้น E ส่วนร่วมต่อประสิทธิภาพของฝนดาวตกทุกกลุ่มที่กำลังเกิดขึ้น (เงื่อนไขการสะท้อนแบบกระจกเงาเดียวกับ [ประสิทธิภาพ](Efficiency-Calculation-th#แบบจำลอง)) จะถูกรวมกันโดยถ่วงน้ำหนักด้วย ZHR จุดที่มีค่าอย่างน้อย 3 % ของค่าสูงสุดจะรวมกันเป็นโซน PREV แต่ละโซนวาดเป็นวงรีที่มีศูนย์กลาง = ค่าเฉลี่ยถ่วงน้ำหนักของจุด และแกน = สองเท่าของการกระจายตัวของจุด

```
W_P = Σ ZHR · c_P(ŝ)      c_P = 100 · w_P·S_P·max(0, ŝ·û_P) / max F      PREV: W_P ≥ 0.03 · max W
```

*การเลือกของโปรแกรม (คู่มือ สมการ 34)* นี่คือกฎปฏิบัติ: หากฝนดาวตกกวาดจากเหนือไปใต้ รอยทางที่ใช้ได้จะตกทางตะวันออกและตะวันตก

## รายการฝนดาวตก (ขวาบน)

| คอลัมน์ | ความหมาย |
|---|---|
| ฝนดาวตก, รหัส | ชื่อและรหัส IMO |
| ZHR ขณะนี้ | กิจกรรม ณ ขณะนี้ (ZHR สูงสุดตาม IMO ร่วมกับโปรไฟล์กิจกรรม) |
| มุมอะซิมุท, มุมเงย | ตำแหน่งของจุดกระจายเมื่อมองจากสถานีของคุณ |
| ประสิทธิภาพ % | ประสิทธิภาพของฝนดาวตกสำหรับเส้นทางนี้ |
| ด้าน | A หรือ B ด้านที่การสะท้อนส่วนใหญ่มาถึง |
| ทิศที่ดีที่สุด | อะซิมุทของจุดกระจาย ±90° |
| ขึ้น, ตก | เวลาขึ้นและตกของจุดกระจาย (UTC); *ไม่ตกขอบฟ้า (circumpolar)* หรือ *อยู่ใต้ขอบฟ้าตลอด* เมื่อเป็นเช่นนั้น |

คลิกแถวเพื่อเลือกฝนดาวตก: เส้นการเคลื่อนตัวสีเหลืองและจุดสีส้มจะเปลี่ยนตาม

## โดมท้องฟ้าขนาดเล็ก (ขวากลาง)

จุดกระจายบนโดมท้องฟ้าที่มองจากสถานีของคุณ พร้อม **รหัส IMO** และ **เส้นทางรายวันสีฟ้าน้ำทะเล** (เวลา UTC) **คลิกจุดกระจาย** เพื่อเลือก สี:

| สี | ความหมาย |
|---|---|
| เหลือง | ประสิทธิภาพ ≥ 50 % และ ZHR ≥ 2 |
| ส้ม | ประสิทธิภาพ ≥ 20 % |
| แดงเข้ม | ประสิทธิภาพ < 20 % |
| เทา | แทบไม่มีกิจกรรม |

ข้าง ๆ กันคือข้อความของการคำนวณ: ความยาวและอะซิมุทของเส้นทาง จุดกึ่งกลางและมุมเงยของมัน อะซิมุทและค่าเยื้องของ Hot A / Hot B, Hot ที่แนะนำ (*… แนะนำขณะนี้: az. …° (…% ของการสะท้อนที่คาดไว้)*) ขอบเขตโซนร่วม และข้อความเตือนความจำ: *การหันสายอากาศที่ดีที่สุดสำหรับฝนดาวตก: ตั้งฉากกับทิศทางที่มา (อะซิมุทของจุดกระจาย ±90°, ค่าเผื่อ ±40–50°, SM6FHZ)*

## ภาพตัด (ขวาล่าง)

*ภาพตัด – รอยทางที่น่าจะเกิดมากที่สุดเมื่อมองจากสายอากาศไปยังสถานี DX* แนวนอนคือ **อะซิมุทเทียบกับสถานี DX** (← A ซ้าย, B → ขวา) แนวตั้งคือ **มุมเงย** สำหรับฝนดาวตกแต่ละกลุ่มจะใช้จุดสะท้อนที่แรงที่สุด 14 จุด รอยทางแต่ละเส้นเป็นส่วนของเส้นตรงที่วางแนวไปทางจุดกระจาย ตั้งแต่ 10 km เหนือถึง 10 km ใต้ความสูงของรอยทาง (ไม่เกิน 60 km ต่อข้าง) และหนาขึ้นเมื่อมีโอกาสเกิดมากขึ้น นอกจากนี้ยังวาด: ลำคลื่นสายอากาศ (วงกลม −3 dB รอบมุมเงยของลำคลื่น) สถานี DX และ Hot A / Hot B

```
Q = P ± t½·ŝ        t½ = min(60 km, 10 km / max(0.17, |ŝ·û_P|))
```

*การเลือกของโปรแกรม (คู่มือ สมการ 35)*

## คำเตือน

| คำเตือน | เมื่อใด |
|---|---|
| **คำเตือน: Hot A (และ/หรือ Hot B) อยู่ภายในลำคลื่นสายอากาศ …** | จุดร้อนอยู่ภายใน ±θ/2 ของอะซิมุทสายอากาศ (θ = ลำคลื่นแนวนอนที่ −3 dB): ด้วยทิศนี้ครอบคลุมอยู่แล้ว แสดงเป็นสีเทาบนแผนที่ Hot ที่แนะนำยังคงเป็นสีแดง |
| **จุดกระจายสูงเกินไป (เหนือ 70°)** | จุดกระจายที่ใช้ได้อยู่สูงกว่า 70° เมื่อมองจากสถานีของคุณ: รอยทางตกเกือบในแนวดิ่งและสะท้อนไปทางเส้นทางได้น้อย (DF5HC, DH9GCD) ชั่วโมงเดียวกันนี้จะมีเครื่องหมาย ↑ ใน [ตารางรายชั่วโมง](Efficiency-Calculation-th#ตารางรายชั่วโมง) |
| *ไม่มีโซนร่วมในชั้น E* | เส้นทางยาวกว่าสองเท่าของระยะที่ความสูงของรอยทาง: สองสถานีไม่เห็นส่วนร่วมของชั้น E (การสะท้อนครั้งเดียวเป็นไปไม่ได้) |
| *ไม่มี Hot ที่แนะนำ* | แทบไม่มีฝนดาวตกที่กำลังเกิดขึ้นในเวลานี้ |
