# 天穹

*选项卡：预报计算 › 预报计算。*

[![天穹](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)](https://raw.githubusercontent.com/ic8tem/YA-MS/main/docs/screenshots/en-2_1.png)

这个子选项卡（即早期版本中的天穹）在一个画面上显示有用的余迹此刻**在哪里**，以及天线**该指向哪里**。左侧是路径的**平面图**；右侧是流星雨列表、带辐射点的小天穹、计算文字以及从天线看出去的**剖面**。所有内容都以*计算时间*滑块所设的时刻为准（默认实时；±36 h，步长 15 分钟）。

**平面图上方的信息条**汇总该时刻的计算结果：日期和时间（*当前*或距现在的小时数）、**路径指数 Σ ZHR×η**、**最有用的流星雨**及其 ZHR 和效率、地平线以上的流星雨数量，以及**推荐的 Hot** 及其方位角。

在小天穹中，一条穿过天顶的**橙色线**始终给出**正确的天线方向**，即与所选流星雨（或最有利流星雨）移动方向正交的方向：辐射点方位 ±90°，两端标注 *天线 NNN°*，并以细线表示 ±45° 容差。天穹边缘上的橙色短刻度给出其他有用流星雨的正交方向。

## 平面图（左侧）

从上方俯视的欧洲地图（**东在右**），四周有度数刻度。地图下方的说明给出其半径（*地图：边缘 = 距本台 … km*）。

| 元素 | 绘制方式 |
|---|---|
| 路径 / DX | 从本台到对方电台的绿线（始终是两个网格坐标之间的实际大圆路径） |
| **Hot A / Hot B** | 位于中点两侧 150 km（可调）、垂直于路径的点。**红色 = 推荐**，**粉色 = 在天线波瓣外**，**灰色 = 在波瓣内**（并给出提示） |
| 天线波瓣 | 以天线方位为中心的 −3 dB 水平波瓣（天线始终指向 DX），标注为 *波瓣 …°* |
| 公共区域边界 | 淡色的 *界 A* / *界 B* 点，以及各台站地平线与 E 层相交形成的两个圆（参见[几何](Geometry-and-Path-Loss-zh#公共区域边界)） |
| 流星雨移动轨迹 | **黄线**：所选流星雨（或最有利流星雨）扫过天空的方向，即辐射点方位 |
| 最佳指向 | **橙点**：与移动方向垂直的两个指向（辐射点方位 ±90°，SM6FHZ） |
| **PREV 区域** | 浅色椭圆：**此刻**最可能的余迹落点，路径每侧各一个 |

标注不会互相重叠：Hot A 和 PREV A 写在路径左侧，B 写在右侧。**图例**是地图右侧一个可折叠的栏。

**在地图上用鼠标：** **左键 = 对方电台网格坐标**，**右键 = 本台网格坐标**。路径会立即重新计算。

流星雨列表上方的选项：**Hot A / Hot B 方向**、**欧洲地图**（Natural Earth，首次启动时下载到 `data/mappa`）、**俯视图（东在右）**。

### 推荐的 Hot

对于所显示的时刻，程序对地平线以上的所有流星雨累加权重 ZHR × 效率，并按 A 侧（比例 f_A）和 B 侧分配。权重较大的一侧即为推荐的 Hot，以红色绘出：

```math
W_A = \sum \frac{ZHR\,\eta}{100}\,f_A,\qquad W_B = \sum \frac{ZHR\,\eta}{100}\,(1-f_A),\qquad \mathrm{Hot} = \arg\max(W_A,\ W_B)
```

*程序的选择（手册公式 23）。* 这一想法的来源：DJ5HG，由 DF5HC 转述（DARC 会议 2018）——根据辐射点位置，HOT-A 和 HOT-B 两点中有一个更有利。向该侧偏转 10–30°（侧向散射）则来自 Cerrotta–Sartori 的文章。

### PREV 区域

对 E 层上的每个点 P，累加所有活跃流星雨对效率的贡献（与[效率](Efficiency-Calculation-zh#模型)中相同的镜面条件），以 ZHR 加权。达到最大值至少 3 % 的点构成 PREV 区域；每个区域绘成一个椭圆，中心 = 各点的加权平均位置，轴长 = 其离散度的两倍。

```math
W_P = \sum ZHR\; c_P(\hat{s}),\qquad c_P = 100\,\frac{w_P S_P \max(0,\ \hat{s}\cdot\hat{u}_P)}{\max F},\qquad PREV:\ W_P \ge 0{.}03\,\max W
```

*程序的选择（手册公式 34）。* 这就是实用规则：如果流星雨由北向南扫过，有用的余迹就落在东侧和西侧。

## 流星雨列表（右上）

| 列 | 含义 |
|---|---|
| 流星雨、代码 | 名称和 IMO 代码 |
| 当前 ZHR | 此刻的活动水平（IMO 峰值 ZHR 结合活动曲线） |
| 方位角、仰角 | 从本台看的辐射点位置 |
| 效率 % | 该流星雨对这条路径的效率 |
| 侧 | A 或 B，大多数反射到达的一侧 |
| 最佳指向 | 辐射点方位 ±90° |
| 升起、落下 | 辐射点的升起和落下时间（UTC）；适用时显示*拱极*或*始终在下方* |

点击一行即可选中该流星雨：黄色移动轨迹线和橙点会随之改变。

## 小天穹（右侧中部）

从本台看的天穹上的辐射点，附有 **IMO 代码**和**青色的每日轨迹**（UTC 时刻）。**点击辐射点**即可选中它。颜色：

| 颜色 | 含义 |
|---|---|
| 黄色 | 效率 ≥ 50 % 且 ZHR ≥ 2 |
| 橙色 | 效率 ≥ 20 % |
| 深红色 | 效率 < 20 % |
| 灰色 | 几乎不活跃 |

旁边是计算文字：路径长度和方位、中点及其仰角、Hot A / Hot B 的方位和偏角、推荐的 Hot（*当前推荐 …：方位 …°（占预期反射的 …%）*）、公共区域边界，以及提示：*流星雨最佳指向：与到达方向垂直（辐射点方位 ±90°，容差 ±40–50°，SM6FHZ）*。

## 剖面（右下）

*剖面 - 从天线朝对方电台方向看到的最可能余迹。* 横轴为**相对于对方电台的方位角**（← A 左，B → 右），纵轴为**仰角**。对每个流星雨取最强的 14 个反射点；每条余迹画成一条指向辐射点的线段，从余迹高度以上 10 km 延伸到以下 10 km（每侧最多 60 km），可能性越大线条越粗。图中还画出天线波瓣（以波瓣仰角为中心的 −3 dB 圆）、对方电台以及 Hot A / Hot B。

```math
Q = P \pm t_{1/2}\,\hat{s},\qquad t_{1/2} = \min\left(60\ \mathrm{km},\ \frac{10\ \mathrm{km}}{\max(0{.}17,\ |\hat{s}\cdot\hat{u}_P|)}\right)
```

*程序的选择（手册公式 35）。*

## 警告

| 警告 | 出现时机 |
|---|---|
| **注意：Hot A（和/或 Hot B）位于天线波瓣内 …** | 热点位于天线方位 ±θ/2 范围内（θ = −3 dB 水平波瓣宽度）：在此指向下它已被覆盖。在地图上以灰色显示。推荐的 Hot 仍为红色。 |
| **辐射点过高（高于 70°）** | 某个有用的辐射点从本台看高于 70°：余迹几乎垂直下落，向路径方向的反射很少（DF5HC、DH9GCD）。在[逐时表格](Efficiency-Calculation-zh#逐时表格)中，相同的小时以 ↑ 标记。 |
| *没有 E 层公共区域* | 路径长度超过余迹高度处覆盖距离的两倍：两个电台看不到 E 层的公共部分（不可能单跳）。 |
| *无推荐的 Hot* | 此时几乎没有活跃的流星雨。 |
