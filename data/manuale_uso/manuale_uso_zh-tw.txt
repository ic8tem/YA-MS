TITLE|YA-MS 使用手冊
SUB|版本 1.8.6 - Costantino IC8TEM 編寫 - 2026 年 11 月
H1|1. 引言
H2|1.1 YA-MS 的用途
P|YA-MS 協助您預測並即時追蹤您的電台與對方電台之間 28 至 432 MHz 的流星餘跡散射（meteor scatter）條件。對於每個活躍的流星雨，它會告訴您其輻射點的位置對您的路徑有多有利（效率）、在哪些時段、反射從路徑的哪一側到來，以及天線最好指向哪裡。在預測旁邊，它也顯示即時量測的資料：Collm 流星雷達的計數、Global Meteor Network 的攝影機、CMOR 雷達、GRAVES 發射機，以及從叢集（cluster）和 PSKReporter 收集到的流星餘跡散射通訊。
P|本程式免費，可在 Windows、Linux（包括 Raspberry Pi）和 macOS 上執行，並已翻譯成 36 種語言。它既不控制無線電機，也不控制旋轉器：通聯時使用慣用的數位模式程式（MSHV、WSJT-X）。
H2|1.2 如何閱讀本手冊
P|本手冊從預測計算開始，逐一介紹各個分頁。每一章說明該分頁顯示什麼、每個控制項的作用，以及如何解讀結果。第 14 章彙整最常用的操作步驟，第 15 章彙整常見問題。效率如何計算（包括來源和核查）在文件「效率計算說明」中解釋；完整的公式請見《計算手冊》（doc 資料夾）。
TAG|PROCEDURA|需要依序執行的步驟。
TAG|NOTA|有助於更理解或更善用某項功能的資訊。
TAG|ATTENZIONE|常見錯誤、計算的限制或需要了解的程式行為。
P|控制項名稱依程式繁體中文介面中的顯示方式書寫；在其他語言中，它們的位置和順序相同。
H1|2. 安裝、啟動與更新
H2|2.1 下載哪個套件
P|所有套件都在 GitHub 的發行頁面上（github.com/ic8tem/YA-MS/releases）。不需要安裝 .NET：它已包含在套件中。
LI|Windows 64 位元：YA-MS-<版本>-windows-x64-setup.exe（安裝到 C:\YA-MS，不需要系統管理員權限），或可攜式 zip，解壓縮到任意資料夾即可。32 位元 Windows 請使用帶有 x86 的相同檔案。
LI|Linux（Debian、Ubuntu、Mint）：.deb 套件，以 sudo apt install ./ya-ms_<版本>_amd64.deb 安裝；首次啟動時程式會將自己複製到 ~/YA-MS。其他發行版請使用 .tar.gz，解壓縮後以 ./YA-MS 執行。
LI|Raspberry Pi 3、4、5、400 和 500：raspberry-pi-64bit 套件（Raspberry Pi OS 64 位元）或 raspberry-pi-32bit，提供 .tar.gz 或 .deb 格式。
LI|其他 ARM Linux 系統（例如 Slackware ARM64 或 armv7l 開發板）：使用 .tar.gz 格式的 linux-arm64 或 linux-armv7l 安裝包，用法同 Linux。
LI|ARM 上的 Windows（Snapdragon 電腦）：windows-arm64 安裝包。Fedora 和 openSUSE：.rpm 安裝包（x86_64 或 aarch64），用 sudo dnf install 或 sudo zypper install 安裝。
LI|Arch、Manjaro 和 Arch Linux ARM：.pkg.tar.zst 安裝包，用 sudo pacman -U 安裝。Slackware64 和 Slackware ARM64：.txz 安裝包，以 root 身分用 installpkg 安裝。任何 Linux：AppImage（x86_64 或 aarch64），設為可執行後直接執行。Alpine Linux：.tar.gz 格式的 alpine-x64 或 alpine-arm64 安裝包。
LI|macOS：適用於 Apple Silicon（M1 及更新機型）或 Intel 的 .dmg，或 app.zip。將 YA-MS.app 拖曳到您自己的資料夾中（例如 ~/YA-MS）：data 資料夾會建立在 App 旁邊。
TAG|ATTENZIONE|Windows 可能會顯示「Windows 已保護您的電腦」：請選擇「其他資訊」，再選擇「仍要執行」。在 macOS 上，第一次請以右鍵按一下 App 並選擇「打開」。本程式沒有使用付費憑證簽署。
H2|2.2 首次啟動
P|啟動時會顯示幾秒鐘的啟動畫面：ESO 的 VLT 上空的英仙座流星雨。首次啟動時，如果系統語言屬於 36 種語言之一，YA-MS 會選用系統語言，否則選用義大利文；它會將歐洲地圖（Natural Earth）下載到 data/mappa 資料夾，並顯示一條範例路徑。只需幾分鐘即可針對您的電台完成設定（第 4 章）。
H2|2.3 data 資料夾
P|所有設定和所有資料都存放在程式旁邊的同一個 data 資料夾中：不使用 AppData，也不使用系統資料夾。要將 YA-MS 移到另一台電腦，只需複製程式資料夾及其 data 資料夾。該資料夾的內容在第 13 章中說明。
H2|2.4 自動更新
P|從 1.8.6 版起，更新為自動且靜默：啟動時以及之後每 6 小時，YA-MS 檢查 GitHub，如有新版本則下載、安裝並自動重新啟動，不詢問任何問題（僅狀態列提示）。缺少的檔案也會在不詢問的情況下重新下載。下面描述的視窗只在按下「更新」或在 data/config.ini 檔案中寫入 aggiornamenti_automatici=0 時出現。
P|自 1.8.0 版起，YA-MS 會在啟動時自動到 GitHub 檢查是否已發行新版本，每天最多一次。如果有新版本，會出現「有可用的更新」視窗，顯示更新內容和三個按鈕：
LI|立即更新：下載適合您系統的套件，取代程式檔案，保留 data 資料夾並重新啟動 YA-MS。新版本要變更的 data 資料夾中的程式檔案會先複製到 data/backup/v<舊版本>；您自己的檔案（設定、封存、spot、ADIF）不會被更動。
LI|稍後：關閉視窗；隔天會再次檢查。
LI|略過此版本：啟動時不再提示該版本。
P|狀態列右下角的「更新」按鈕可手動執行相同的檢查，對已略過的版本也有效。
TAG|ATTENZIONE|自動更新必須能寫入程式資料夾。如果無法寫入（例如程式被複製到系統資料夾中），YA-MS 會告知這一點，並建議開啟發行頁面以手動安裝。1.7.0 及更早的版本沒有此功能：第一次必須手動更新，直接覆蓋安裝在舊版本上。
TAG|NOTA|如果不想再檢查新版本，請在 data/config.ini 檔案中寫入 controlla_aggiornamenti=0。
H2|2.5 缺少程式檔案
P|啟動時，YA-MS 會檢查自己的所有檔案（翻譯、星表、文件）是否齊全。如果缺少某些檔案（例如複製不完整之後），「缺少的檔案」視窗會列出這些檔案，並提供「下載缺少的檔案」（從 GitHub 下載與程式相同版本的檔案）或「不下載，繼續」。按「更新」時會再次執行相同的檢查。
H1|3. 主視窗
H2|3.1 視窗的組成部分
LI|頂端是對所有分頁都有效的三列控制項：電台與頻段、E 層與天線、計算時間（第 4 章）。
LI|主分頁列，右側是「控制」按鈕、配色方案（主題）和語言。
LI|子分頁位於顏色較淺的一列中，僅用於具有子分頁的分頁。
LI|底部是狀態列：計算訊息、連線警告，以及「更新」按鈕。
H2|3.2 分頁
LI|Live 與即時資料：即時流量、雷達通量、GRAVES 雷達、資料收集（第 9 章）。
LI|預測計算：預測計算、幾何與衰減、效率計算、實驗性預測（第 5-8 章）。
LI|即時流星雨、流星雨、方格地圖（第 10-11 章）。
LI|技術文件（最後一個）：使用手冊、來源、歐洲雷達地圖、效率計算說明（第 12 章）。
H2|3.3 語言、顏色、字型
LI|語言：36 種語言。變更語言後，視窗會在原位置、原分頁上重建，不需重新啟動。數字和日期依所選語言顯示（義大利文以逗號作小數點，英文以句點）。
LI|主題：12 種配色方案；「淺色」為預設方案，「夜間」和「黑色」適合在黑暗中使用，「流星餘跡」是 YA-MS 的原始風格。
LI|字型（位於第一列控制項的末端）：將所有文字放大 100 至 300 %。字型較大時，分頁會換行。
LI|控制：收合和展開三列控制項，為地圖和圖表騰出空間。此選擇會被記住。
TAG|NOTA|幾乎每個控制項都有工具提示：將滑鼠停在控制項上，即可看到它的用途以及預設值的來源。
H1|4. 設定電台與路徑
H2|4.1 第 1 列：電台與頻段
LI|我的 locator 和 海拔 m：您的 Maidenhead locator（4、6 或 8 個字元；使用方格的中心）以及電台的海拔高度。
LI|對方電台 和 海拔 m：要通聯之電台的 locator 和海拔。
LI|頻段 MHz：28、50、70、144、222 或 432 MHz。用於天線增益和波瓣、衰減和鏈路預算，以及通量估算。
LI|計算：重新計算路徑（E 層取樣，不到一秒）。
LI|天線方位：天線的方位角，一律朝向對方電台。
H2|4.2 第 2 列：E 層與天線
LI|餘跡高度 km 和 來自雷達：流星餘跡的高度。勾選「來自雷達」時，使用 Collm 雷達量測到的最常見高度（通常為 88-90 km）；取消勾選即可手動輸入。
LI|波瓣仰角 °：您的天線垂直波瓣最大值的仰角。固定在 0° 的指向性天線，由於地面反射，其主波瓣仍會在地平線以上幾度：通常為 3-8°，視以波長計的天線高度而定。
LI|天線場型：開啟（預設）時，反射點依兩支天線的垂直增益計入：在波瓣最大值附近為全額，朝地平線和朝上逐漸減少。關閉時，波瓣仰角是一條明確的界限：低於該仰角看到的點不計入。
LI|八木天線：boom m：天線主桿（boom）的長度。程式會在旁邊顯示以波長計的長度、增益（DL6WU 曲線）以及水平和垂直的 -3 dB 波瓣寬度。低於 2 λ 時估算不太精確。
LI|熱點距中點 km 和 自動（AMS）：Hot A 和 Hot B 與中點的距離。勾選「自動（AMS）」時，依照 DJ5HG 引用的 J. Richardson 表格（1000 km 時偏離 13°，1500 km 以上偏離 10°）；取消勾選即可手動輸入 30-400 km（MSHV 使用 150 km）。
TAG|ATTENZIONE|當「天線場型」關閉且波瓣仰角只有幾度時，在長路徑上兩個電台可能看不到該層的任何共同點：所有效率均為 0，並出現「無共同區域」警告，列出所需的波瓣仰角或餘跡高度。例如：JN70CN - JO76QP，1791 km，波瓣 3°，餘跡 88.5 km。
H2|4.3 第 3 列：計算時間
LI|時間：UTC 時鐘。
LI|計算日期（UTC）：計算的日期。適用於「預測計算」、「效率計算」中的 24 小時表格，以及「GRAVES 雷達」的時間回溯。預設為今天，到午夜時自動切換到新的一天。
LI|小時（−12 至 +36 h）：以 15 分鐘為間隔移動計算時刻。旁邊會顯示「計算時間：現在」或所選的日期和時間。
LI|即時：回到目前時刻。
H2|4.4 設定自己的電台
TAG|PROCEDURA|1) 輸入「我的 locator」和海拔。2) 輸入對方電台的 locator 和海拔，或在「預測計算」的地圖上按一下：左鍵 = 對方電台，右鍵 = 您的電台。3) 選擇頻段。4) 輸入您天線的 boom 長度和波瓣仰角。5) 按「計算」：狀態列會確認「路徑已計算：... km，取樣 ... 個反射點」。
TAG|NOTA|關閉程式時以及每次計算時，設定都會儲存在 data/config.ini 中：下次啟動時您會看到同一條路徑。
H1|5. 預測計算
P|「預測計算」群組的第一個子分頁在一個畫面中顯示有用的餘跡此刻落在哪裡，以及天線應指向哪裡。所有內容都對應於以日期和小時滑桿所選的時刻。
H2|5.1 摘要列
P|地圖上方的一條摘要列概括該時刻的計算結果：日期和時間、路徑指數（活躍流星雨的 ZHR × 效率之和）、最有用的流星雨及其 ZHR 和效率（也以相對於 DJ5HG 參考值的 dB 表示）、地平線以上的流星雨數量，以及建議的 Hot 及其方位角。
H2|5.2 平面地圖
P|左側是從上方俯視的歐洲地圖（東方在右側），四周有度數刻度：
LI|綠線：兩個 locator 之間的實際路徑；
LI|Hot A 和 Hot B：中點兩側的兩個熱點。紅色 = 建議，粉紅色 = 在天線波瓣之外，灰色 = 已在波瓣之內（並有警告）；
LI|天線波瓣：天線方位角周圍的 -3 dB 扇區；
LI|界限 A 和界限 B（淡色）：兩個電台都能看到的天空的最遠邊緣，並不是要指向的點；
LI|黃線：所選流星雨（或最有利的流星雨）掃過天空的方向；橘色點：兩個垂直方向的指向（輻射點方位角 ±90°）；
LI|PREV 區域（淺色橢圓）：此刻最可能出現餘跡的位置，路徑每一側各一個。
P|在地圖上按左鍵 = 對方電台的 locator，按右鍵 = 您電台的 locator；路徑會立即重新計算。圖例是地圖右側可收合的一欄。流星雨清單上方的核取方塊用於開啟和關閉 Hot 方向、歐洲地圖和俯視圖。
H2|5.3 流星雨清單
P|每個流星雨顯示：名稱和 IMO 代碼、此刻的 ZHR、從您的電台看輻射點的方位角和仰角、該路徑的效率、主要一側（A 或 B）、最佳指向、輻射點的升起和落下時間。按一下某一列即選取該流星雨：黃線和橘色點會隨之更新。
H2|5.4 小天球圖與計算文字
P|從您的電台看到的輻射點，標有 IMO 代碼，青色為每日軌跡。黃色 = 效率至少 50 % 且 ZHR 至少 2；橘色 = 至少 20 %；深紅色 = 更低；灰色 = 幾乎不活躍。穿過天頂的橘線給出正確的天線方向，與流星雨的掃過方向正交。旁邊是計算文字：路徑、中點、建議的 Hot 及預期反射的百分比、共同區域的界限。
H2|5.5 剖面圖
P|右下方顯示從天線朝對方電台方向看到的最可能的餘跡：橫軸為相對於對方電台的方位角（A 在左，B 在右），縱軸為仰角。每條餘跡是一條朝向輻射點的線段，越可能出現就畫得越粗。圖中也畫出天線波瓣、對方電台和各個 Hot。
H2|5.6 警告
LI|警告：Hot A（或 Hot B）落在天線波瓣內：以此指向，該熱點已被涵蓋。
LI|輻射點過高：某個有用的輻射點高於 70°；餘跡幾乎垂直落下，朝路徑方向的反射很少。
LI|沿路徑的低輻射點：計算出的效率仍低，但對於與路徑平行的掠射餘跡，DJ5HG 預期會有少量但很強的反射：值得收聽。
LI|路徑超出餘跡的地平線：在餘跡高度上，中點位於地平線以下；警告會說明需要多高的高度。
LI|無共同區域：該層沒有任何點能同時被兩個電台看到；警告會說明差多少以及需要什麼條件。
H1|6. 幾何與衰減
P|路徑的文字報告（可選取和複製），右側是三種餘跡高度下天線仰角隨與反射點距離變化的圖表。
H2|6.1 本分頁的資料
LI|功率 W（400）、天線增益 dBi（14；兩端使用相同天線）、最低訊號 dBm（-130）、餘跡密度 q = 10^14 電子/m：用於鏈路預算。
LI|餘跡初始半徑：ITU 值的兩倍（Stober 2021，保守，預設）、ITU-R P.843，或不計入。半徑越大，高頻段的損耗越大。
LI|各波段之間的 ping 持續時間：理論值 λ²（McKinley，SM6FHZ；保守，預設）或觀測值（NN4SA 的 HamSCI MSQP 量測，2026 年英仙座流星雨：從 50 到 144 MHz，ping 縮短 1.5 倍而非 8 倍）。
H2|6.2 報告
LI|路徑幾何：電台及其海拔、距離、方位角、中點、餘跡高度、朝向中點的天線仰角。
LI|HOT A / HOT B：每個熱點的 locator、方位角、與直接方向的偏差、距離和仰角。
LI|共同區域界限：在餘跡高度上到地平線的涵蓋距離、天線波瓣及其最大值和垂直寬度、界限 A 和界限 B；八木天線的增益和波瓣。
LI|路徑衰減：中點、Hot A 和 Hot B 在 28、50、70、144、222 和 432 MHz 的衰減（餘跡橫越路徑平面，最不利的情況）。
LI|鏈路預算：功率和 EIRP、衰減、天線處的訊號、最低訊號和餘裕；最佳情況（餘跡位於路徑平面內）以及採用 OH5IY 平均衰減時的餘裕。
LI|頻段間的實驗規則：相對於 144 MHz 的反射數量、強度和持續時間；IARU 最大 ping；由 MSQP 量測得到的觀測持續時間。
TAG|NOTA|餘裕為正，表示一條一般的欠密餘跡就足以讓您的電台完成該路徑的通聯；餘裕為負，表示需要更密的餘跡或過密流星。這只是估算：參考依據仍然是在頻段上的實際經驗。
H1|7. 效率計算
P|效率以百分比表示某個流星雨的輻射點位置在多大程度上允許在您的路徑上產生反射：100 % 是該路徑最有利的位置。此子分頁逐小時顯示「計算日期」當天的效率，取每小時中間時刻的值。
H2|7.1 四個資訊框
LI|一天中的最佳時段：路徑指數最高的時段及主要一側。
LI|最有利的流星雨：貢獻最大的流星雨，及其時段、一側和兩個最佳指向。
LI|現在：本小時的指數和一側，以及建議的 Hot（僅當所選日期為今天時）。
LI|實驗性預測：現在、1 小時後和 2 小時後預期的每小時反射數（第 8 章）。
P|當某個資訊框沒有數值時，會說明原因：無共同區域、沒有活躍的流星雨，或輻射點整天都不利。每個資訊框的工具提示說明它所顯示的內容。必要時，資訊框下方會出現「無共同區域」警告，以及一條解釋字母 A 和 B 的說明列。
H2|7.2 計算設定
LI|保守（預設）：餘跡高度來自雷達、一般餘跡、β 角開啟。得出最低的數值。
LI|同 DJ5HG：固定高度 102 km、輻射點低時餘跡較長、β 角開啟；重現 QTFGUI 程式的結果。
LI|自訂：當您手動變更某個核取方塊或高度時會自動選取。
LI|輻射點低時餘跡較長（DJ5HG）：輻射點較低時落下的流星較少，但餘跡較長、反射較頻繁；在約 9° 以上，兩種效應會相互抵消。
LI|餘跡與路徑間的 β 角（完整 McKinley），位於標有「影響最大的選項」的橘色框中：開啟時，橫越路徑平面的餘跡比位於該平面內的餘跡低 10-15 dB，與路徑平行的輻射點占優勢。關閉時，採用傳統規則：最佳輻射點高度為 15-70°，且與路徑橫交。
LI|經典判斷：在每個流星雨下方增加「經典」一列，列出業餘無線電傳統規則在路徑中點處的判定：✗ 輻射點在地平線以下，◐ 勉強（過低、過高或幾乎與路徑平行），● 良好，★ 極佳（與路徑橫交）。不會改變計算結果。
TAG|ATTENZIONE|β 角對長路徑上的數值影響很大：JN70CN - JO76QP（1791 km），2026 年 12 月 14 日的雙子座流星雨，β 關閉時為 98 %，β 開啟時為 13 %。兩種論點的來源不同，與 BRAMS 計數的初步比較也無法區分它們：請以頻段上的經驗比較這兩種情況。百分比是相對於該路徑下輻射點的最佳位置而言；要比較不同的路徑，請使用以 dB 表示的效率。
H2|7.3 這些數字可信到什麼程度
P|最佳時段和一側是最可靠的資訊：它們隨計算設定的變化很小。而百分比則在很大程度上取決於所做的選擇，尤其是 β 角。與 50 MHz 上 181 767 筆真實 MSK144 spot（HamSCI，2025 年 8 月 11-12 日英仙座流星雨）的比較證實了路徑指數的逐時變化趨勢，但也顯示在某個時段能聽到哪一對電台，主要取決於偶發流星和空中的活動情況，而這些都不在模型之內。
TAG|NOTA|請用本程式來選擇時段以及天線要轉向的一側；不要把百分比當作通聯成功的機率。
H2|7.4 圖表

H1|8. 實驗性預測

H1|14. 典型操作
H2|14.1 為某個流星雨準備 sked
TAG|PROCEDURA|1) 設定兩個電台並按「計算」。2) 在「流星雨」中查看該流星雨的下一次極大。3) 將該日期填入「計算日期」。4) 在「效率計算」中查看該流星雨的列和 Σ 列：選擇效率最高的時段。5) 記下一側（A 或 B），並將天線朝該側轉 10-30°。6) 在「幾何與衰減」中檢查鏈路預算的餘裕。
H2|14.2 追蹤一次即時活動
TAG|PROCEDURA|1) 按「即時」。2) 在「預測計算」中追蹤建議的 Hot 和 PREV 區域，它們每分鐘更新一次。3) 在「雷達通量」中確認 Collm 雷達正在計數流星。4) 在「即時流量」中查看誰正在通聯以及他們的餘跡落在哪裡。
H2|14.3 用 GRAVES 測試電台
TAG|PROCEDURA|1) 在「GRAVES 雷達」中查看「GRAVES 波束中的有效區域」卡。2) 依「路徑」卡的說明指向天線。3) 在波束下次掃過的時間窗口內，在 143.049 MHz 以 USB 收聽。4) 將 ping 與預期回波以及 RMOB 觀測者的資料比較。
H2|14.4 用 RMOB 校準預測
TAG|PROCEDURA|1) 在「實驗性預測」中載入您所在頻段某位觀測者的 RMOB 月度檔案。2) 按「從 RMOB 檔案推算指數」，如果共同時段足夠多，則接受 k。3) 將電台係數 K 調整為建議值。
